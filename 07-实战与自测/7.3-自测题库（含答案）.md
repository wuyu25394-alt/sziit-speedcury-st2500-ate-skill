> 标注 ⭐ 的是本课程的**核心考点**。

## 第一部分：产业与概论（8 题）

**1.** 半导体产业链的四个环节是什么？各环节的代表企业有哪些？

<details><summary>答案</summary>
① 芯片设计（Fabless：海思、博通；EDA：Cadence、Synopsys、Mentor、华大九天；IP：ARM）；② 晶圆加工（Foundry：台积电、中芯国际）；③ 封装测试（OSAT：长电、华天、日月光、通富）；④ 设备材料（ASML、东京电子、Advantest、Teradyne、加速科技；信越化学、陶氏化学）。
</details>

**2.** ⭐ CP 和 FT 分别指什么？各自用什么设备和治具？

<details><summary>答案</summary>
CP = Circuit Probing，晶圆测试/中测，用 **Prober 探针台 + PIB + Probe Card 针卡**；FT = Final Test，成品测试，用 **Handler 分选机 + DIB/Load Board + Socket**。
</details>

**3.** ⭐ ATE、DUT、DIB、PIB、Die、BIN 分别是什么？

<details><summary>答案</summary>
ATE = 自动测试设备（测试机）；DUT = 被测器件；DIB = Device Interface Board，负载板，用于成测；PIB = Probe Interface Board，用于中测；Die = 晶圆上的一颗芯片；BIN = 按测试结果给所测芯片分类。
</details>

**4.** 测试机、分选机、探针台三者的职责分工是什么？

<details><summary>答案</summary>
测试机（Tester）：等待 handler/prober 发出测试启动信号，执行测试并把结果返回；分选机（Handler）：自动把芯片与测试机连接，告知是否就绪及同测数量，记录结果并按结果分等级；探针台（Prober）：把晶圆放到针卡针下，告知何时就绪、几颗可测、芯片 X-Y 坐标，记录结果并对失效品打墨点。
</details>

**5.** 什么是 IDM、Fabless、Foundry、OSAT？

<details><summary>答案</summary>
IDM：垂直整合制造，设计+制造+封测+销售全包（Intel、TI、三星、长江存储）；Fabless：只设计不制造（高通、联发科、海思）；Foundry：晶圆代工（台积电、中芯国际、华虹宏力）；OSAT：委外封装测试（日月光、长电、通富、华天）。
</details>

**6.** IC 测试的定义是什么？为什么要测试？

<details><summary>答案</summary>
IC 测试是通过测量 IC 的输出响应，将其与预期的输出相比较，以评估 IC 器件电性能的过程。它是验证产品性能、监控生产状况、分析产品失效的重要手段。测试的原因：IC 制造工艺永远无法达到 100% 良率，在上系统前必须先测试，剔除不良品以降低成本损失。
</details>

**7.** 课件列出的测试行业四大痛点是什么？

<details><summary>答案</summary>
① 半导体测试核心技术被海外垄断（爱德万、泰瑞达）；② 高昂测试设备阻碍 IDH 发展（数字测试机常百万美金）；③ 高昂设备增加生产成本；④ 严重缺乏测试专业人才。
</details>

**8.** 测试程序运行结束后会返回哪些信息？

<details><summary>答案</summary>
① 测试结果：通过或失效；② 结果分类（BIN）：HBIN 和 SBIN；③ 晶圆测试包含与结果对应的 die 坐标；④ 结果统计。
</details>

## 第二部分：直流参数测试（14 题）

**9.** ⭐ 为什么 OS 测试要放在测试的第一项？

<details><summary>答案</summary>
因为 DUT 与 ATE 的连接经过了连接器、测试负载板、测试头，电气连接可能有连接部件缺陷（探针卡或 Socket 接触异常、Pogo 管脚弯曲、测试头连接不良），会导致开路或短路。OS 测试能及早检测出物理缺陷（管脚短路、静电损坏、制造缺陷），从而减少后面的测试项、减少测试时间、降低测试成本。
</details>

**10.** ⭐ OS 测试的物理基础是什么？怎么根据极性判断测的是对 VDD 还是对 GND 的保护二极管？

<details><summary>答案</summary>
物理基础是芯片每个管脚都有的 **ESD 保护电路**（两个首尾相接的二极管，一端接 VCC、一端接 GND），正常工作时处于截止高阻态。极性约定：**流出 ATE 的电流为正电流，流入 ATE 的电流为负电流**。施加**正**电流 → 电流经 VDD→D1→引脚→ATE，测的是**对 VDD** 的保护二极管压降；施加**负**电流 → 测的是**对 GND** 的保护二极管压降。
</details>

**11.** ⭐ 为什么并行 OS 测试测不出 Pin-to-Pin 短路？有哪三种解决办法？

<details><summary>答案</summary>
原因：两引脚短路时电位相等，各自的保护二极管导通后，因工艺相同导通电压也基本相同，**不会造成电压变化**，每根引脚的测量值都会通过。解决办法：① 改用串行测试；② **奇偶分组法**（测奇数脚时偶数脚接地，测偶数脚时奇数脚接地）；③ 用**运行测试向量**的方式（对具备动态负载单元的数字测试机）。
</details>

**12.** 漏电流测试为什么要用 VDDmax？

<details><summary>答案</summary>
VDDmax 是漏电流测试**最严苛的条件**（电压应力越大，漏电越明显），能最大程度暴露绝缘氧化膜变薄、桥接、异物、划伤、隐裂等缺陷。
</details>

**13.** ⭐ IIL 和 IIH 的测试条件分别是什么？

<details><summary>答案</summary>
**IIL**：① 电源加 VDDmax；② 除被测引脚外其他引脚加高电平 VIH = VDDmax；③ 被测引脚用 PMU 加 VIL（0V），测得电流为 IIL。**IIH**：方法相同，但其他引脚加低电平（0V），被测引脚加高电平（VDDmax）。
</details>

**14.** IDD 有哪三种？各是什么含义？

<details><summary>答案</summary>
① **静态 IDD**：DUT 在静态条件下（如睡眠模式）消耗的电流；② **动态 IDD**：DUT 内部电路一直翻转时消耗的电流；③ **IDDQ**（瞬态 IDD / Quiescent IDD）：静态电源电流测试。前两者都需要先运行**预置向量**把 DUT 置成相应状态并维持到测量完毕。
</details>

**15.** ⭐ VOH 的测试步骤是什么？为什么要用 VDDmin？

<details><summary>答案</summary>
步骤：① 电源加 **VDDmin**；② 执行预置状态向量使被测引脚输出逻辑 1；③ PMU 施加 IOH（一般为**负向**）；④ PMU 测量 VOH；⑤ 判断。用 VDDmin 是因为这是**最严苛的条件** —— 在这个条件下 VOH 仍能满足规格要求，才能保证器件在全电压范围内都合格。
</details>

**16.** ⭐ VOH 和 VOL 的电流方向分别是什么？

<details><summary>答案</summary>
VOH：**抽**电流（从 DUT 流出，IOH 一般为负向）；VOL：**灌**电流（流入 DUT，IOL 一般为正向）。
</details>

**17.** ⭐ 为什么 VIH/VIL 无法直接测量？

<details><summary>答案</summary>
因为输入电平不是用表去量，而是**通过功能测试来判断**：给 DUT 供电，把 VIL/VIH 设置到极限值（使输入电压符合逻辑 0 的最大电压 / 符合逻辑 1 的最小电压，这是最严苛条件），然后执行相应的测试向量，**通过向量执行成功与否判断 VIL/VIH 是否符合要求**。
</details>

**18.** ⭐ 五种测量模式 FVMI / FIMV / FVMV / FIMI / FNMV 分别是什么？测电压和测电流各用哪个？

<details><summary>答案</summary>
FVMI = Force Voltage Measure Current（强压测流）；FIMV = Force Current Measure Voltage（强流测压）；FVMV = Force Voltage Measure Voltage；FIMI = Force Current Measure Current；FNMV = Force Nothing Measure Voltage（不强制，只测压）。
**口诀：要测电压 → 用 FIMV；要测电流 → 用 FVMI。**
</details>

**19.** ⭐ OS / IIL / IDD / VOH / VOL 分别用哪种测量模式？

<details><summary>答案</summary>
OS（OSP/OSN）用 **FIMV**；IIL / IIH 用 **FVMI**；IDD 用 **FVMI**；VOH 用 **FIMV**；VOL 用 **FIMV**。
</details>

**20.** CD4511 的 VOL 只灌 10 µA 而 VOH 抽 10 mA，说明了什么？

<details><summary>答案</summary>
体现了 CMOS 电路"**拉电流能力强、灌电流能力弱**"的特性 —— 课件明确说"CMOS 电路能提供较大的拉电流，可直接驱动共阴 LED 数码管"。两者量级差 1000 倍。测反了会损坏器件或测不准。
</details>

**21.** 小电流测量为什么要"先大量程、再切小量程"？

<details><summary>答案</summary>
因为上电瞬态或电容充电效应会让小量程下的读数超量程或剧烈跳动。先用大量程让电路稳定，再切到小量程（2 µA / 5 µA / 10 µA / 1 µA）精测，可以得到稳定可靠的读数。
</details>

**22.** 写一个测试函数的"六步套路"是什么？

<details><summary>答案</summary>
变量定义 → 硬件选择 → 信号连接 → 参数设置 → 参数测量 → 复位。（来自 TPS73625 课件的「编程提示」）
</details>

## 第三部分：交流参数与功能测试（12 题）

**23.** 传输延时 Tpd 的定义与测量方法是什么？

<details><summary>答案</summary>
定义：从输入脉冲到引起输出电平跳转的时间间隔。测量：通常取**波形幅度的 50%** 作为测量点，分别测出上升沿延时 t<sub>PLH</sub> 和下降沿延时 t<sub>PHL</sub>，**将这两个延时值求算术平均值**即为传输延时 Tpd。
</details>

**24.** 上升时间和下降时间通常怎么定义？

<details><summary>答案</summary>
**上升时间 = 输出脉冲幅度从 10% 上升到 90% 所需时间；下降时间 = 从 90% 下降到 10% 所需时间。**
</details>

**25.** 建立时间（Setup Time）和保持时间（Hold Time）的定义是什么？

<details><summary>答案</summary>
建立时间：指触发器的时钟信号有效沿（如上升沿）到来**之前**，数据保持稳定不变的时间；若不满足建立时间，数据只能在下个时钟上升沿输入触发器。保持时间：时钟边沿触发**之后**数据需要继续保持的时间。这两个参数表征**时钟边沿触发前后数据需要在锁存器输入持续的时间**。
</details>

**26.** ⭐ 什么是 Pattern？Pattern 与 Vector 是什么关系？向量深度指什么？

<details><summary>答案</summary>
测试向量（Pattern，也叫测试图形）是一组按照某种模式排列的向量序列。Pattern 的**每一行**称为**一行向量（Vector）**，由多行 Vector 组成一个测试 Pattern。**向量深度（Vector Depth）/ Pattern 存储容量**指可以存储多少行 Vector。本课程中 Pattern 与 Vector 意义相同。**Pattern 的本质就是真值表**。
</details>

**27.** ⭐ 默写 Pattern 中的 8 个符号含义。

<details><summary>答案</summary>
`0` = 输入低电平；`1` = 输入高电平；`Z` = 输入高阻态；`H` = 输出高电平；`L` = 输出低电平；`M` = 输出高阻态；`V` = 输出有效状态（无论高低）；`X` = 不关心输出状态。
</details>

**28.** ⭐ 为什么不能在功能测试中把输入引脚写成 "X"？

<details><summary>答案</summary>
因为 **"X" 是输出测试的 mask 态**。给了 `X`，测试机就会把此引脚**当作输出去处理**，连接到比较电路。**在功能测试中，输入引脚不能直接测试期望得到 Pass/Fail 的结果；信号施加到输入引脚，我们需要测试的是输出引脚。** 输入脚不关心时应给确定的 0/1 或用 `P` 保持。
</details>

**29.** 为什么不能把测试机的驱动单元连接到 DUT 的输出引脚？

<details><summary>答案</summary>
会造成测试机和器件本身**在同一时间驱动电压和电流到该引脚**，当它们在某一点相遇时，**电流小的一方会受到严重破坏**（可能烧毁通道或 DUT）。
</details>

**30.** Pattern 数据有哪两种生成方式？各适用于什么场合？

<details><summary>答案</summary>
① **手工解读产品手册的真值表** —— 适用于功能简单的产品；② **由电路设计的仿真文件转换** —— 适用于复杂芯片（靠解读真值表已不可行）。仿真文件格式包括 **WGL、STIL**（一般提供 SCAN 测试向量，时序固定，提取相对简单）和 **VCD**（功能测试常用，转换难易度取决于 ATE 结构与硬件限制，需要经验）。
</details>

**31.** ⭐ 时序的四个基本概念是什么？

<details><summary>答案</summary>
① **周期（Cycle）**：ATE 运行 Pattern 以周期为单位，反映运行速度，**ATE 可设置的最小周期是衡量性能的重要指标**（如 125 MHz → 8 ns），通常用 T0 表示；② **沿（Edge）**：一个周期内数据出现或改变的时刻点，包括输入时间沿、比较时间沿；③ **波形格式（Format）**：RZ（归 0）、RO（归 1）、NRZ（非归 0）、SBC（补码环绕），以及更灵活的 Wave Table；④ **输出采样（Strobe）**：在固定时刻点对输出电平采样比较，有单点采样（Edge Strobe）和窗口采样（Window Strobe）两种。
</details>

**32.** 功能测试的三件套是什么？为什么缺一不可？

<details><summary>答案</summary>
**Pattern（输入输出状态）+ Timing（时序）+ Pin Level（引脚电平）**。因为 Pattern 中只包含输入输出的状态，要把 Pattern 数据变成电路测试所需的输入信号、并在相应的时刻点采集输出信号，就必须配合时序信息；而要确定什么样的电平表示 0、表示 1，以及判据电平 VOL/VOH，就必须设定引脚电平。Pin Level 的设定依据是 **Datasheet 的 DC 参数部分**。
</details>

**33.** 74LS194 的 DC 参数表中 VOH = 2.7 V（Vcc = Min，IOH = Max），如果做输出比较，VOH 阈值应设多少？

<details><summary>答案</summary>
设 **2.7 V**（或略低）。VOH = 2.7 V 表示在 Vcc 最小、IOH 最大（最恶劣条件）下输出高电平的最小保证值，因此用 2.7 V 作为"输出高电平"的判据才有意义。
</details>

**34.** RZ、RO、NRZ、SBC 分别是什么？

<details><summary>答案</summary>
RZ = Return to Zero，归 0；RO = Return to One，归 1；NRZ = None Return to Zero，非归 0；SBC = Surrounded by Complement，补码环绕。
</details>

## 第四部分：ST2500 平台与资源（8 题）

**35.** ⭐ `1:1:0` 这种通道号格式的三个参数分别代表什么？

<details><summary>答案</summary>
**Adapter（机头，1–8）: FBID/Slot（业务板，1–5）: Channel（通道，从 0 开始）**。
**不含"资源类型"层** —— 资源类型由 `.sig` 文件的 `AFEType` 字段单独指定。
</details>

**36.** 课件给出的各资源通道范围是多少？

<details><summary>答案</summary>
DPS 0–3；DIO 0–31；TMU 0–3；CBIT 0–7；AWG 0；DGT 0。
</details>

**37.** ⭐ 列出 ST2500 的 AFE 资源类型及其功能（至少 9 种）。

<details><summary>答案</summary>
CBIT（控制继电器，切换不同资源通道）；DPS（电源管理模块，芯片上下电）；DIO（数字输入/输出/高精度测量，芯片输入 Pattern）；BPMU（板载高精度测量）；AWG（波形发生器）；DGT（数字采集模块）；RVS（Reference 电源管理模块）；TMU（AC 参数测试）；SMU（高压电源模块，独立的 4 通道电压电源板卡）。另有 POWER、RF、DPS_GANG2/3/4、SMU_GANG2/3/4、LF_AWG_NEG/POS、LF_DGT_NEG/POS。
</details>

**38.** 课件把测试资源按功能分成哪五类？

<details><summary>答案</summary>
电源模块（PPMU、DPS、BPMU、RVS —— 电压电流的提供与测量）；数字模块（DIO）；时间测量模块（TMU）；A/D 模块（AWG、DGT）；继电器模块（CBIT）。
</details>

**39.** 单个测试机头有几块业务板？最多几个机头？最多几个 Site？

<details><summary>答案</summary>
单个机头 **5 块**业务板（Slot1~Slot5）；最多 **8 个**机头（Adapter 1–8）；最多支持 **1024** 个 Site 工位。
</details>

**40.** Online / OffLine 是什么意思？

<details><summary>答案</summary>
Online = 板卡在位；OffLine = 未在位。`.res` 文件里 Status 字段表示当前机头和板卡的在位状态。
</details>

**41.** ChType 有哪些取值？各代表什么？

<details><summary>答案</summary>
`Inout`（输入输出）、`Supply`（供电）、`In`（输入）、`Out`（输出）、`Default`（默认）、`RxTx`（接收发送）。
</details>

**42.** Kelvin（开尔文四线）检测的要点是什么？

<details><summary>答案</summary>
用**独立**的对载电流电极和电压检测电极，相比传统两线（2T）传感能进行更精确的测量。关键优点是**分离的电流与电压电极消除了布线和接触电阻的阻抗**。用于欧姆表、阻抗分析仪、精密应变计和电阻温度计接线、薄膜薄层电阻测量等。
</details>

## 第五部分：SMU 专题（4 题）

**43.** ⭐⭐ SMU 的全称是什么？中文叫什么？

<details><summary>答案</summary>
**SMU = Source Measure Unit**，中文叫"**源测量单元**"，业内俗称"**源表**"。S = Source（源，能发出电压或电流）；M = Measure（测量，能读出电压或电流）；U = Unit（通道化的独立仪器单元）。
</details>

**44.** ⭐⭐ 在 ST2500 使用手册里，SMU 是怎么定义的？有哪几个变体？

<details><summary>答案</summary>
手册表 2-22「AFEType 说明」中的定义是"**高压电源模块，独立的 4 通道电压电源板卡**"，`ChType = Supply`。变体有 **SMU / SMU_GANG2 / SMU_GANG3 / SMU_GANG4**（多通道并联 Gang 版本）。
此外手册 P.81 正文提到"板卡类型不单只有 DFB32，还增加了 **SMU 板**、音频板 MWB8"—— 说明 SMU 是与 DFB32、MWB8 **并列的独立板卡类型**，而非板载 AFE 模块。
</details>

**45.** ⭐ SMU 和 DPS / PPMU / BPMU 的区别是什么？

<details><summary>答案</summary>
① **物理形态**：SMU 是**独立板卡**；DPS / PPMU / BPMU 是 **DFB32 板上的 AFE 模块**。② **定位**：SMU 定位"**高压**"；DPS 是标准器件供电（−3.25 V ~ +8.4 V）；PPMU / BPMU 是精密参数测量。③ **Gang 命名对称**：DPS 与 SMU 各有 GANG2/3/4，语义相同（多通道并联），ChType 均为 Supply。④ 手册**未给出 SMU 的任何电气指标**（量程/精度/分辨率/带宽），也未说明其是否具备电流测量能力。
</details>

**46.** ⭐ 本课程的 6 个实训工程用到了 SMU 吗？为什么？

<details><summary>答案</summary>
**没有**。6 个工程用到的资源是 DPS、PPMU、BPMU、DIO、CBIT、AWG、DGT、TMU。因为教室教学机配置的是 **DFB32 业务板**，SMU 是同平台的**选配板卡**。一旦机上装了 SMU 板，`.res` 自检后 `AFEType` 下拉列表会自动多出 SMU / SMU_GANG2/3/4 这几项。
**但要注意**：本课程所有 DC 测试（OS 的 FIMV、IIL/IDD 的 FVMI、VOH/VOL 的 FIMV）在**仪器原理上都属于"源测量单元"的工作** —— SMU 的概念贯穿全课程。
</details>

## 第六部分：工程文件与开发流程（8 题）

**47.** ⭐ 工程的 7 个配置文件各自的职责是什么？

<details><summary>答案</summary>
`.job`（工程总入口，串联全部文件、声明测试库与 Lot 信息）；`.res`（机台资源定义，自检结果存此处）；`.sig`（信号→通道映射：SigName, AFEType, ChType, Site0_CH）；`.grp`（信号分组）；`.tim`（时序/Wave Table）；`.pat`（Pattern 索引）；`.tmf`（测试流、限值、Bin）。
</details>

**48.** ⭐ `.pat` 和 `.tmf` 的关键区别是什么？

<details><summary>答案</summary>
`.pat` 只是"**向量素材目录**"（名字 → CSV 路径），**无顺序、无限值、无 Bin**；`.tmf` 是"**整份考卷 + 评分标准**"，管全部测试项（DC 参数项根本不经过 `.pat`），负责**顺序、限值、分 Bin**。数量上 `.tmf` 项数 ≥ `.pat` 数（如 HK32F031：14 项 vs 11 pattern；CD4511：8 项 vs 1 pattern）。
</details>

**49.** ⭐ `Test.cpp` 里有哪些系统预设函数？分别在什么时机执行？

<details><summary>答案</summary>
`ProjectReuse`（程序重新加载时）、`ProjectInit`（第一次加载时）、`ProjectReset`（退出时）、`site_init`（每次测试开始时）、`site_reset`（每次测试结束时）、`EndOfWafer`/EOW（CP 测完一片时）、`EndOfLot`/EOL（FT & CP 测完一个 Lot 时）、`USER_CODE` 用户测试项（与 tmf 项目关联）、`SetPassBin`（最终分 Bin）。另有无 main() 的设计：靠 `USER_CODE` 导出 + `.tmf` 的 FuncName 调度。
</details>

**50.** ⭐ SetPassBin 和 SetErrorBin 各自的作用是什么？

<details><summary>答案</summary>
**SetPassBin**：当所有测试项目都 pass、顺序执行结束、中途没有 fail 被分到不良品 Bin，则会从最后一个项目顺序执行到 SetPassBin，此项目分 Bin 后判定为**良品，一般设置 Bin 参数为 1**。
**SetErrorBin**：如果程序编写的测试逻辑或分 Bin 部分出现疏漏，无法顺利到设定的 fail Bin 或 pass Bin，则程序会运行到 SetErrorBin 并进行 Bin，此时需要进行程序逻辑的确认。此项目**在建立 tmf 开始自动生成**，只需设置 Bin 参数并**确保不要和正常测试项目相同**。
</details>

**51.** `.tmf` 里 `Result` 列的三种取值（fail / pass / None）分别是什么行为？

<details><summary>答案</summary>
**fail**：limit 判定 fail → 跳出分 Bin；limit 判定 pass → 继续执行下一项。
**pass**：limit 判定 fail → 继续往下执行；limit 判定 pass → 进行分 Bin。
**None**：无论 limit 判定 pass 还是 fail，都继续往下执行。
</details>

**52.** 测试工程的完整流程是什么（从建工程到看日志）？

<details><summary>答案</summary>
① 开工控机 → 开测试机（指示灯变绿）→ 启动系统软件；② 登录（admin/dev/user）→ 选 Development；③ File → New → Project；④ 依次配置 `.res`（Get Resources）→ `.sig` → `.grp` → `.tim` → `.pat` → `.tmf`（保存后 Test.cpp 自动生成函数框架）；⑤ 在 Test.cpp 里按六步套路实现各测试函数；⑥ **Ctrl+B 编译**（必须先 Build）；⑦ **Ctrl+L 加载**（Console 全 success 无红字）；⑧ 打开 `.tmf` 选中测试项 → 设 LoopCount/DoAll → Site Configuration 选 site → **Run**；⑨ 点 **Log** 打开 Datalog 看 Table Log / Text Log。
</details>

## 附加：简答题（6 题）

**53.** 为什么测试程序的测试项要按"OS → IDD → 功能 → DC 参数"的顺序排列？

<details><summary>答案</summary>
这是**测试成本控制**的核心逻辑：先做**最快、最便宜、最容易筛掉坏品**的项（连接性、开短路、Gross IDD），把可能造成损坏的项放前面，**越贵的测试越往后放**。这样坏品在早期就被剔除，不必走完整个昂贵的测试流程。
</details>

**54.** HK24C02 为什么必须用继电器控制上拉电阻？

<details><summary>答案</summary>
因为 I²C 的 SDA 是开漏结构、**本身没有输出高电平的能力**，功能测试时必须通过电阻上拉到 VCC。但接入上拉电阻后会**影响开短路及漏电流测试**（上拉电阻提供了一条到 VCC 的低阻通路，测到的"漏电流"其实是上拉电流）。所以必须用 CBIT 控制的继电器**物理断开或连接上拉**，才能同时满足功能测试需求和 DC 测试需求。
</details>

**55.** 为什么 MCU 的 VOH/VOL 测试不直接用 PMU 加压测流？

<details><summary>答案</summary>
因为 MCU 引脚**功能复用复杂**（同一引脚可能是 GPIO / SPI / ADC / 定时器 / 晶振），必须**先输入 PassCode 把芯片切进专门的测试模式**，让引脚被配置成期望的输出状态，才能可靠地测。所以 HK32F031 的 VOH/VOL 是在测试模式下**跑 Pattern 比较电平**，而不是用 PMU 强制。
</details>

**56.** ADC 量产测试中"单阈值设定"是什么？为什么要这样做？

<details><summary>答案</summary>
把 DO 的采样电平 **VOL 和 VOH 都设为 2.5 V**（VCC/2）：输出高于 2.5 V 采集为 H，低于 2.5 V 采集为 L。这样做等价于**用 DIO 比较器实现了一个 1 bit ADC**，从而能把 ADC 的串行数字输出流还原成数字码。如果 VOH 和 VOL 设成不同值，采集到的码就会错。
</details>

**57.** 遇到"从 PDF 提取出来的文本很少"应该怎么处理？

<details><summary>答案</summary>
**第一反应应是"它可能是扫描版/图片型 PDF"，而不是"这份文档没有内容"。** 本课程就有两份这样的数据手册：HK24C02（18 页只提取出 423 字符）和 CD4511BE（电气特性页全是图片）。正确做法是用 PDF 渲染工具把页面转成图片，再用视觉方式识读内容。教学课件里也有 **222 个图片型页面**（尤其是硬件介绍 18/18 页、电源模块 15/16 页）。
</details>

**58.** 本课程 6 个实训工程的难度排序是什么？为什么这么排？

<details><summary>答案</summary>
**CD4511 → HK24C02 → LM358 → TPS73625 → HK32F031F4P6 → ADC0832**。
CD4511 最简（1 个 Pattern、7 个 DC 项，把工程体系跑通）；HK24C02 引入 I²C 协议与继电器切上拉；LM358 跳出数字世界进入模拟参数（失调、增益、CMRR、PSRR）；TPS73625 综合度上升（DC + AC 混合、六类资源、大电流负载）；HK32F031 最复杂（14 个测试项、PassCode 测试模式、TMU 测频、11 个 Pattern）；ADC0832 最高阶（AWG 激励 + 高速采集 + 自行实现 FFT 与 INL/DNL/SNR/ENOB 算法）。
</details>
