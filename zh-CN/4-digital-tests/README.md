# 第 4 部　数字与功能测试

直流测试回答「电气特性对不对」，功能测试回答另一件事：**这颗芯片的逻辑对不对。**

功能测试是测试机最能体现「自动化」的部分：一张真值表或一段时序，被翻译成几千行向量，在几十纳秒的节拍里被驱出去、采回来、逐条比对。出了问题，报错信息往往只有一句「第 37 行第 5 拍不匹配」——所以这一部除了讲怎么写，也要讲怎么读懂它。
