# 第 7 部　走出实训台

实训台上测一颗芯片，fail 了就看一眼、改个判据、重测。量产线上不能这么做：那里一分钟过几百颗，每一个判据背后都有统计，每一次重测都要有理由。

这一部讲两件事：**数据怎么说话**（良率、Bin、Cpk、相关性），以及**从一个人的测试台到一条产线，中间差了什么**（Handler、多工位、测试时间、成本）。
