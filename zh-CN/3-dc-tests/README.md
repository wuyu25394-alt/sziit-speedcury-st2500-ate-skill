# 第 3 部　直流参数测试

直流测试是测试程序里最先跑、跑得最多、也最容易被轻视的一类。它慢——几百微秒到几毫秒一次；它简单——本质就是给一个电压量一个电流，或者反过来；但它能回答一个最根本的问题：**这颗芯片的输入端、输出端和电源端，还好不好。**

这一部按「芯片的哪个部位」来分：漏电流看输入端，输出能力看输出端，电源电流看电源端，模拟参数看放大与稳压这两类电路的核心指标。

| 章节 | 你会读到 |
|---|---|
| [第 9 章　漏电流：IIL、IIH 与 IOZ](09-leakage/README.md) | 输入漏电怎么来的、为什么 µA 级测量要特别小心 |
| [第 10 章　输出能力：VOH、VOL、IOH 与 IOL](10-output-drive/README.md) | 输出高低温、拉灌电流能力、负载条件 |
| [第 11 章　电源电流：IDD 与 ICC](11-supply-current/README.md) | 静态与动态电流、为什么它常是良率的晴雨表 |
| [第 12 章　模拟参数：失调、增益、抑制比](12-analog-parameters/README.md) | VOS、AVD、CMRR、PSRR，以及运放与 LDO 的关键指标 |
