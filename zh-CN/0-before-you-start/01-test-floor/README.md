## 机柜与板卡

ST2516 的机头分上下两段：上面是测试主体，主控板（System Control Board，SCB）加业务板；下面是电源模块。正面认五样：五个槽位（Slot1～Slot5）、整机状态灯、电源按钮、急停按钮、各业务板自己的状态灯。

槽位是容量单位，ST2516 五个槽位插满，就是 160 路数字 I/O、160 路 PPMU、20 路 DPS；ST2532 是两个 ST2516 拼起来，ST2564 是四个，规格直接叠加。主控板管上下电与电压温度监控，FPGA 管数据转发与业务板间的快速触发协同。

主力业务板叫 **DFB32**，一块板集成九类模拟前端（Analog Front End，AFE）模块：

| 模块 | 通道 | 干什么 |
|---|---|---|
| DIO | 32 | 数字波形输入与比较 |
| PPMU | 32 | 每个 DIO 附一个，测电压 |
| BPMU | 4 | 板载高精度测量 |
| DPS | 4 | 给芯片供电 |
| CBIT | 8 | 控制 DUT 板上的继电器 |
| RVS | 1 | 参考电压 |
| AWG / DGT | 各 1 | 生成与采集模拟波形 |
| TMU | 4 | 测频率、周期、脉宽 |

整机 125 MHz、250 Mbps。板卡不止 DFB32 一种：手册还列了 **SMU 板**（SMU20，独立 4 通道，20 V、±500 mA）与**音频板 MWB8**。

三类板可同机共存，选资源之前先要知道板在不在位——这件事归 `.res` 管。

> [!NOTE]
> **📖 名词｜业务板（Function Board）与 AFE 模块**
>
> - **定义**：业务板是插在槽位里的整块板卡；AFE 模块是板上按功能划分的电路单元，一块板可有多种。
> - **现场用法**：「这个槽位的板掉了，先把它 OffLine，用剩下四块跑。」
> - **相关名词**：SCB、Slot、DFB32、SMU20、MWB8
> - **常见混淆**：把板卡和资源当成一回事。DPS 是资源，住在 DFB32 上；SMU 既是资源名，也是一种独立板卡。

## 一条通道的三段编号

`.sig` 里给引脚挑资源，填的是 `1:1:6` 这样的三段数字：

**Adapter : FBID（Slot） : Channel**

| 字段 | 含义 | 范围 |
|---|---|---|
| Adapter | 级联系统里第几台机头 | 1～8 |
| FBID | 机头里第几块业务板，对应 Slot1～Slot5 | 1～5 |
| Channel | 这种资源的第几个通道，**从 0 开始** | 见下 |

通道上限随资源类型变：DIO 0～31、DPS 0～3、BPMU 0～3、TMU 0～3、CBIT 0～7，AWG、DGT、RVS 只有 0 号。手册的实例是「PA0 用 1 号机头 Slot1 的 DIO6 通道」，写成 `1:1:6`；`1:1:0` 则是同一位置的 **0 号**通道，也就是第一个。

> [!NOTE]
> **📖 名词｜通道三元组（Adapter : FBID : Channel）**
>
> - **定义**：`.sig` 里给每个信号指定物理资源通道的三段式地址，依次是机头、业务板、通道号。
> - **现场用法**：「VDD 走 `1:1:0`，PA0 走 `1:1:6`，中间那位不是通道。」
> - **相关名词**：AFEType、Site、Share、`.res`
> - **常见混淆**：写成「板卡 : 资源 : 通道」是错的，三元组**没有资源类型这一层**，资源类型由 `AFEType` 单独指定。另一个坑是通道号从 0 起：`1:1:1` 取到的是第二个通道。

## 接口板与继电器

业务板每块两个高密度插槽，上面 J1、下面 J2，各 160 针。DUT 线缆一头插 J1、J2，另一头是 3 列（a/b/c）× 32 排，插到 DUT 板上。整块板的 160 个通道，就在这张表上排开：

| 资源 | 位置 |
|---|---|
| DIO | PIN 1～32 的 a 列，CH0 / 8 / 16 / 24 带 `_HV` |
| DPS / BPMU | PIN 29～32、PIN 19～22，各 4 组 FORCE / SENSE |
| CBIT / RVS | PIN 8～11 的 D0～D7、PIN 18 的 1 组 |
| 模拟与电源 | PIN 24 的 AWG_OUT 与 DGT_IN；PIN 1、3、4、6、7 的 −7.2 V、11.5 V、5 V、GND |

再往外是接口板：中测用探针接口板（Probe Interface Board，PIB）加探针卡，成测用负载板（Device Interface Board，DIB）加 Socket。课程用的 SE-GIB100 通用接口板有 8 块万用板、5 个 96Pin 端口，两侧一一对应。

真正的开关是继电器。模块布局统一：**上部线缆插槽 → 中部继电器 → 下部 Socket**，HK24C02 一个、ADC0832 三个、LM358P 六个、TPS73625 八个，CBIT 就是控制它们的那八根线。

LM358P 上同一个 1IN− 引脚，靠继电器能改成四种接法：接 AWG、串 100 Ω、与 1OUT 短接成闭环、接辅助积分电路——引脚没变，接在它上面的电路变了。HK24C02 的 RL14（CBIT0）把 VCC 接到 SDA 与 SCL 做上拉，没有它 I²C 就写不进去。

> [!TIP]
> **🔧 Know-how｜先置继电器，再测量**
>
> - **情境**：同一块模块上两个参数，一个要开环、一个要闭环，接线只有一套。
> - **做法**：先把 CBIT 对应位置到需要的状态，等继电器动作完（工程里一般留 8～10 ms）再施加激励。
> - **为什么**：继电器是机械动作，线圈通电到触点闭合有延时，不等它就会在旧接法上读数。
> - **没做会怎样**：读数看着正常，其实测的是上一个接法下的电路，整批数据的含义都错位。
> - **相关章节**：[第 8 章 其他资源：继电器、CBIT、TMU、AWG 与 DGT](../../2-instrumentation/08-other-resources/README.md)

## 软件的四种入口

同一个软件，登录界面给四个入口。选错不报错，只是有些操作凭空消失。

| 入口 | 账号 | 能做什么 |
|---|---|---|
| 用户管理模式 | admin / admin | 建账号、配权限，账号名定了不能再改 |
| 开发模式 | dev / dev | 建工程、写程序、调时序与向量 |
| 量产模式 | user / user | 跑已发布的程序，看良率与 Bin |
| 机台维护模式 | — | 校准、自检、查板卡状态 |

开发模式里还有一道自检：打开 `.res` 点 **Get Resource**，显示 **Online** 才算真连上——灯只说明供电，Online 说明自检通了。区别不在权限大小，而在**同一个动作被允许到什么程度**：开发能改判据、改时序，量产只能跑。这条线是良率的保险丝——判据能随手放宽，良率数字就不值钱了。

## 本课程的实训平台

教室那台 **ST2516** 配五个成品模块和一块通用器件接口板。模块各带外围电路与线缆插槽，留了调试接口可直接量引脚电压；资源配得克制：HK24C02 只用 DIO 与 CBIT，LM358P 加 AWG 与 BPMU，TPS73625 再加 DGT，HK32F031F4P6 用 TMU，ADC0832 用 AWG。

六个案例里只有 CD4511 走通用器件接口板，电路要自己用杜邦线在万用板上搭；其余五个插上芯片、接好线、导入工程就能跑。**没有一块板用到 SMU**：教学机装的是 DFB32，SMU20 属于扩展板卡。

接线三条规矩，每条都是拿片子换来的：**缺口对齐后再插**，不能蛮力；**换芯片先停测试、断电**；**芯片 1 脚对准白色三角**。

开机顺序按实训平台手册走更稳：**先控制主机（标记 1 开机、2 重启），进桌面后再按机头电源**。软件必须在测试机启动之后打开；测试机重启，软件要跟着重启。

> [!TIP]
> **🔧 Know-how｜开机顺序为什么不能反过来**
>
> - **情境**：早上到实验室，先点软件，再去按机头电源。
> - **做法**：控制主机 → 进桌面 → 机头电源 → 等自检完成 → 开软件。
> - **为什么**：软件启动时要读机台资源，机头没起来，读到的是空的。
> - **没做会怎样**：`.res` 里资源为空或全 Offline，后续所有通道选择都无从下手。
> - **相关章节**：[第 19 章 调试与排错：连不上、不生效、对不上](../../5-programming/19-debugging/README.md)

## 本章重点

1. 机头 = 主控板 + 5 块业务板 + 电源模块；槽位是容量单位，ST2516 五个槽位、160 路 DIO、20 路 DPS。
2. 一块 DFB32 集成九类 AFE 模块；SMU20 与音频板 MWB8 是并列的**独立板卡**，装不装决定 `.res` 里有没有这项资源。
3. 通道写成 `Adapter : FBID : Channel`，FBID 是槽位号 1～5，Channel **从 0 开始**，三元组里没有资源类型这一层。
4. 资源到引脚要过两层：接口板负责翻译，继电器负责切换，「引脚接了什么」是程序要管的状态。
5. 四个入口的分界是「能不能改」，开工先看 `.res` 是否 Online。
