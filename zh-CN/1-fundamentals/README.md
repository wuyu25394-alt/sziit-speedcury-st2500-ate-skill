# 第 1 部　基础

在拆开测试机之前，先把两件事说清楚：**测试到底在测什么量的什么值**，以及**一次测试是按什么顺序串起来的**。

这两章不涉及任何一台具体的机器。想明白它们，后面每一个测试项都会变得顺理成章；想不明白，就只能靠背。
