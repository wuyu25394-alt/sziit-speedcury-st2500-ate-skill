# 第 6 部　六个实训案例

前面五部是拆散了讲的。这一部把它们装回去：六颗真芯片，六个完整的测试工程，从引脚分配一路做到 bin 分类。

六颗芯片的难度是递进的：从纯数字的译码器开始，经过存储器、运放、稳压器、单片机，最后到模数混合的 ADC。每多一颗，就多一类资源、多一种测试方法、多一个坑。

| 章节 | 你会读到 |
|---|---|
| [第 20 章　案例一：CD4511 数字译码器](20-cd4511/README.md) | 纯数字器件：开短路 + 漏电 + 输出电平 + 真值表 |
| [第 21 章　案例二：HK24C02 存储器](21-hk24c02/README.md) | I²C 时序怎么写进 Pattern、页写与读回 |
| [第 22 章　案例三：LM358 运算放大器](22-lm358/README.md) | 失调电压、开环增益、共模与电源抑制比 |
| [第 23 章　案例四：TPS73625 线性稳压器](23-tps73625/README.md) | 输出电压精度、压差、静态电流与使能控制 |
| [第 24 章　案例五：HK32F031F4P6 单片机](24-hk32f031/README.md) | 多电源域、复位与时钟、跑一段程序再测 |
| [第 25 章　案例六：ADC0832 模数转换器](25-adc0832/README.md) | ADC 的静态与动态指标：DNL、INL、ENOB |

> 每个案例的完整源码与逐行分析在笔记库里：`notes/05-实训案例/`。
