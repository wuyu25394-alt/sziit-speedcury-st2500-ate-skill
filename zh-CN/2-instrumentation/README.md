# 第 2 部　测试机的资源

一台测试机看起来很神秘，拆开之后其实是一排板卡，每块板卡提供几种**资源**，每种资源只能做少数几件事。

这一部按「一条通道能干什么」来讲：从每根引脚都要有的驱动与比较，到给整颗芯片供电的器件电源，再到精度最高、功能最全的源表。看完这一部，你手里就有一张资源清单，知道每个测试项该向谁借力。

| 章节 | 你会读到 |
|---|---|
| [第 4 章　引脚电子：每条通道的驱动与比较](04-pin-electronics/README.md) | Driver、Comparator、动态负载、每引脚的 PMU |
| [第 5 章　DPS：给芯片供电，顺便量出它吃多少](05-dps/README.md) | 器件电源的电压/电流档、四线接法、Gang 并联 |
| [第 6 章　PMU 与开短路测试](06-pmu-and-os/README.md) | PPMU 与 BPMU、二极管钳位、为什么开短路能一眼看出坏 |
| [第 7 章　SMU：一台能四象限工作的源表](07-smu/README.md) | 源测一体、四象限、Compliance、开尔文四线、与 PMU 的区别 |
| [第 8 章　其他资源：继电器、CBIT、TMU、AWG 与 DGT](08-other-resources/README.md) | 资源怎么被切换到引脚上、时钟与波形资源、板级自检 |
