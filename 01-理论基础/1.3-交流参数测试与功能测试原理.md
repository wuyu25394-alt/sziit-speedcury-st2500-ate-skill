# 第一部分：交流参数测试（AC Test）

交流参数测的是信号在**时间维度**上的行为。课件列出三个核心参数族：

## 一、传输延时 Tpd（P.18）

### 1.1 为什么重要

在数字电路中，时钟（Clock / CLK）起同步作用 —— 数据时序、逻辑门电路翻转都以时钟为基准。**时钟频率的精度对电子系统可靠、稳定工作至关重要。**

电路中：
- 电子器件的数据处理**需要时间**；
- 信号线路传输信号**也需要时间**。

这些引入的延时必须被测出来，才能在电路设计和程序控制时精确计算时序控制，保证逻辑功能正确。

### 1.2 定义与测量

> **传输延时（Tpd）**：从输入脉冲到引起输出电平跳转的时间间隔。

以非门状态翻转为例：芯片输入 x 低电平，输出 Y 输出高电平，x 与 Y 之间存在延时。

**测量方法**：通常取**波形幅度的 50%** 作为测量点。
- 输入 X 转换到低电平 → 输出 Y 经过延时 t<sub>PHL</sub> 转换为高电平；
- 反向跳变延时记为 t<sub>PLH</sub>；
- **将这两个延时值求算术平均值，这个值就是传输延时 (Tpd)**。

> 课件给出的实例（74LS194 交流参数表，环境温度 25 °C，VCC = 5.0V，CL = 15pF）：
> t<sub>PLH</sub> 传输延迟 14 / 22 ns，t<sub>PHL</sub> 时钟到输出 17 / 26 ns，
> 主复位到输出 19 / 30 ns，t<sub>W</sub> 时钟或主复位脉宽 20 ns，
> t<sub>S</sub> 模式控制建立时间 30 ns，t<sub>S</sub> 数据建立时间 20 ns，
> t<sub>h</sub> 输入保持时间 0 ns，t<sub>rec</sub> 恢复时间 25 ns，f<sub>MAX</sub> 最大时钟频率 10 MHz。

## 二、建立/保持时间与上升下降时间（P.19–P.20）

### 2.1 真实波形为什么不是理想方波

数字时序信号由一系列"0""1"排列组合而成。课件用四个信号对比说明（P.19）：

| 信号 | 波形特征 | 影响 |
|---|---|---|
| a | 上升沿和下降沿陡峭笔直 | 可看成理想波形 |
| b | 边沿已有弧度 | 这个波形还是比较好的 |
| c | 上升到稳定过程中产生**过冲振铃**，需延时后才稳定 | 与理想信号差别较大 |
| d | 上升/下降沿坡度较缓 | 读写需要稳定的电平窗口；上升下降时间较长就必须**降低传输速率**才能保证正确读写 |

**根本原因**：实际电路除电阻元件外，还有**电容、电感元件、电路间或导线的寄生电容**，它们对信号波形产生较大影响，特别是波形的上升/下降边沿。

- **过阻尼**：波形永远不会达到理论上的高、低两个值；
- **欠阻尼**：波形在稳定下来之前会在高、低两个值附近震荡。

### 2.2 三个关键 AC 参数

> **上升建立时间（Setup Time）、下落下降时间（Fall Time）、数据保持时间（Hold Time）** —— 这三个参数表征**时钟边沿触发前后数据需要在锁存器输入持续的时间**。

- **建立时间 t<sub>su</sub>**：指触发器的时钟信号**有效沿（如上升沿）到来之前**，数据保持稳定不变的时间。
  输入信号应提前时钟上升沿 t 时间到达芯片。**若不满足建立时间，这个数据就不能在当前时钟周期输入触发器，只能在下一个时钟上升沿输入。**
- **上升时间 / 下降时间**：理想方波在高、低电平两个值之间瞬时变化，实际上由于波形产生系统的物理局限性，这种理想状态永远不可能实现。
  信号从低值上升到高值、再从高值下降所花费的时间分别称为上升时间和下降时间。
  **通常定义：上升时间 = 输出脉冲幅度 10% 上升到 90% 所需时间；下降时间 = 90% 下降到 10% 所需时间。**

### 2.3 与后续案例的关系

| 案例 | 涉及的 AC / 频率测试 |
|---|---|
| **LM358** | CMRR（65/80 dB）、PSRR（65/100 dB）、开环增益 A<sub>VD</sub>（15 V/mV）、T<sub>pd</sub> 类指标 |
| **HK32F031F4P6** | HSI 频率（8 MHz ±2%）、LSI 频率（20~40 kHz）、PLL 频率（20 MHz）—— 用 **TMU** 测频 |
| **ADC0832** | SNR、THD、SINAD、SFDR、ENOB —— 动态参数，需 AWG 输入正弦波 + DGT/DIO 采集 + FFT |
| **TPS73625** | PSRR（100 Hz / 10 kHz 两个频点）—— 需 AWG 叠加交流干扰 + DGT 采集 |

# 第二部分：功能测试（Functional Test）

## 三、测试向量（Pattern / Vector）的定义（P.22）

> **测试向量**也被称为**测试图形（Pattern）**，是一组按照某种模式排列的向量序列。
> Pattern 的**每一行**被称为**一行向量（Vector）**，由多行 Vector 组成一个测试 Pattern。

- **向量深度（Vector Depth）/ Pattern 存储容量**：指可以存储多少行 Vector。
- 在本课程的叙述中，**Pattern 与 Vector 意义相同**（除非有特殊说明）。
- **Pattern 的本质就是真值表（Truth Table）**，主要内容是**输入电平与期望输出电平的符号组合**，也包含用于实现某些复杂功能的**微指令（Micro Instruction）**。

## 四、Pattern 中的符号含义（P.23）—— 必背

| 符号 | 含义 |
|---|---|
| **0** | 输入低电平 |
| **1** | 输入高电平 |
| **Z** | 输入高阻态 |
| **H** | 输出高电平（期望） |
| **L** | 输出低电平（期望） |
| **M** | 输出高阻态（期望） |
| **V** | 输出有效状态，无论高低电平 |
| **X** | 不关心输出状态 |

> ⚠️ **不同 ATE 实际表示的意义可能稍有不同，具体含义应参考所使用 ATE 的编程手册。**

### 教材给的重要警告（MCU 课件 P.46，本课程最实用的忠告之一）

> **永远不要将 DUT 的输入引脚当作输出引脚进行功能测试。**
> 最常见的是在 Pattern 中，如果一个输入引脚在此测试项不需要去管（既给 0 或给 1 不影响结果），有人就给它"X"。而**"X"是输出测试的 mask 态** —— 这样测试机就会把此引脚**当作输出处理**，连接到比较电路（只是对结果不做比较）。记住：**在功能测试中，输入引脚不能直接测试期望得到 Pass/Fail 的结果；信号施加到输入引脚，我们需要测试的是输出引脚。**

> **永远不要将测试机的驱动单元连接到 DUT 的输出引脚。**
> 此举会造成测试机和器件本身在同一时间驱动电压和电流到该引脚，**当它们在某一点相遇时，电流小的一方会受到严重破坏**。

## 五、Pattern 数据的两种生成方式（P.24–P.26）

### 5.1 手工解读真值表（适用于功能简单的产品）

测试工程师通过**解读产品手册的真值表**来生成测试所需的 Pattern。

课件以移位寄存器 **74LS194** 为例：

| 运行模式 | MR | S1 | S0 | DSR | DSL | P0~3 | Q0 | Q1 | Q2 | Q3 |
|---|---|---|---|---|---|---|---|---|---|---|
| 复位 | L | X | X | X | X | X | L | L | L | L |
| 保持 | H | l | l | X | X | X | q0 | q1 | q2 | q3 |
| 左移 | H | h | l | X | l | X | q1 | q2 | q3 | L |
| 左移 | H | h | l | X | h | X | q1 | q2 | q3 | H |
| 右移 | H | l | h | l | X | X | L | q0 | q1 | q2 |
| 右移 | H | l | h | h | X | X | H | q0 | q1 | q2 |
| 并行加载 | H | h | h | X | X | P0~3 | P0 | P1 | P2 | P3 |

图例：`L` = 输入低电平；`H` = 输入高电平；`X` = 不关心；
`l` = 输入低电平，需要时钟上升沿之前产生；`h` = 输入高电平，需要时钟上升沿之前产生；
`Pn(qn)` = 输入/输出数据。

**通过解读真值表就可以得到测试 Pattern。**

### 5.2 由设计仿真文件转换（适用于复杂芯片）

随着数字电路复杂度增加，更多功能集成在一颗芯片上，**靠解读真值表生成 Pattern 已不再可行**。这时利用电路设计过程中的**仿真文件**，通过工具转化成 ATE 可识别的 Pattern 格式。

| 仿真文件格式 | 内容 | 转换难度 |
|---|---|---|
| **WGL** | 一般提供扫描（SCAN）测试向量，包含固定的时序 | 时序提取相对简单 |
| **STIL** | 同上 | 同上 |
| **VCD** | 功能测试通常以 VCD 格式提供 | **转换难易度很大程度上取决于所用 ATE 的结构和硬件限制，需要一定经验** |

转换工具一般由**第三方供应商**提供，或**每家 ATE 厂商提供转化自家测试机使用的工具**。

## 六、时序的四个基本概念（P.27–P.29）—— 必背

### 6.1 周期 Cycle

- ATE 运行 Pattern **以周期为单位**，Cycle 反映了 Pattern 运行的速度。
- **ATE 可以设置的最小周期是衡量 ATE 性能的一项重要指标。**
- 例：一台 ATE 的测试频率是 125 MHz，那么可以设置的最小 Cycle 是 **8 ns**。
- 测试过程中通常用 **T0** 表示一个周期。

### 6.2 沿 Edge

一个周期内**数据出现或改变的时刻点**，包括：
- **输入时间沿**（驱动沿）
- **比较时间沿**（采样/Strobe 沿）

也有部分 ATE 可以提供**跨 Cycle 的时间沿**。

### 6.3 波形格式 Format

按时序输入给 DUT 的 Pattern，直观上就是高低电平沿时间轴的变化，即通常意义上的**波形（Waveform）**。为提供符合 DUT 测试所需的波形，需要通过 ATE 定义输入信号的格式 Format：

| 格式 | 全称 | 含义 |
|---|---|---|
| **RZ** | Return to Zero | 归 0 |
| **RO** | Return to One | 归 1 |
| **NRZ** | None Return to Zero | 非归 0 |
| **SBC** | Surrounded by Complement | 补码环绕 |

另外某些 ATE 提供更灵活的方式供用户定义波形格式，如在时刻点自由定义信号的升降及其组合，通常称这种方式为 **Wave Table（波形表）**。

**Wave Table 的字段**（课件原文）：

| 字段 | 含义 |
|---|---|
| TimingName | 时序名称 |
| Period | 周期 |
| Signal | 信号名 |
| **WFC** | 用户定义符号（Wave Format Character） |
| Evtn Evnt | 沿 n 波形事件（驱动 D/U、比较 H/L/X 等） |
| Evtn Expr | 沿 n 时刻 |

> 本课程工程中的 `.tim` 文件就是这个 Wave Table 的落地形式。例如 CD4511 工程定义 **WFT1**：周期 10 µs，输入脚 WFC `0`→驱动低(D)、WFC `1`→驱动高(U)、边沿 0 µs；输出脚 `L`/`H`/`X` 在 **9 µs** 处比较。即**前半周期驱动输入，接近周期结束时对输出做期望电平比较**。

### 6.4 输出采样 Strobe

在**固定的时刻点**对输出电平采样比较，根据预先设定的 **VOL / VOH 电平**来判断输出信号的高低。有两种方式：

| 方式 | 说明 |
|---|---|
| **Edge Strobe** | 单点采样比较 |
| **Window Strobe** | 窗口采样比较 |

## 七、功能测试的完整准备链条（P.30–P.32）—— 工程落地总结

> **在功能测试中，仅使用 Pattern 往往是不够的。因为 Pattern 中只包含输入输出的状态，要把 Pattern 数据变成电路测试所需的输入信号，并在相应的时刻点采集输出信号，就必须配合时序信息。**

完整链条如下：

```
① Pattern（向量）        —— 输入什么 0/1，期望输出什么 H/L/X
        ＋
② Timing（时序）          —— 周期 T0 多长、驱动沿在哪、比较沿在哪、波形格式是什么
        ＋
③ Pin Level（引脚电平）   —— 什么样的电压算 0（VIL）、算 1（VIH）；
                              期望输出的判据电平 VOL / VOH；
                              输入/输出电流 IOL / IOH；
                              电源电压 VDD
        ↓
④ 运行 Pattern → 实际输出与期望输出比较 → Pass / Fail
```

**引脚电平（Pin Level）的设定依据**（P.31）：
> Pattern 及 Timing 确定之后，我们还需要设定什么样的电平表示 0，什么样的电平表示 1。这就涉及输入电平 VIL/VIH、输出电平 VOL/VOH、输入电流 IOL/IOH 等参数的设定。同时，为了使 DUT 可以正常工作，还必须对其电源引脚供电，需要定义供电电压。**关于这部分的设定，可以参照 Datasheet 中关于 DC 参数的部分。**

### 课件给出的 74LS194 电平设定范例（P.32）

**DC 参数表（Datasheet）**：

| 符号 | 参数描述 | 最小值 | 典型值 | 最大值 | 单位 |
|---|---|---|---|---|---|

| TA | 运行环境温度 | 0 | 25 | 70 | °C |

## 九、本章速记

1. **AC 三参数**：传输延时 Tpd（取 50% 点、正反跳变取平均）、建立/保持时间、上升/下降时间（10%–90%）。
2. **Pattern 的本质是真值表**；一行 = 一个 Vector；深度 = 能存多少行。
3. **符号表必背**：0/1/Z 是输入，H/L/M/V/X 是期望输出，**X 是输出 mask 态，不能乱用在输入脚**。
4. **复杂芯片的 Pattern 来自 WGL/STIL/VCD 转换**，不是手工编。
5. **时序四概念**：Cycle（周期，T0）、Edge（沿）、Format（RZ/RO/NRZ/SBC 或 Wave Table）、Strobe（单点 Edge / 窗口 Window）。
6. **功能测试三件套**：Pattern（输入输出状态）＋ Timing（时间）＋ Pin Level（电压/电流），缺一不可。
7. **Pin Level 从 Datasheet 的 DC 参数表抄**。
