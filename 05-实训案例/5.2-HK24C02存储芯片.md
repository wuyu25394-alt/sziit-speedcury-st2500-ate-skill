## 一、器件认识

### 1.1 EEPROM 是什么

> **EEPROM**（Electrically Erasable Programmable Read Only Memory，带电可擦可编程只读存储器）是一种**掉电后数据不丢失**的芯片。（课件 P.4）

### 1.2 HK24C02 概述（课件 P.5）

- **2048 bit** 串行电可擦除可编程只读存储器；
- 编为 **256 个字节（Byte）**，每 Byte 占 **8 位（bit）**；
- **8 脚 DIP、8 脚 SOP** 等封装形式；
- **标准 2 线串行接口**处理所有读写功能；
- 扩展了 **VCC 范围：1.8 V 至 5.5 V**。

### 1.3 引脚说明（课件 P.6）

| 引脚 | 功能 |
|---|---|
| **VCC / GND** | 芯片供电端与接地端 |
| **SCL** | I²C 时钟输入端 |
| **SDA** | I²C 信号输入输出端 |
| A0 / A1 / A2 | 器件地址识别位（片选） |
| WP | 写保护 |

> ⚠️ 课件只讲了 VCC/GND/SCL/SDA 四个功能；完整引脚号与 A0~A2、WP 的定义见数据手册（第 3 页，图片页）。

### 1.4 数据手册关键规格（来自图片识读）

| 参数 | 值 |
|---|---|
| 容量组织 | **2 Kbit = 256 × 8**，**32 页 × 8 字节**（页写缓存 8 字节） |
| VCC 范围 | 1.8 V ~ 5.5 V |
| **ISB**（待机电流） | **Typ 10 nA / Max < 100 nA** ← 全组最严苛的限值 |
| 读电流 | 200 µA |
| 写电流 | 300 µA |
| **tWR**（写周期时间） | **< 5 ms（A 等级）/ < 8 ms（B 等级）** |
| ISB1 / ISB2 / ISB3 | ≤ 0.1 µA |
| VOL1 / VOL2 | ≤ 0.2 V @1.8V/0.15mA；≤ 0.4 V @3.0V/2.1mA |
| 器件地址 | **1010 + A2 A1 A0 + R/W** |
| AC 特性 | 手册只给 **1.8 V / 2.5 V 两档**（fSCL、tLOW、tHIGH、tAA、tBUF、tSU.DAT 等） |

> ⚠️ **手册规格缺口**：首页 FEATURES 声称 5 V 时可达 **1 MHz**，但 AC 特性表**没有 5 V 档的 tLOW/tHIGH 限值**，**不可从 2.5 V 档外推**。这是本案例最需要注意的"手册不完整"之处。

## 二、I²C 协议要点（课件 P.7–P.12）

### 2.1 I²C 总线

> I²C 是一种**同步通信**，以**半双工**方式传送的串行总线。由数据线 **SDA** 和时钟线 **SCL** 构成，可发送和接收数据。在 CPU 与被控 IC 之间、IC 与 IC 之间进行双向传送，**高速 I²C 总线一般可达 400 kbps 以上**。

### 2.2 控制字节（传输控制字节的位定义，P.8）

```
 S | 1 0 1 0 | A2 A1 A0 | R/W | ACK
 ↑     ↑          ↑        ↑     ↑
 起始  控制码   片选位    读写   应答位
```

| 位段 | 含义 |
|---|---|
| **S（Start）** | 开始传输指示 |
| **Control Code** | 所有 I²C 接口 EEPROM 统一的控制码，4 位组成 **"1010"** |
| **Chip Select Bits** | EEPROM 地址识别位，3 位组成 **A[2:0]**，分别对应器件引脚 A[2:0] 的输入电平。当 I²C 总线上挂接多片 EEPROM 时由此做片选。**有的 EEPROM A[2:0] 未用或只用 1~2 个，那么多余的位可用来做 EEPROM 内部存储 Block 选择** |
| **R/W** | 读写标识，**"1" 为读；"0" 为写** |
| **ACK** | 从机应答/响应位，用于指示通讯是否成功 |

### 2.3 四种操作时序

| 操作 | 时序要点 |
|---|---|
| **字节写**（P.9） | ① 主机发 Start + 控制字节 → ② EEPROM 应答 ACK → ③ 主机发送要写入的**存储单元地址** → ④ EEPROM 应答 ACK → ⑤ 主机发送**数据** → ⑥ EEPROM 应答 ACK → ⑦ 主机发 **Stop**，结束 |
| **按页写**（P.10） | 与字节写相似，**不同之处**：主机写完 1 个字节后**不发 Stop**，继续发送数据，**直到写满 EEPROM 的页写缓存（Page Write Buffer）**。内部有**地址循环计数器**，每写 1 字节地址加 1；当地址加到当前 Page 上界时**回到当前 Page 的下界** |
| **随机读**（P.11） | ① 主机先发**写操作命令**并发送地址（随机地址 Random Address）→ ② 主机**重新发送开始指令（Re-start）**结束写操作，再发送包含**读命令**的控制字节 → ③ 主机接收 1 字节后收到**无效响应 NACK**，并发送 Stop 结束。**注意：这里的 NACK 是协议规定的正常操作**，用于表示读取结束，而不是从机无响应或操作出错 |
| **连续读**（P.12） | 与随机读类似，**不同之处**：主机接收到 1 字节后**不发 Stop**，而是**继续发送 Acknowledge Bit**，继续接收。每读 1 次地址计数器加 1；同样是循环计数，**读操作的地址计数边界为整片 EEPROM 地址边界**（不同于 Page Write 的 Page 边界），因此**连续读方式可以读完整片 EEPROM** |

> **易混点**：Page Write 的地址循环边界 = **当前 Page**；连续读的地址循环边界 = **整片 EEPROM**。

## 三、硬件资源与通道分配

### 3.1 DUT 板原理图要点（课件 P.22）

- **VCC 分配 DIO 的 PPMU 来提供电源电压**，并**连接去耦电容**以增加电源稳定性；
- **SDA 与 SCL 分配数字 DIO 通道**，同时**通过上拉电阻与 VCC 相连**。

## 四、测试项与实施

### 4.1 开短路（OS）测试计划（P.23）

```
① 电源 VCC 由 PPMU 供电 0 V，SCL 与 SDA 施加 0 V
② 对 SCL 加载 +100 µA，量测电压，完毕后施加 0 V
③ 对 SDA 加载 +100 µA，量测电压，完毕后施加 0 V
④ 对 SCL 加载 −100 µA，量测电压，完毕后施加 0 V
⑤ 对 SDA 加载 −100 µA，量测电压，完毕后施加 0 V
```

**测试要求**：
- 给**正**电流：**0.2 V < Vos < 1.5 V**
- 给**负**电流：**−1.5 V < Vos < −0.2 V**

> 注意这里的限值（±1.5 V）比 CD4511（±0.8 V）**宽得多**。

### 4.2 漏电流（Leakage）测试计划（P.26）

```
① VCC 输入电压 5.5 V
② SCL 与 SDA 输入 5.5 V 并量测电流
③ SCL 与 SDA 输入 0 V 并量测电流
```

**测试要求**：量测电流范围应为 **−1.5 µA < I < 1.5 µA**。

### 4.3 存储功能测试（ROM / Function Test，P.19–P.20、P.28）

**原理（P.19）**：HK24C02 容量 2 K，因此有 **11 位地址位**，最小地址 `00000000000`，最大地址 `11111111111`。每个确定地址对应一个存储单元，需要验证所有存储单元的读写功能。

读写验证方式：**写全"0"读全"0"、写全"1"读全"1"、棋盘格（Check Board, CKBD）** 等，具体选择**根据客户要求以及测试时间**而定。

**Function 测试步骤（P.28）**：
```
① VCC 输入电压 5 V
② 通过 I²C 协议向所有的 Cell 里写入 logic 0
③ 通过 I²C 协议读取所有 Cell 里的 logic 0
④ 向所有的 Cell 里写入 Logic 1
⑤ 读取 Cell 里的 Logic 1
⑥ 往 Cell 里写入 0x55AA
⑦ 读取所有 Cell 里的 0x55AA
```

**向量实现（P.20）**：
- 通过 I²C 协议建立**写入向量（0x55）**；
- **HK24C02 芯片比较特殊：在进行 ROM 测试之前需要发送命令进入测试模式**；
- 电源上电之后，以向量的方式将对应的电信号送入芯片对应引脚进行存储单元写入；
- 写入之后再进行读操作（0x55）；
- **将这两个向量先后送入芯片并且其中的 H、L 比较全部通过，就说明对应地址 `00000000000` 读写 0x55 是正常的**。

### 4.4 工程实测测试项（5 项）

| # | 测试项 | 说明 |
|---|---|---|
| 1 | OS | VCC 由 PPMU 供 0 V，对 SCL/SDA 加 ±100 µA |
| 2 | Leakage | VCC=5.5 V，测 SCL/SDA 电流 ±1.5 µA |
| 3 | 存储功能 | I²C Pattern：全 0 / 全 1 / 0x55AA 读写验证 |
| 4 | standby 电流 | **100 次软件平均**（应对 nA 级小电流的测量噪声） |
| 5 | 其他 DC | — |

**Pattern 数量**：3 个（最长 `TM_RD_55AA_2K` **2375 行**）。
**CBIT**：用于**上拉电阻的物理投切**（关键，见下）。

## 五、测试总结（课件 P.33，本案例最有价值的三条工程经验）

### 5.1 上拉电阻与 DC 测试的矛盾 —— 用继电器解决

> **因为 I²C 管脚 SDA 本身没有输出高电平的能力，所以测试时需要通过电阻上拉，但接入上拉电阻后，会影响到开短路及漏电流的测试。通过继电器物理断开或连接上拉即可满足功能测试需求，也可以满足 DC 的测试需求。**

**解读**：
- **功能测试时**：需要上拉（否则 SDA 无法拉高，I²C 通信失败）；
- **OS 和漏电流测试时**：上拉电阻会提供一条到 VCC 的低阻通路，使测得的"漏电流"变成"上拉电流"，测试完全失效；
- **解法**：用 **CBIT 控制的继电器**在两种状态间物理切换。

> 这是本课程**最能体现"硬件设计与测试方案相互制约"**的一个例子。

### 5.2 用 DIO 的 PPMU 替代 DPS 供电

> **这里我们使用了 DIO 的 PPMU 替代 DPS 给芯片供电，在一些电源电流消耗不大的情况下是提高并测数的一种方式。**

**解读**：DPS 通道数有限（4 通道/板），而 DIO 通道多（32/板）。对功耗小的芯片用 DIO 的 PPMU 供电，可以**释放 DPS 通道、提高单机台并测颗数**，从而降低测试成本。

### 5.3 去耦电容对 DC 测试稳定时间的影响

> **因为 VDD 管脚上连接了电容，当容值较大，超过 1 µF 时，其充放电效应会影响 DC 测试的稳定时间，当结果不稳定时，可适当增加等待时间达到测试稳定的效果。**

**解读**：这是"延时量级"选择的依据 —— 大电容需要更长的稳定等待（工程中对应 15~30 ms 档的延时）。

## 六、教学重点与易错点

### 6.1 教学重点

1. **从"纯 DC"进入"协议测试"**：第一次需要理解通信协议（I²C 控制字节、ACK/NACK、Page Write 地址回绕）。
2. **Pattern 从 3 行跳到 2375 行**：体会"功能向量是真的要一行一行写出来"的规模感。
3. **存储测试的通用方法**：全 0 / 全 1 / 0x55AA / 棋盘格 —— 这套方法适用于任何存储器（SRAM、DRAM、Flash）。
4. **测试模式（Test Mode）概念首次出现**：HK24C02 需要发命令进测试模式才能做 ROM 测试（与 MCU 案例的 PassCode 是同一思想）。
5. **继电器（CBIT）的必要性**：上拉电阻必须能物理投切。

### 6.2 易错点

| # | 易错点 | 说明 |
|---|---|---|
| 1 | **忘记切上拉电阻就测漏电流** | 会测到上拉电流而不是漏电流，结果必然 Fail 或全是假数据 |
| 2 | **把随机读的 NACK 当错误** | NACK 是协议规定的"读取结束"标志，不是从机无响应 |
| 3 | **混淆 Page Write 与连续读的地址边界** | Page Write 上界回到**当前 Page 下界**；连续读回到**整片地址边界** |
| 4 | **tWR 未等待就发下一个命令** | 写周期 tWR 最长 **8 ms（B 等级）**，等待不足会导致写失败 |
| 5 | **测量 nA 级待机电流** | 手册 ISB Max < 100 nA，必须用软件多次平均（工程用 **100 次**） |
| 6 | **拿 2.5 V 的 AC 限值套 5 V** | 手册 AC 表**没有 5 V 档**，不能外推 |
| 7 | **复习时只读 txt 提取稿** | 该数据手册是**扫描版图片 PDF**，文字层几乎是空的，必须渲染识读 |
