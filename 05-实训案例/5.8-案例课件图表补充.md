VOH的测试步骤：

1. 给 dut 电源引脚施加 VDDmin，这样是为了让 VOH 在最严厉的条件下仍然能满足要求；
2. 执行预置的状态向量，使得被测引脚输出逻辑 1；
3. PMU（为 ATE 测试机台的测试通道）施加测试条件中的驱动电流 IOH（在设计 IO 时调用的 IO 的驱动能力，4mA 或者 8mA 等），IOH 为负，即从待测电路流向 ATE；
4. PMU（为 ATE 测试机台的测试通道）测量 VOH 电压；
5. 判断输出电压是否符合设定的 limit 值；

### 课件12 测试案例-数模混合芯片 ADC0832

#### P08
**标题：ADC芯片介绍—ADC芯片典型应用**（按信号带宽/转换频率分类的 5 类典型应用框）

1. 超低的信号带宽：转换频率很低，时间上变化很慢的信号，如应用于高精度的体重计、温度计等测量仪器，ADC 精度需求通常在 20bit 以上。
2. 低信号带宽：转换频率低，带宽 100Hz 或者更小的信号，如应用于生物信号的测量，精度在 8bit–18bit 左右。
3. 音频带宽：转换人耳可以听到的 20Hz–20KHz 的声音信号，如应用于耳机、Hi-Fi 上面，精度在 8bit–18bit 左右。
4. 视频和图像带宽：ADC 在成像中应用除了电视、相机等消费类电子，也包括医疗电子，如 X 射线、超声波、核磁共振等。
5. 通信带宽：模拟信号带宽要求越来越大，但转换精度要求基本保持不变。显而易见，这两个部分对于 ADC 芯片的设计要求越来越高。5G 通信下，手机终端需要 160+MSPS、12bit 的 ADC 芯片，基站里面需要 250MSPS–1GSPS、14–16bit 的 ADC 芯片。

#### P24
**标题：动态特征参数介绍—信噪比 SNR**

- 示意图（虚线框内公式图）：`Noise`（噪波波形） + `Signal`（正弦波） = `Noisy Signal`（叠加噪波的正弦波）。
- 正文：信噪比（SNR）的计算公式为：

**Calculation**（文本框内）

- N = Number of Sampled Data；M = Number of Cycles of the Test Signal
- `Signal Power = V_[M]^2`
- `Noise Power = V_[1]^2 + V_[2]^2 + … + V_[M-1]^2 + V_[M+1]^2 + … + V_[N-2]^2`
- `Harmonics Power = V_[2*M]^2 + V_[3*M]^2 + V_[4*M]^2 + …`
- `SNR = 10 * log [ Signal Power / (Noise Power - Harmonics Power) ]`

#### P26
**标题：动态特征参数介绍—总谐波失真 THD**

- 框图（流程）：输入正弦波 → 「模/数转换」方框 → 「快速傅里叶变换」方框 → 频谱图（横轴标注 `X`、`2X`、`3X`、`4X`、`5X`；`X` 处为主信号谱线，`2X`/`3X`/`4X`/`5X` 处为谐波谱线，上方括号标注「谐波失真」）。
- 正文：总谐波失真的计算公式为：

**公式（文本框内）**

- `THD = 10 * log [ Harmonics Power / Signal Power ]`
- `THD[dB] = 10 × log [ (H_2^2 + H_3^2 + H_4^2 + H_5^2 + …) / S^2 ]`
- `THD[%] = sqrt(H_2^2 + H_3^2 + H_4^2 + H_5^2 + …) / S × 100`

### 3. 实验方法学上的共性（课件 7~12 一致）

1. **固定三件套**：每个案例都从 `SetErrorBin` 起、`SetPassBin` 止，中间插入真测试项；Sbin/Hbin 分层用于失败分类。
2. **开发流程**：新建 Project → 建 Sig（信号映射，AFEType/ChType/Site0_CH）→ 建 Grp（分组）→ 建 Tim/Pat（时序与向量，纯直流项可省）→ 编 Tmf（测试流程与限值）→ `Test.cpp` 写测试程序。
3. **开短路配方**：电源拉 0 V，PPMU/DIO 以 FIMV 灌/抽电流（CD4511、HK32 用 ±100 µA 量级并测 ±(0.2~1.2) V；HK24C02 用 −100 µA / −300 µA；ADC0832 用 ±200 µA），限值多为 −1.5/−1.2 ~ −0.2 V 与 0.2 ~ 1.2 V。
4. **参数项测量方式**：VOH/VOL 用 PMU 加/灌电流后测压；VOPU/VOPD、IIL/IIH 类用电流档（uA）测量；频率类（HSI/PLL/LSI）由 TMU 计数给出 MHz/KHz；动态 ADC 项由 AWG 激励 + DGT 采集后在代码内做 FFT 计算。
5. **课件的「调试与总结」页**统一给出 DUT 板实物 + 上位机 Datalog 截图，用于对照限值与实测。
