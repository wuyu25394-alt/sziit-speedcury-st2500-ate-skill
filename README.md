## 一、先看这里：SMU 是什么

> 这是本课程第一个容易被问到的概念，先给结论。

**SMU = Source Measure Unit，中文叫「源测量单元」，业内俗称「源表」。**

在本课程 / ST2500 平台里，它有两层含义：

**① 通用本义**：一种把「**精密源**」（可强制电压或电流）与「**精密测量**」（可测电压或电流）集成在同一通道的仪器单元。本课程所有直流参数测试（OS、IIL/IIH、VOH/VOL、IDD/IGND）在仪器层面都是「用 SMU 干活」。

**② 本平台的具体资源**：它是 `.sig` 文件 `AFEType` 里的一类板卡资源，也是本平台 5 种电源资源（DPS / BPMU / PPMU / RVS / **SMU**）中**规格最高、功能最全**的一种：

| 项目 | SMU 规格 |
|---|---|
| 全称 | **Source Measure Unit**（源测量单元 / 源表） |
| 板卡型号 | **SMU20**（独立电源板卡，与 DFB32、MWB8 并列） |
| 通道数 | **4**（SMU0 ~ SMU3） |
| **电压** | **1 V / 5 V / 10 V / 20 V 四档，最大 20 V**（全平台最高 → 手册称"高压电源模块"） |
| **电流** | **±500 mA；Gang 模式最大 2 A** |
| **电压精度** | **±(0.05%+0.5 mV) ~ ±(0.05%+10 mV)**（全平台最好） |
| **电流档位** | **7 档：1 µA、10 µA、100 µA、1 mA、10 mA、100 mA、500 mA** |
| 连接方式 | 4 线 |
| **最本质特征** | **DPS 只能 Force Voltage（不支持 FIMV/FIMI），而 SMU 五种模式全支持，且是全平台唯一支持 `FVMIMV` / `FIMVMI` 混合模式的资源** —— 这才是它叫 "Source **Measure** Unit" 而不是 "Power Supply" 的原因 |
| 变体 | `SMU`、`SMU_GANG2`、`SMU_GANG3`、`SMU_GANG4`（多通道并联） |
| 本课程实训用了吗 | **6 个实训工程全部未使用**（教学机配置的是 DFB32 业务板；SMU 属扩展板卡） |

📖 **完整详解（含 5 种电源资源的逐格规格对比表、模式支持矩阵）** → [1.4 术语速查表 第 8 节](01-理论基础/1.4-术语速查表（含SMU详解）.md)

> 💡 **整理过程中的一个教训**：使用手册里 SMU 只出现 5 处、且**只有一句定义、没有任何电气指标**；完整规格其实藏在**教学课件《5课件-电源模块功能介绍》P09 的一张图片表**里。**同一门课的不同资料必须交叉对照**，而且要意识到"PDF 提取不到内容"往往是因为那一页是图片。

| 步骤 | 工具 | 规模 |

| 中文文档读取 | `python-docx` | 1 份 DOCX |

**可信度分级**（详见 [6.1 的"数据来源与可信度说明"](06-芯片数据手册/6.1-六款芯片关键参数.md) 与 [4.1 第 4 节](04-实训平台与硬件接线/4.1-实训平台与通用接口板使用指南.md)）：

- ✅ **有明确出处**：标注了手册页码 / 课件页码 / 工程文件名，可回溯核对。
- ⚠️ **图片识读**：由渲染图识读得到，标注了"（图不清，疑为…）"的地方请以原文件为准。
- ❗ **口径冲突**：同一数据在不同资料中不一致时，**已全部列出并标注**，未擅自择一。已知冲突见 [7.2 第四、五节](07-实战与自测/7.2-常见问题与踩坑清单.md) 与 [5.0 第 6.2 节](05-实训案例/5.0-六案例总览与横向对比.md)：
  - **课件限值 vs 工程 `.tmf` 限值多处不一致**（CD4511 的 OS / VOH / IIL；TPS73625 的 OS）
  - **ADC0832 的 ENOB：课件写 12~16 bit，工程写 7~8 bit** —— 8 位 ADC 物理上限就是 8 bit，**课件明显是模板沿用未改**
  - CD4511 课件引脚表 vs 文字（6=BI/7=LT 还是 4=BI/3=LT）
  - HK32F031F4P6 的 VIH/VIL 两套规格（0.9·VDD 还是线性公式，3.3 V 下差 2.97 V vs 1.546 V）
  - HK24C02 缺少 5 V 档 AC 规格
  - 开机顺序两套手册口径不同
  - TMU 通道数两课件冲突（4 ch vs 32 ch）
  - TPS73625 / ADC0832 / HK32F031F4P6 工程中的代码 bug（量纲不匹配、漏 `.Execute()`、参数数不匹配、空结果向量）
  - 原页用字与大小写混用（"箱位"/"箝位"、`Setmode`/`SetMode`、P15 归零用 FVMI 而非 FIMV）

## 六、一句话总结这门课

> 这门课教的是**怎样把一颗芯片的 Datasheet 参数，变成一套跑在 ATE 上的测试程序**：
> **读 Datasheet → 定测试计划 → 分配测试机资源（`.sig`/`.grp`/`.res`）→ 写时序与向量（`.tim`/`.pat`）→ 定顺序与限值（`.tmf`）→ 用 Force/Measure 模式写测试函数（`Test.cpp`）→ 编译加载运行看 Log → 按 Bin 分选。**
>
> 六个实训案例就是这套流程在**数字逻辑、存储、模拟、电源管理、MCU、数模混合**六类芯片上的完整演练。
