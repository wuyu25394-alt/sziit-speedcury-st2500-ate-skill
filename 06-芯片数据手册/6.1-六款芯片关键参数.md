## 1. CD4511BE —— CMOS BCD-to-7 段锁存译码驱动器

### 1.1 器件概述

| 项目 | 内容 |
|---|---|
| 器件类别 | 数字逻辑 —— BCD 到 7 段码锁存/译码/驱动器 |
| 制造工艺 | CMOS 逻辑 + n-p-n 双极型输出晶体管（单片结构） |
| 高压类型 | High-Voltage Types，**20V 额定** |
| 核心功能 | 把 4 位 BCD 码锁存并译码为 7 段显示驱动信号 a～g |
| 输出能力 | 高电平拉电流（high-output-sourcing）**最大 25 mA**，可直接驱动 LED |
| 辅助输入 | LT（Lamp Test）、BL（Blanking）、LE/STROBE（Latch Enable/Strobe） |
| 典型应用 | 驱动共阴极 LED 数码管；共阴极 LED 显示的多路复用；驱动白炽灯显示；驱动低压荧光显示 |
| 封装 | 16 引脚：DIP（E 后缀）、SOIC（NSR）、TSSOP（PW/PWR）、陶瓷 DIP（F3A） |
| 相似型号 | MC14511 |

## 2. ADC0832 —— 8 位串行 I/O A/D 转换器（2 通道）

> 手册覆盖 ADC0831-N / **ADC0832-N** / ADC0834-N / ADC0838-N 系列，本笔记聚焦 **ADC0832-N（2 通道 MUX，8 脚）**，同时给出共用规格。

### 2.1 器件概述

| 项目 | 内容 |
|---|---|
| 器件类别 | 数模混合 —— 8 位逐次逼近型（SAR）A/D 转换器，串行 I/O |
| 分辨率 | **8 Bits** |
| 通道 | ADC0832-N：**2 通道单端 / 1 通道差分**，8 脚封装 |
| 总未调整误差 | ADC0832-N：**±1 LSB** |
| 电源 | 单电源 **5 VDC**（工作范围 4.5 ～ 6.3 VDC） |
| 功耗 | **低功耗 15 mW** |
| 转换时间 | **32 µs** |
| 接口 | TI MICROWIRE 兼容，可直接接 COPS 系列处理器；也可接通用移位寄存器或 µP |
| 输入范围 | 0V ～ 5V（单 5V 供电） |
| 特点 | 无需零点/满量程调整；可比例式（ratiometric）或 5V 基准工作；TTL/MOS 输入输出兼容；内置分流稳压器 |

**（d）输出数据格式与转换时序**

| 项目 | 说明 |
|---|---|
| 启动 | CS 拉低启动一次转换，CS 必须**全程保持低** |
| 起始位 | DI 上第一个逻辑 "1" 为 start bit（前导 0 被忽略） |
| MUX 地址 | start bit 之后输入 2～4 位 MUX 分配字（ADC0832-N 为 SGL/DIF + ODD/SIGN） |
| 通道建立 | MUX 选定后自动插入 **½ 个时钟周期**空档让通道建立；SAR 状态线拉高表示转换开始，DI 被禁止 |
| 数据输出 | DO 从三态（TRI-STATE）脱离，在 MUX 建立期先输出 1 个前导 0 |
| 转换 | 转换开始时，比较器结果在**每个时钟下降沿**出现在 DO 上，**MSB 先出（MSB first）** |
| 完成 | 8 个时钟周期后转换完成，SAR 状态线在 ½ 时钟周期后回低 |
| LSB first | 全部 8 位结果存入输出移位寄存器；无 SE 控制线的器件在 MSB first 数据流后自动输出 LSB first 数据流；之后 DO 拉低并保持到 CS 回高 |
| 寄存器清除 | CS 为高时所有内部寄存器被清除；若要再次转换，CS 必须再次产生高→低跳变并跟随地址信息 |
| DI/DO 共线 | DI 与 DO 可并联，用处理器一根双向 I/O 线控制（因 DI 仅在 MUX 寻址期间被采样，此时 DO 仍为高阻） |

**（e）基准与输入范围**

- 基准输入端需由能驱动**典型 3.5 kΩ** 基准输入电阻的电压源驱动。
- 1 LSB = VREF/256；VREF = 5.000 VDC 时 **½ LSB = 9.8 mV**。
- 模拟输入可在**低于地 50 mV ～ 高于 VCC 50 mV** 范围内而不降低转换精度。要获得绝对 0～5 VDC 输入范围，需最小供电 **4.950 VDC**。
- 零点误差：VIN(−) 接地，向 VIN(+) 加小幅正电压，零点误差 = 使输出从 0000 0000 变为 0000 0001 的实际 DC 输入电压与理想 ½ LSB 之差。
- 满量程调整：加比目标满量程低 1½ LSB 的差分输入，调 VREF 使输出刚好从 1111 1110 变到 1111 1111。

**特别注意事项**
1. **ADC0832-N 的 VREF 与 COM 内部已连到 VCC / GND**，因此外部无 VREF/COM 引脚，基准不能外调；比例式应用直接以 VCC 为基准。
2. 低 VCC（4.5V）测试时，若模拟输入为 5V 会使输入二极管正偏导通而**引起满量程附近的转换误差**（尤其高温下）。规格允许任一二极管正偏 50 mV。测试程序在低 VCC 条件下应避免加超过 VCC+50 mV 的输入。
3. 时钟占空比必须保证 40%～60%；若时钟源超出该范围，最低高/低电平时间须 ≥ 1 µs、最高高电平时间 ≤ 60 µs。
4. 输入源电阻 > 1 kΩ 时**不应使用旁路电容**（会与 MUX ±1 µA 漏电产生 DC 误差：1 kΩ × 1 µA = 1 mV）。
5. tSET-UP（250 ns）/ tHOLD（90 ns）相对较慢，但 tpd 最大 1500 ns 已接近普通数字通道比较沿的能力，建议用 DC 参数与输出码验证替代高速时序测试，或单独建立时序测试板。

**特别注意事项**
1. **TPS73625 是固定 2.5V 版本，没有 FB 引脚（该脚为 NR）**，因此 VFB 与 IFB 测试项不适用；NR 脚需接降噪电容（典型 0.01 µF）以降低噪声。
2. **"无电容稳定"是本器件卖点**，但电气特性表的默认条件是 **COUT = 0.1 µF**。ATE 测试板必须按此配置，否则负载瞬态与稳定性表现与手册不符。
3. **IGND 有"传统器件"与"新器件"两套规格**（@IOUT=10mA 为 550 µA vs 630 µA）。程序必须明确被测批次属于哪一类，否则会误判。
4. **µA 与亚 µA 级电流项（ISHDN、IEN、IREV）是主要测试难点**：需要高输入阻抗的电流测量单元（PMU）、低漏电继电器，并注意 DUT 板清洗与保护环（guard ring）。
5. **瞬态大电流项（ICL、ISC）与热关断**：ISC 典型 450 mA、ICL 最高 800 mA，测试时间必须严格限制并监控结温，否则会触发热关断（160°C）导致误判或损伤。
6. **VDO 测试的前提**：VIN 必须能降到 VOUT(nom) − 0.1V = 2.4V，同时由 ATE 精确测量 VOUT 跌落 100 mV 点；测试机的 VIN 源精度与量程切换点很关键。

### 6.7 真值表 / 功能表

#### 6.7.1 器件地址（DEVICE ADDRESSING）

I²C 总线协议要求 START 位之后发送 **8 位器件地址字**：

| 位序 | 位含义 | 取值 |
|---|---|---|
| bit7～bit4 | 器件类型标识 | **必须以 1010 开头**（common to all serial EEPROM devices） |
| bit6～bit4 | 器件地址位（device address bits） | 对**本 4-PIN EEPROM 产品无器件寻址信息，bit5/6/7 为 don't care** |
| **bit0（第 8 位）** | **read/write command bit** | **为 VIH（1）→ 芯片进入读模式**；**为 "0" → 器件进入编程（写）模式** |

> 即器件地址字为 **1010 x x x R/W**，其中 bit3～bit1 为 don't care。手册原文表述为"The next three bits are device address bits. But for this 4-PIN EEPROM product, there is no device addressing information, so we don't care the bit5/6/7."
> **注意**：手册文字称"4-PIN EEPROM product"，但本手册给出的是 8-pin 与 5-pin 封装。此处疑为厂商沿用同系列文档的措辞。

#### 6.7.2 读写操作时序表

| 操作 | 时序构成 | 图示 |
|---|---|---|
| **Byte Write（字节写）** | START → Device Address（含 W=0）→ **Word Address（8 位）** → DATA（8 位）→ STOP | Figure 3 / Figure 4 前段 |
| **Page Write（页写）** | START → Device Address（W=0）→ Word Address → DATA(0) → DATA(1) … → 最多共 **8 个字节** → STOP | Figure 4 |
| **Current Address Read（当前地址读）** | START → Device Address（R=1）→ DATA（8 位）→ 第 18 个时钟不发 ACK → STOP | Figure 5 |
| **Sequential Read（顺序读）** | START → Device Address（R=1）→ DATA → ACK → DATA → ACK → …（内部地址计数器自动 +1，到最大地址后**回卷**到存储阵列起始）→ 最后不 ACK + STOP | Figure 6 |
| **Random Read（随机读）** | 第一步"dummy write"：START → Device Address（W=0）→ Word Address（ACK）；第二步：START → Device Address（R=1）→ DATA(N) → STOP | Figure 7 |

**关键时序规则**

| 项目 | 规则 |
|---|---|
| SCL 与数据跳变 | SDA 通常由外部电阻上拉为高。**数据只允许在 SCL 为 VIL 时改变** |
| START | SCL 为 VIH 时，**SDA 由高→低**跳变 = START。所有合法命令必须以 START 开始 |
| STOP | SCL 为 VIH 时，**SDA 由低→高**跳变 = STOP。所有合法读/写命令以 STOP 结束 |
| ACKNOWLEDGE | 2-wire 协议按 8 位字收发地址与数据。EEPROM 每收到一个字后通过输出 **"0"** 应答。**ACK 信号出现在每个字之后的第 9 个串行时钟** |
| 写周期内 | 内部定时写周期内所有输入被禁止，EEPROM 在写完成前不响应 |
| 页写地址递增 | Word Address 的**低 5 位**在每收到一个数据字后内部递增；**高地址位不递增**，保持存储页行位置。若发送超过 8 个数据字，地址将**回卷（roll over）**并覆盖先前数据 |
| ACK Polling | 在自定时内部编程期间可轮询编程状态：若器件仍在编程模式，第 9 个时钟周期不应答；若编程完成且芯片回到 STANDBY 模式，则返回有效 ACKNOWLEDGE |
| STANDBY 进入时机 | 上电后、读模式下收到 STOP 位后、或完成自定时内部编程操作后，EEPROM 进入低功耗 STANDBY 模式 |

| **时序参数** | tLOW、tHIGH、tAA、tBUF、tHD.STA、tSU.STA、tSU.DAT、tSU.STO、tDH、tR、tF、ti | 见 6.6 节表；测量条件 **RL = 1.3 kΩ 接 VCC、输入脉冲 0.3VCC～0.7VCC、参考电平 0.5VCC** | **AC 测量条件必须严格复现**（RL=1.3 kΩ 是关键）；标 (1) 的参数（ti、tBUF、tR、tF）仅由特性保证，可降低测试强度 |
| **功能测试（读写）** | Byte Write / Page Write / Current Address Read / Sequential Read / Random Read | 全 256 字节读写成对比 | **覆盖 5 种操作模式**；重点验证：8 字节页写边界与回卷（roll over）、器件地址 1010xxxR/W、ACK 第 9 时钟、STOP 后进入 STANDBY、ACK Polling |
| **页写回卷边界** | Word Address 低 5 位递增 | 写超过 8 字节时应回卷并覆盖 | 这是 EEPROM 的经典失效点，应设专项测试向量 |
| **器件地址验证** | Device Address | **1010 x x x R/W** | bit5/6/7 为 don't care，程序不应依赖其取值 |

**特别注意事项**
1. **HK24C02A 与 HK24C02B 规格不同**：A 版 TWR < 5ms、VCC 1.8～5.5V；B 版 TWR < 8ms、VCC 1.8～**4.5V**。**测试限值与 VCC 范围必须按实际订购型号区分**，否则 B 版在 5V 下测试会超规格。
2. **SDA 是开漏输出**，必须外接上拉电阻（AC 条件规定 RL = 1.3 kΩ 接 VCC）。ATE 的 DUT 板上拉值若不等于 1.3 kΩ，tAA、tR 等参数测量结果会偏离手册。
3. **5 引脚封装与 8 引脚封装引脚号完全不同**（5L：1=SCL、2=GND、3=SDA、4=VCC；8L：4=GND、5=SDA、6=SCL、8=VCC）。同一测试程序不能直接套用。
4. **手册文字称"4-PIN EEPROM product"**（在器件地址一节），但全文给出的是 8-pin 与 5-pin 封装。此处为厂商文档措辞遗留，**不代表实际封装**，不必据此改 DUT 板。
5. **AC 特性表缺少 5V 档**：手册只给出 1.8V 与 2.5V 两档，但首页 FEATURES 声明"1 MHz (5V)"。**5V 条件下的 tLOW/tHIGH 等时序限值需向原厂索取或参照同类 I²C EEPROM（如 24C02）的 5V 规格**，不可凭 2.5V 档外推。
6. **图像识别质量说明**：本 PDF 为扫描件，但 18 页中的关键页（第 1、2、3、11、12 页：特性、产品等级、引脚/极限参数、AC 表、DC 表）**图像清晰、可完整识读**；第 4～10 页为框图与读写时序图，第 13 页为订购信息，第 14～18 页为封装尺寸图（DIP8、SOP8、TSSOP8、SOT-23-5/TSOT-23-5、DFN8），均清晰可读。**本节未出现"该页图片不清晰，未获取"的情况。**

## 7. 六款芯片 ATE 测试项汇总对照

### 7.1 器件分类与测试策略

| 芯片 | 类别 | 测试策略重点 | 主要测试难点 |
|---|---|---|---|
| CD4511BE | 纯数字逻辑 | 参数测试（IDD/VOH/VOL/VIH/VIL/IIN）+ 真值表功能测试 | 18V 高压 IIN 测试；VOH 限值随 IOH 分档复杂；VIL 限值极紧 |
| ADC0832 | 数模混合（ADC） | ICC + 数字 IO 参数 + 通道 MUX 功能 + 转换精度扫描 | ADC0832-N 的 ICC 限值专属（6.5 mA）；通道漏电需停时钟测 |
| LM358 | 纯模拟 | 运放参数测试（VOS/IB/IOS/AOL/CMRR/PSRR/摆幅/IO/IQ） | 限值按型号与温度档分档极细；nA 级 IB/IOS；两版测试条件不同 |
| TPS73625 | 模拟电源 | VOUT 精度 + VDO + IQ + ISHDN + 保护功能 | 亚 µA 级 ISHDN/IEN/IREV；大电流 ICL/ISC 需限时防过热 |
| HK32F031F4P6 | 数字 MCU（混合） | IDD 动态/待机 + IO 参数 + ADC 参数 + 结构化功能测试 | 亚 µA 待机电流；Flash 擦写寿命仅 1K；ADC ns 级时序 |
| HK24C02 | 存储器 | 待机/读/写电流 + IO 参数 + 读写功能（5 种模式） | **100 nA 级待机电流**；5V AC 规格手册缺失；开漏 SDA 需精确上拉 |

> **全组最严苛的电流项**：HK24C02 的 **100 nA** 待机电流（需 nA 级 PMU 与极低漏电 DUT 板），其次是 HK32F031F4P6 的 **3.17 µA** Standby 与 TPS73625 的 **1 µA** ISHDN。

### 7.2 通用 ATE 测试注意事项

1. **测试条件必须完整复现**：几乎所有参数都带测试条件（VCC/VDD、负载 CL/RL、温度、偏置点）。仅抄限值不抄条件，测试结果无意义。
2. **限值随型号/版本/温度档变化**：LM358 系列（B/BA/A/基础）、HK24C02（A/B 版）、TPS736（传统/新器件）都有多套规格，程序必须参数化。
3. **µA / nA 级电流测量的共性要求**：低漏电 PMU、低漏电继电器、DUT 板清洗与保护环、未用引脚按规格端接、SCL/时钟停止翻转、环境温度稳定。
4. **大电流/短路测试必须限时**：TPS736 的 ISC（450 mA）、LM358 的 ISC（±60 mA）、CD4511 的 VOH（25 mA）都需监控结温与测试时长。
5. **"仅由特性确定（characterized only）"的参数不宜作量产 100% 测试**：各手册均标注了此类参数（表中通常带脚注），ATE 程序应据此降低测试强度。
6. **不可反复擦写 Flash/EEPROM**：HK32F031F4P6 的 Flash 擦写寿命仅 **1 千次**（手册专门更正过），HK24C02 为 100 万次。量产测试程序应尽量在 RAM 中运行，避免消耗被测件的擦写寿命。
7. **手册之间的规格冲突需要原厂澄清**：本次抽取中发现两处明显冲突——
   - **HK32F031F4P6 的 VIH/VIL**：Table 4-9（存储器特性）用 0.9VDD/0.1VDD，Table 4-10（IO 引脚直流特性）用线性公式。VDD=3.3V 时分别为 2.97V 与 1.546V，差异极大。
   - **HK24C02 的 5V AC 规格**：AC 表只给 1.8V/2.5V 两档，首页 FEATURES 声称 5V 时 1 MHz，但无对应 tLOW/tHIGH 限值。
