# 级联速查（2 片 XD7219 = 16 位数码管）

## 接线

```
MCU MOSI ──► DIN  [XD7219 #1] DOUT ──► DIN  [XD7219 #2] DOUT ──► (不接)
MCU SCK  ──► CLK  ────────┬──────────────► CLK
MCU GPIO ──► LOAD ────────┴──────────────► LOAD
5V/GND   ──► 两片 V+ / 两个 GND 都接
```

- 所有芯片的 **CLK、LOAD 并联**。
- 数据方向：**第一片 DOUT → 第二片 DIN**，依此类推。
- 每片仍然要接自己的 RSET（9.53 kΩ 到 V+）和 0.1 µF 去耦。

## 帧格式

一次传输发送 `N × 16 bit`（N = 芯片数），MSB 先发。因为数据在链中移位，**先发出的 16 bit 最终停在最远端**：

```
发送顺序:  [给最后一片的 16 bit] ... [给第一片的 16 bit]
```

两片时，一次 `spi.xfer2([...])` 发 4 个字节：

```python
# 让第 2 片（远端）显示 digit0=1，第 1 片（近端）显示 digit0=2
spi.xfer2([0x01, 0x01,   0x01, 0x02])
#           addr data    addr data
#           -> chip2     -> chip1
```

## No-Op

不想改变某片时，给它发 `0x00, 0x00`（No-Op 寄存器）：

```python
# 只更新第 1 片 digit0，不动第 2 片
spi.xfer2([0x00, 0x00,   0x01, 0x05])
```

## 扫描位数要一致

若两片显示位数不同（例如一片 6 位、一片 5 位），占空比不同会导致亮度不同。把两片的 Scan Limit 都设成较大值（如 0x05 = 6 位），多余位不接数码管即可。

## 初始化（两片）

对每片都写一遍，或按级联顺序一次发多帧：

```
0x0F,0x00  0x0F,0x00
0x09,0xFF  0x09,0xFF
0x0B,0x07  0x0B,0x07
0x0A,0x07  0x0A,0x07
0x0C,0x01  0x0C,0x01
```

注意：级联时没有“广播”——每条 16 bit 只会落到一片。初始化要发 N 组。

## 常见问题

| 现象 | 原因 |
|------|------|
| 只有一片亮 | LOAD/CLK 没并联，或 DOUT→DIN 方向反了 |
| 显示错位/移位 | 帧顺序反了（先发的到了远端） |
| 第二片不亮 | 第二片没接 V+/GND，或 RSET 漏接 |
| 亮度不一致 | Scan Limit 设置不同，或 RSET 不同 |
| 写第一片时第二片乱闪 | 忘了给第二片发 No-Op，数据被当成命令 |
