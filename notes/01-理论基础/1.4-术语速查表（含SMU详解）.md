### 信号通道三元组格式（重要，易错）

```
      Adapter : FBID(Slot) : Channel
         ↓          ↓          ↓
      哪个机头    哪块业务板   板上的哪个通道
      1 ~ 8       1 ~ 5       从 0 开始
例如  1     :    1        :   6      →  1 号机头、Slot1、通道 6
```

> ⚠️ **口径更正**：部分实训工程说明文档把这个三元组写成"板卡:站点内资源:通道"，**这是不准确的**。手册（P.83）与课件3（P.19）的一致定义是 **Adapter（机头）: FBID/Slot（业务板）: Channel（通道）**，**不含"资源类型"层** —— 资源类型由 Sig 文件的 `AFEType` 字段**单独指定**。
>
> 课件3 P.19 给出的通道取值范围：
> DPS 0–3；DIO 0–31；TMU 0–3；CBIT 0–7；AWG 0；DGT 0。

## 4. AFE 资源类型（Sig 文件 `AFEType` 可选值）

手册表 2-22「AFEType 说明」完整清单（P.87）：

| AFE 类型 | 功能 | ChType |
|---|---|---|
| **CBIT** | 测试时控制继电器，例如芯片管脚需使用不同 AFE，测试时通过 CBIT 模块切换不同的资源通道 | Default |
| **DPS** | 电源管理模块（Device Power Supply），例如芯片上下电 | Supply |
| **DPS_GANG2** | 电源管理模块，两通道 DPS Gang | Supply |
| **DPS_GANG3** | 电源管理模块，三通道 DPS Gang | Supply |
| **DPS_GANG4** | 电源管理模块，四通道 DPS Gang | Supply |
| **DIO** | 数字输入/输出/高精度测量，例如芯片输入 Pattern | Inout / In / Out |
| **BPMU** | 板载高精度测量（Board PMU） | Inout / In / Out |
| **AWG** | 波形发生器（任意波形发生器） | In / Out |
| **DGT** | 数字采集模块（Digitizer） | In / Out |
| **RVS** | Reference 电源管理模块 | Supply |
| **TMU** | AC 参数测试（Time Measurement Unit，时间测量单元） | In / Out |
| **POWER** | 电源 | Default |
| **RF** | 射频信号 | RxTx |
| **SMU** | **高压电源模块，独立的 4 通道电压电源板卡** | Supply |
| **SMU_GANG2** | 高压电源模块，两通道 SMU Gang | Supply |
| **SMU_GANG3** | 高压电源模块，三通道 SMU Gang | Supply |
| **SMU_GANG4** | 高压电源模块，四通道 SMU Gang | Supply |
| **LF_AWG_NEG / LF_AWG_POS** | 低频高精度 AWG 模块负极 / 正极 | Default |
| **LF_DGT_NEG / LF_DGT_POS** | 低频高精度 DGT 模块负极 / 正极 | Default |

**`ChType`（通道类型）可选值**：`Inout`（输入输出）、`Supply`（供电）、`In`（输入）、`Out`（输出）、`Default`（默认）、`RxTx`（接收发送）。

**课件《2.课件-测试设备硬件介绍》P.17 的功能分类**（更宏观的视角）：

| 功能模块 | 测试资源 | 模块功能 |
|---|---|---|
| 电源模块 | **PPMU、DPS、BPMU、RVS** | 电压、电流的提供与测量 |
| 数字模块 | **DIO** | 0/1 数字信号的输入与输出 |
| 时间测量模块 | **TMU** | 信号的耗时、时间差等测量 |
| A/D 模块 | **AWG、DGT** | 模拟信号的生成、采集功能 |
| 继电器模块 | **CBIT** | 继电器控制模块 |

## 5. 工程文件体系

| 文件 | 中文 | 一句话说明 |
|---|---|---|
| **`.job`** | 工程总入口 | 声明工程名、各子文件路径、测试库（Test.dll）与 Lot 信息 |
| **`.res`** | 机台资源定义 | 哪些槽位 OnLine、各板卡数量（自检结果写入此处） |
| **`.sig`** | 信号映射 | `SigName, AFEType, ChType, Site0_CH` —— 信号名 → 硬件通道 |
| **`.grp`** | 信号分组 | 把多个信号打包成组名，供代码与时序整组引用 |
| **`.tim`** | 时序定义 | Wave Table：周期 Period + 各信号在各 WFC 下的驱动(D/U)/比较(H/L/X)边沿时刻 |
| **`.pat`** | Pattern 索引 | `序号,,名字,编号,true,相对路径` → 真正的 0/1 向量在 `pattern/*.csv` |
| **`.tmf`** | 测试流与限值 | Test Manage Flow：测试顺序（FuncList）、每步 Sbin/Hbin、ResultAnalysis（参数 Min/Max/Unit） |
| **`Test.cpp`** | 用户测试程序 | 全部测试方法与生命周期函数实现，编译进 `Test.dll` |
| **`interface.h`** | 接口头文件 | 定义 `USER_CODE` 导出宏 + 包含平台头（`usrInterface.h`、`usrDataType.h`） |
| **`Makefile`** | 编译脚本 | 用 MinGW g++ 把 `Test.cpp` 编译成 `Test.dll` |
| **`pattern/*.csv`** | 向量文件 | 数字功能测试的具体向量表（列：Label、WFT、Sequence、各引脚 0/1/H/L/X） |

### 易混点：`.pat` vs `.tmf`

| | `.pat` | `.tmf` |
|---|---|---|
| 角色 | "**向量素材目录**" | "**整份考卷 + 评分标准**" |
| 内容 | 名字 → CSV 文件路径 | 顺序、限值、Bin |
| 是否有顺序 | 无 | **有** |
| 是否有限值 | 无 | **有** |
| 是否有 Bin | 无 | **有** |
| 数量关系 | 少 | **多**（DC 参数项根本不经过 `.pat`） |
| 例 | CD4511：1 个 pattern | CD4511：8 个 FuncList 项 |

### Test.cpp 的生命周期函数

| 函数 | 执行时机 |
|---|---|
| `ProjectInit` / `ProjectReset` / `ProjectReuse` | 工程初始化 / 复位 / 复用 |
| `site_init` / `site_reset` | 站点初始化 / 复位 |
| `EndOfWafer` (EOW) | CP 测完一片晶圆时（需 `Enable_EOW_Func` 注册） |
| `EndOfLot` (EOL) | FT & CP 测完一个 Lot 时（需 `Enable_EOL_Func` 注册） |
| `USER_CODE` 测试函数 | 由 `.tmf` 的 `FuncName` 按顺序调度（**无 main()**） |
| `SetPassBin` | 全部通过后置 Pass Bin（一般 `binObj.SetBin(1)`） |
| `SetErrorBin` | 逻辑疏漏时兜底分 Bin（建 tmf 时自动生成） |

## 6. 测量模式（Force / Measure）

| 模式 | 全称 | 强制 | 测量 | 用途 |
|---|---|---|---|---|
| **FVMI** | Force Voltage Measure Current | 电压 | 电流 | 测漏电流、IDD、IGND |
| **FIMV** | Force Current Measure Voltage | 电流 | 电压 | 测 OS、VOH、VOL |
| **FVMV** | Force Voltage Measure Voltage | 电压 | 电压 | 校验、上电建立 |
| **FIMI** | Force Current Measure Current | 电流 | 电流 | 电流源校验 |
| **FNMV** | Force Nothing Measure Voltage | 不强制 | 电压 | 高阻测电压 |

> 这五种是 ST2500 编程手册（CHM）中 `usrInterface` 实际提供的模式集合。若见到资料写 "FMIM"，应理解为 **FIMI**（编程手册中无 FMIM 这个名字）。

**其他相关工程术语**：

| 术语 | 含义 |
|---|---|
| **Force** | 强制施加（源出） |
| **Measure** | 测量 |
| **Clamp** | 钳位，限制输出电压/电流不超过安全范围 |
| **Range** | 量程（如 2 µA 量程、500 mA 量程） |

## 8. ★ SMU 详解（本节回答"课程里 SMU 是什么意思"）

### 8.1 一句话结论

> **SMU = Source Measure Unit，中文叫"源测量单元"，业内俗称"源表"。**
>
> 在这个课程里它出现在**两个层面**：
> - **通用层面（本义）**：一种把"**精密源**"（可强制电压或电流）和"**精密测量**"（可测电压或电流）集成在同一个通道里的仪器单元 —— 这也是本课程所有 DC 测试操作（FVMI / FIMV / FVMV / FIMI / FNMV）背后的仪器概念。
> - **本课程 / ST2500 平台层面（具体用法）**：它是 Sig 文件 `AFEType` 里的**一类板卡资源名**，也是本平台 5 种电源资源（DPS / BPMU / PPMU / RVS / **SMU**）中**规格最高、功能最全**的一种。
>

### 8.4 ★ SMU 是"功能最全"的电源资源（模式支持矩阵，课件 P05）

课件 P05 给出了一张**模式-模块支持矩阵**（原文：`F == Force，V == Voltage，M == Measurement，I == Current，N == None`）：

| 模式 / 功能 | DPS | BPMU | PPMU | RVS | **SMU** |
|---|:--:|:--:|:--:|:--:|:--:|
| FVMV | √ | √ | √ | √ | **√** |
| FVMI | √ | √ | √ | √ | **√** |
| FNMV | √ | √ | √ | √ | **√** |
| **FIMV**（强制电流） | **×** | √ | √ | √ | **√** |
| **FIMI**（强制电流） | **×** | √ | √ | √ | **√** |
| **FVMIMV / FIMVMI**（混合组合） | × | × | × | × | **√ 唯一** |
| Clamp Current（电流钳位） | √ | √ | × | × | **√** |
| Clamp Voltage（电压钳位） | × | √ | √ | × | **√** |
| **Gang Mode** | √ | × | × | × | **√** |

**这张表回答了一个关键问题**：

> ⭐ **DPS 只能 Force Voltage（FV 系列），不支持 FIMV / FIMI —— 也就是 DPS 不能当电流源。**
> ⭐ **SMU 支持全部四种基本 F/M 组合（含 FIMV / FIMI），并且是全平台唯一支持 `FVMIMV` / `FIMVMI` 混合组合模式的资源，两种钳位都支持，还支持 Gang Mode。**
>
> **这就是 SMU 之所以叫 "Source Measure Unit" 而不是 "Power Supply" 的实证** —— 它真的能"源出电压或电流、同时测量另一个量"，四象限工作；DPS 只能算"电压源 + 电流表"。**使用手册没写清楚的"SMU 是否具备电流测量能力"，在这张课件表里得到了肯定的答案。**

### 8.5 ST2500 上 SMU 与 DPS / PPMU / BPMU / RVS 的定位差异

| 维度 | **SMU** | **DPS** | **PPMU / BPMU** | **RVS** |
|---|---|---|---|---|
| 物理形态 | **独立板卡**（型号 SMU20，与 DFB32、MWB8 并列） | DFB32 **板载模块** | DFB32 板载模块 | DFB32 板载模块 |
| 手册定位 | "**高压**电源模块，独立 4 通道电压电源板卡" | 电源管理模块（器件供电） | 板载**高精度测量** | Reference 电源管理 |
| ChType | Supply | Supply | Inout / In / Out | Supply |
| 电压上限 | **20 V（最高）** | 8.4 V | 6.5 V（PPMU） | 10 V |
| 电压精度 | **±(0.05%+0.5 mV)（最好）** | ±(0.1%+5 mV) | ±(0.1%+5 mV) | ±(0.1%+4 mV) |
| 电流档数 | **7 档（最多）** | 6 档 | 5 档 | 1 档 |
| 强制电流能力 | **✔ FIMV / FIMI** | **✘ 不支持** | ✔ | ✔ |
| 混合模式 | **✔ 唯一** | ✘ | ✘ | ✘ |
| 钳位 | 电流 + 电压**都支持** | 仅电流 | PPMU 仅电压；BPMU 两者 | 都**不支持** |
| Gang | **✔ 2 A** | ✔ 2 A | ✘ | ✘ |
| 连接方式 | 4 线 | 4 线 | **PPMU 是唯一 2 线** | 4 线 |
| 本课程实训怎么用 | **6 个实训工程均未使用** | 给 DUT 供电（VDD/VCC） | 测 OS / 漏电流 / VOH / VOL / IGND | 未使用 |

**四条要点**：

1. **物理形态不同**：SMU 是**独立板卡**（插在 Slot1–Slot5，与 DFB32、MWB8 并列）；DPS / PPMU / BPMU / RVS 是 **DFB32 板上的 AFE 模块**。
2. **"高压 + 高精度"是 SMU 的定位**：电压上限 **20 V**（全平台最高）、电压精度 **0.05% 级**（全平台最好）、电流档 **7 档从 1 µA 到 500 mA**（覆盖范围最宽）。
3. **"唯一全能"是 SMU 的本质**：既能当电压源、又能当电流源，还能混合模式，两种钳位都有 —— 它就是一台**真正的源表**。
4. **Gang 命名完全对称**：DPS 与 SMU 各有 GANG2/3/4，语义相同（多通道并联输出更大电流，**只能并联相邻通道**：4 通道 2 A、3 通道 1.5 A、2 通道 1 A），`ChType` 均为 `Supply`。

### 8.6 通道编号对 SMU 的适用性

SMU 的通道选择规则与 DPS 等一致，仍用 Sig 文件三元组 **`Adapter : FBID(Slot) : Channel`**，通道号**默认从 0 开始**。
SMU 为 **4 通道**卡，命名为 **SMU0 ~ SMU3**，因此 Channel 范围为 **0 ~ 3**。

> 实测建议：以 `.res` 文件自检到的实际资源为准（点 `Get Resources` 后 `AFEType` 下拉列表里才会出现 SMU 相关项）。

课程使用的教学机（ST2516 / MINI-ATE 实训平台）配置的是 **DFB32 业务板**，6 个实训工程用到的资源是：

### 8.9 通用层面：SMU 的四象限工作能力

> 以下属于**行业通用知识**（不限于本课程平台），整理时与本目录中早前留下的一份 SMU/PMU 笔记互补合并。

**SMU 区别于普通电源的本质 = 四象限工作。**

| 象限 | 电压 | 电流 | 功率方向 | 典型场景 |
|:--:|---|---|---|---|
| 第一 | 正 | 流出（+） | 输出 | 正常供电 |
| 第二 | 负 | 流出（+） | **吸收** | 模拟负载 |
| 第三 | 负 | 流入（−） | **吸收** | 反偏、放电 |
| 第四 | 正 | 流入（−） | 输出 | 灌电流 |

> **普通实验室电源只能工作在第一个象限；SMU 四个象限都能工作。** 所以它可以：
> ① 当电源（source）；② 当负载（sink）；③ **双向扫描**（−1 V → +1 V 扫二极管曲线，或 +V → −V 扫晶体管输出特性）。
>
> 这就解释了本课程 OS 测试为什么能既灌 **+100 µA** 又抽 **−100 µA** —— 因为源测量单元天生就是四象限的。

**Compliance（钳位 / 限值）机制**：

| 模式 | 必须设的钳位 | 作用 |
|---|---|---|
| **FVMI**（强压测流） | **current compliance**（电流上限） | 防止被测件短路烧毁 |
| **FIMV**（强流测压） | **voltage compliance**（电压上限） | 防止开路时电压失控 |

> **关键机制**：SMU 一旦触及 compliance，就自动从"源"模式转入"限制"模式 —— **不再强行维持设定值，而是停在限值上**。
>
> 这正对应本课程工程代码里的 `CurrClamp(0.5, -0.5)`、`VoltClamp(2, -2)` —— 而课件 P05 的模式矩阵也印证了：**SMU 是唯一同时支持 Clamp Current 与 Clamp Voltage 的资源之一**（BPMU 也两者支持；PPMU 只支持电压钳位；DPS 只支持电流钳位；RVS 两者都不支持）。

**开尔文四线连接（Force / Sense）**：

标准 SMU 有两对线：

| 线 | 作用 |
|---|---|
| **Force 线** | 走电流 |
| **Sense 线** | 测电压 |

**为什么要分开？** Force 线上有导线电阻和接触电阻，电流流过会产生压降。若直接用 Force 端的电压当测量值，就把线阻算进去了。Sense 线在被测件两端单独测电压（此时 Sense 线几乎不走电流，压降可忽略），从而消除这个误差。

> 这就是 **开尔文四线测量 —— 测小电阻、大电流时必用**。也印证了课件 P06/P08 的结论：**DPS / BPMU / RVS / SMU 都是 4 线，只有 PPMU 是 2 线**。

### 8.10 ★ SMU 与 PMU 的关系（最容易被混为一谈）

这是**考试和面试的常考点**，也是本课程里 `PPMU` / `BPMU` / `SMU` 三个名字并存的原因：

| | **SMU** | **PMU**（Parametric Measurement Unit） |
|---|---|---|
| 全称 | Source Measure Unit | 参数测量单元 |
| 定位 | **独立仪器**（如 Keithley 2400、Keysight B2900）—— 本课程里是 **SMU20 独立板卡** | **ATE 系统内的功能模块** —— 本课程里是 **DFB32 板载 PPMU/BPMU** |
| 形态 | 台式，带面板和界面 / 独立板卡 | 板卡通道，集成在测试头里 |
| 通道数 | 通常 **1~2 路**（本平台 SMU20 为 4 路） | 一块板**几十上百路**（本平台 PPMU **32 通道**） |
| 精度 | 高（nA ~ fA 级）—— 本平台 SMU 达 **±(0.05%+0.5 mV)** | 相对低（受通道数和成本限制）—— 本平台 PPMU 为 **±(0.1%+5 mV)** |
| 速度 | 慢（ms 级） | 快（µs 级，要跟上测试节拍） |
| 用途 | 器件表征、实验室调试 | **量产测试、多引脚并行** |

> **一句话概括**：**PMU 是"ATE 里的 SMU"，是 SMU 在量产测试场景下的集成化、多通道、高速化版本。**
>
> ⚠️ **注意**：有些教材/厂商会把 ATE 里的模块也直接叫 SMU（如 "per-pin SMU"）。看到时要**按上下文判断是台面仪器还是机台模块**。
>
> 📌 **本课程的实际口径**：ST2500 把两者**明确区分**了 —— `SMU`（独立高压电源板卡，4 通道，精度最高，功能最全）与 `PPMU`/`BPMU`（DFB32 板载参数测量模块，32/4 通道）。**同时平台还多出 DPS（纯电压源）和 RVS（参考电压源）两类，分工比通用教材更细。**

### 8.11 SMU 的时序约束（影响测试吞吐量的隐形因素）

SMU 不是理想器件，有几个时间参数会**直接限制测试吞吐量**：

| 参数 | 说明 |
|---|---|
| **Settling time**（建立时间） | 施加电压后，到电流读数稳定所需时间 |
| **Range change time**（量程切换时间） | 量程切换开销（µA 档 → mA 档） |
| **Cable 电容充放电** | 长电缆有几十 ~ 几百 pF，切换电压时要充放电 |

> **量产测试中参数测试往往是瓶颈项**（模拟测量天生比数字慢）。因此测试程序里讲究：
> - **少切量程**（尽量用同一档测完一组）—— 这正解释了工程代码里"先大量程稳定、再切小量程精测"的做法为什么只在必要时才切；
> - **合理设置延时**（不够测不准，太长掉产能）—— 对应工程里的 1~5 ms / 8~10 ms / 15~30 ms 三档延时；
> - **并行测量**（多 PMU 同时测）—— 对应 HK24C02 案例"**用 DIO 的 PPMU 替代 DPS 供电以提高并测数**"的工程决策。
