## 一、半导体产业链与测试的位置

### 1.1 产业链四大环节

课件把半导体产业链拆成四块（P.3）：

| 环节 | 内容 | 代表企业 |
|---|---|---|
| ① 芯片设计 | 算法、架构、前端/后端 | Fabless：海思、博通；EDA：Cadence、Synopsys、Mentor、华大九天；IP：ARM |
| ② 晶圆加工 | 器件制造、互联 | Foundry：台积电、中芯国际 |
| ③ 封装测试 | 减薄、贴装、**功能验证** | OSAT：长电、华天、日月光、通富 |
| ④ 设备材料 | 光刻、封装、测试 | 设备：ASML、东京电子、Advantest、Teradyne、Chroma、华峰、长川、加速科技；材料：信越化学、陶氏化学 |

产业模式：
- **IDM**（Integrated Device Manufacture）垂直整合制造：设计+制造+封测+销售全包，如 Intel、TI、Samsung、长江存储。
- **Fabless**：只设计不制造，如高通、联发科、海思。
- **Foundry**：只代工制造，如台积电、中芯国际、华虹宏力。
- **OSAT**（Outsourcing Assembly and Test）：只做委外封装测试，如日月光、长电、通富、华天。
- **Strategic Outsourcing Model**：IDM 策略性外包前沿产品制造，但保留自身工艺开发，如 ADI。

### 1.3 测试行业的四个痛点（P.6）

课程明确点出这门课的存在理由：

1. **核心技术被海外垄断** —— 半导体测试设备全球市场基本被爱德万（Advantest）、泰瑞达（Teradyne）两家垄断；国内华峰、长川研发多年未能突破数字测试机技术。
2. **设备昂贵阻碍 IDH 发展** —— 数字测试机价格通常在**百万美金**量级，中国上千家 IDH 难以承受。
3. **推高生产成本** —— 高昂测试费用变相增加我国半导体行业生产成本。
4. **严重缺乏测试专业人才** —— 数字芯片复杂度越高，对测试要求越高，人才缺口越大。

人才缺口数据（P.7）：预计 2024 年前后全行业人才需求达 **78.9 万人**（设计 32.52 万、制造 26.97 万、封测 19.41 万），全行业缺口超 **15 万**，其中封测领域超 **3 万**。
2022 上半年集成电路/半导体行业招聘量同比增长 **29.5%**（全行业约 10%）。

## 二、IC 测试的定义与目的

> **IC 测试**：通过测量 IC 的输出响应，将其与预期的输出相比较，以评估 IC 器件电性能的过程。它是验证产品性能、监控生产状况、分析产品失效的重要手段。（P.10）

为什么要测：
- IC 制造工艺**永远无法达到 100% 良率**；
- 在上系统前必须先测试，**剔除不良品以降低成本损失**。

测试分为两大阶段：

| 阶段 | 缩写 | 中文 | 设备 | 治具 |
|---|---|---|---|---|
| 晶圆测试（中测） | **CP** (Circuit Probing) | 在整片晶圆上逐 Die 测试 | 测试机 + **Prober 探针台** | **PIB**（Probe Interface Board）+ Probe Card 针卡 |
| 成品测试（成测） | **FT** (Final Test) | 封装完成后测成品 | 测试机 + **Handler 分选机** | **DIB / Load Board**（负载板）+ Socket |

CP 流程（P.15）：probe card 探针接触 wafer 上某颗 die 的每个 bond pad → 送 Start 信号经 Interface 给 Tester → Tester 测完送回分类信号（End of Test）给 Prober。**量产时 tester 与 prober 必须做 docking（连接）才能测试。**

FT 流程（P.21）：Handler 手臂把 DUT 放入 socket → contact chuck 下压使引脚正确接触 → 送 Start 经 Interface 给 Tester → 测完 Tester 送回 binning 与 EOT 信号 → Handler 做分类。DUT 尺寸与脚数不同，Handler 需换不同模具（kits）。

### 三台主设备的职责分工（P.13）

| 设备 | 职责 |
|---|---|
| **测试机 Tester** | 等待 handler/prober 发出测试启动信号，执行芯片测试，把结果返回 |
| **分选机 Handler** | 自动把芯片与测试机连接，告知是否就绪及同测数量，记录测试结果并按结果分等级 |
| **探针台 Prober** | 放晶圆到针卡针下，告知何时就绪、几颗可测、芯片 X-Y 坐标；记录结果并对失效品**打墨点** |

## 四、测试程序开发流程

### 4.1 标准流程（P.27）

```
产品测试计划制定
   ↓
ATE 配置选择 ──→ 资源分配 ──→ 硬件开发（DIB 制作）
   ↓
测试程序编写
   ↓
上机调试
   ↓
数据验证
   ↓
程序优化
```

### 4.2 测试工程师要读的三份文档

| 文档 | 作用 |
|---|---|
| **产品手册 Datasheet** | 芯片制造商发布的正式文档。含特性总结、功能描述、直流参数、时序规范。**开发测试程序之前必须读懂**，其中的电流、电压、时序描述是测试程序开发的基础（P.28） |
| **测试计划 Test Plan** | 详细记录产品测试需求的文档，含测试项目、测试流程。详细定义测试条件、参数判断条件。制定需设计、测试、产品工程师协作；根据结果可能反过来修订产品手册的参数定义（P.29） |
| **测试程序 Test Program** | 测试项目的流程控制；依据测试条件控制测试机硬件；与探针台/分选机通讯；测试结束返回测试结果（Pass/Fail）、**HBIN 和 SBIN**、晶圆测试的 die 坐标、结果统计（P.30） |

### 4.3 课件给出的测试计划实例（P.27，ECP5-25 / BGA256）

这是理解"测试项怎么写"的最好范例：

| Test Name | Vcc | Force / Expect | Pinlist | Timing |
|---|---|---|---|---|
| opens | 0V | Force: -200 µA，Pass if > -900 mV | ALL_PINS | — |
| shorts | 0V | Force: -200 µA，Pass if < -200 mV | ALL_PINS | — |
| vcc_shorts | 0.2V | Force 0.2V，Pass between -15 mA ~ 300 mA | supplies_pkg | — |
| jtag_state_machine | 1.1V | 0X41111043 | Jtag | 70 ns |
| icc_core | 1.155V | Pass if < 344 mA | Vcc | 100 ns |
| iccio | 1.155V | Pass if < 0.5 mA (per bank) | VccIO | 100 ns |
| icc_aux | 1.155V | Pass if < 30 mA | VccAux | 100 ns |
| pin_leakage_min | 1.1V | Force 0V on pin，Pass between -8 µA ~ 8 µA | NOPULL_PINS | 100 ns |
| pin_leakage_max | 1.1V | Force 3.465V on pin，Pass between -8 µA ~ 8 µA | NOPULL_PINS | 100 ns |
| pd_leakage_min | 1.1V | Force 0.8V on pin，Pass between 32 µA ~ 205 µA | PULLDOWN_PINS | 100 ns |
| pd_leakage_max | 1.1V | Force 3.465V on pin，Pass between 32 µA ~ 205 µA | PULLDOWN_PINS | 100 ns |
| pu_leakage_min | 1.1V | Force 0V on pin，Pass between -30 µA ~ -246 µA | PULLUP_PINS | 100 ns |

**读法**：每一行 = 一个测试项 = 电源条件 + 施加条件 + 判据 + 作用引脚 + 时序。

### 4.4 测试程序流程示意（P.31）

课件给出的典型量产测试流程图（Good Device 的 Bin 划分）：

```
Bin10 开始
  → Continuity（连接性）
  → Opens/Shorts（开短路）
      ├─ Fail → Bin 9
      → Gross IDD ──── Fail → Bin 8
      → Gross Functional ── Fail → Bin 5
      → Functional VIL/VIH（VDDmin/VDDmax）── Fail → Bin 7
      → 100MHz Functional（VDDmin/VDDmax）
            ├─ Pass → Bin 1 = 100MHz
            ├─ Fail → Bin 2
            → 75MHz Functional（VDDmin/VDDmax）
                  ├─ Pass → Bin 2 = 75MHz
                  ├─ Fail → Bin 3（best frequency）
                  → Static IDD（VDDmax）── Fail → Bin 6
                  → Dynamic IDD（VDDmax）── Fail → Bin 5
                  → Input Leakage（VDDmax）/ IO Z High Impedance Leakage（VDDmax）
                        → DC PMU VOL/VOH（VDDmin）/ VDDmin / VDDmax
                              → Bin 4
```

**关键思想**：先做最快、最便宜、最容易筛掉坏品的项（连接性、开短路、Gross IDD），把可能造成损坏的项放前面，越贵的测试越往后放 —— 这就是"测试成本控制"的核心逻辑。

## 七、本章速记

1. 产业链 = 设计 → 晶圆加工 → 封装测试 → 设备材料；测试贯穿**设计验证、CP 中测、FT 成测**三个环节。
2. IC 测试 = **测输出响应 → 与预期比较 → 评估电性能**。
3. CP 用 **Prober + PIB + Probe Card**；FT 用 **Handler + DIB/Load Board + Socket**。
4. 测试程序输出三件事：**Pass/Fail、HBIN/SBIN、Die 坐标**。
5. 测试流程排序原则：**便宜的、能快速筛掉坏品的项（OS、IDD）放前面**。
6. 开发测试程序的依据是 **Datasheet + Test Plan**。
