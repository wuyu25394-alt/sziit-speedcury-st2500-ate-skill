## 一、先建立整体图景

运算放大器（Operational Amplifier，Op-Amp）是一种**高增益、直接耦合、差分输入**的放大器。

它有三个基本端子：

- 同相输入端：`V+`，输入与输出同相；
- 反相输入端：`V−`，输入与输出反相；
- 输出端：`Vout`。

实际器件还需要正负电源或单电源供电。

运放本身只提供一个非常大的开环增益；真正好用的放大电路，要依靠**外部反馈网络**决定增益、输入阻抗、输出阻抗和频率特性。

一条最重要的主线是：

```text
开环增益很大
    ↓
差分输入只需 µV 级，输出就会大幅变化
    ↓
开环时很容易饱和，不能直接当普通放大器用
    ↓
加入负反馈，让电路自动调节到 V+ ≈ V−
    ↓
闭环增益主要由外部电阻决定
```

## 二、开环公式：Vout = (V+ − V−) × Av

### 2.1 各符号的含义

开环理想关系为：

```text
Vout = Av × (V+ − V−)
```

其中：

| 符号 | 含义 |
|---|---|
| `V+` | 同相输入电压，有时写作 `Vinp` |
| `V−` | 反相输入电压，有时写作 `Vinn` 或 `Vn` |
| `Vd = V+ − V−` | 差模输入电压 |
| `Av`、`AOL`、`AVD` | 开环差模电压增益 |
| `Vout` | 输出电压 |

因此，运放放大的不是某一个输入端对地的电压，而是**两个输入端之间的差值**。

增益的两种常用写法：

```text
倍数：100000 V/V
工程写法：100 V/mV
分贝：20 lg(100000) = 100 dB
```

注意：电压增益使用 `20 lg`，功率比才使用 `10 lg`。

### 2.2 传输特性的三个区域

完整的实际传输特性不是一条无限延伸的直线，而是：

```text
负饱和区 ───────┐
                │  线性区：斜率 = Av
                └─────── 正饱和区
```

- **线性区**：满足 `Vout = Av × Vd`，输出随输入连续变化；
- **正饱和区**：输出接近正电源轨，继续增大 Vd 也不会再升高；
- **负饱和区**：输出接近负电源轨或地，公式同样失效。

例如，`Av = 100000`、输出饱和电压约为 ±13 V，则线性区对应的差模输入只有：

```text
|Vd| ≤ 13 / 100000 = 130 µV
```

所以开环运放的输入只要相差几 mV，输出通常就已经饱和。比较器正是利用这种「大差值输入、输出翻转」的特性工作，但专用比较器在速度、输出结构和延迟方面更适合该用途。

### 2.3 开环增益不是闭环增益

这是最常见的混淆：

- **开环增益 Av**：器件本身的属性，非常大，但随频率、温度、负载变化；
- **闭环增益 Acl**：由外部反馈网络决定，例如反相电路的 `−Rf/R1`。

不能用 `Vout = Av(V+−V−)` 直接计算普通闭环放大器的输出，再随意代入一个输入电压；闭环分析应使用反馈方程或虚短、虚断。

## 三、虚短、虚断：闭环分析的两把钥匙

### 3.1 虚短

在线性负反馈电路中：

```text
V+ − V− = Vout / Av
```

由于 Vout 有限而 Av 很大，所以：

```text
V+ ≈ V−
```

这叫**虚短**：两输入端电位近似相等，但物理上并没有短接。

### 3.2 虚断

理想运放输入电流为零；实际通用运放的输入电流通常也远小于外部信号电流，因此近似：

```text
I+ ≈ 0，I− ≈ 0
```

这叫**虚断**：分析外部电阻网络时，可把运放输入端近似看作不取电流。

### 3.3 两条近似成立的前提

必须同时注意：

1. 电路处于**负反馈**状态；
2. 运放在**线性区**，没有饱和；
3. 输入共模电压在允许范围内；
4. 输出电流、负载和摆幅没有超过器件能力；
5. 频率没有高到使增益和相位条件失效。

比较器、振荡器、饱和输出电路中，不能机械套用「虚短」。

## 四、五种最常用的闭环电路

### 4.1 电压跟随器

```text
             ┌─────────┐
Vin ──────── │ +       │
             │   运放  ├──── Vout
      ┌───── │ −       │      │
      │      └─────────┘      │
      └───────────────────────┘
```

```text
Vout ≈ Vin
闭环增益 = 1
```

用途：缓冲、提高输入阻抗、降低输出阻抗、隔离前后级。

### 4.2 反相放大器

```text
             Rf
      ┌─────\/\/\/─────┐
      │                │
Vin ─\/\/\/──┬────── − │
     R1      │    运放  ├──── Vout
             └────── +  │
                        │
                       GND
```

利用反相端虚地 `V− ≈ 0` 和虚断：

```text
Vin / R1 + Vout / Rf = 0
Vout / Vin = −Rf / R1
```

特点：有反相，输入阻抗约为 R1；增益可小于 1，也可大于 1。

### 4.3 同相放大器

```text
闭环增益 = 1 + Rf / Rg
```

特点：不反相、输入阻抗高、闭环增益不小于 1。

### 4.4 差分放大器

理想对称电阻条件下：

```text
Vout = (R2 / R1) × (V2 − V1)
```

用途：放大两路信号之差并抑制共模电压。

实际 CMRR 不仅取决于运放，还非常依赖外部电阻匹配。电阻误差会直接降低整个电路的共模抑制能力，所以高精度差分测量常选用集成差分放大器或仪表放大器。

### 4.5 加法器、积分器与有源滤波器

- 反相加法器：多路输入电流在虚地点相加，输出为加权和的反相；
- 积分器：反馈电阻换成电容，输出与输入的时间积分相关；
- 有源滤波器：用电阻、电容和运放构成低通、高通、带通等频率选择电路。

## 五、关键参数：每个参数分别回答什么问题

### 5.1 输入失调电压 Vos

**定义**：理想运放两输入端等电位时，输出应为中点或零；实际器件由于输入差分对、电流镜和工艺失配，需要额外的差分输入补偿，等效为输入端串联一个小直流电压源。

一种常用模型写成：

```text
Vout = Av × [(V+ − V−) + Vos]
```

有些教材把 Vos 定义为「使输出归零所需的输入电压」，公式会写成减号。两种约定可能差一个符号，所以：

- 原理分析时先说明定义；
- 生产判限通常使用绝对值和上下限；
- 不要把某一颗芯片的正负极性当成所有器件都相同。

**影响**：直流放大器、传感器前端、电桥、ADC 驱动电路的零点误差。纯交流放大可用隔直电容减轻其影响。

**温漂**：`dVos/dT`，单位常为 µV/°C。25 °C 合格不代表全温区合格。

### 5.2 输入偏置电流 Ib 与输入失调电流 Ios

- `Ib`：两个输入端偏置电流的平均值；
- `Ios`：两个输入端偏置电流之差，即 `Ib+ − Ib−` 的绝对值或带符号差值。

输入电流流经外部电阻会产生额外误差：

```text
由偏置电流引起的等效输入误差 ≈ Ib × Rsource
```

因此，「Vos 很小」不代表高源阻抗电路误差也小。高阻传感器、光电二极管等场合通常需要 JFET 或 CMOS 输入运放。

### 5.3 开环增益 AOL / AVD

```text
AOL = ΔVout / ΔVd
```

它决定闭环精度和虚短近似的好坏，但不能简单理解为「电路固定放大多少倍」。

### 5.4 共模抑制比 CMRR

共模电压：

```text
Vcm = (V+ + V−) / 2
```

差模电压是信号，共模电压是两输入共同携带的部分。理想运放只响应差模，不响应共模；实际器件会有共模增益。

```text
CMRR = Ad / Acm
CMRR(dB) = 20 lg(Ad / Acm)
```

CMRR 越大，说明共模干扰被抑制得越好。单端反相或同相放大电路虽然也存在输入共模范围问题，但「差分放大器抑制共模」的应用最能体现 CMRR 的意义。

### 5.5 电源抑制比 PSRR

PSRR 表示电源变化对输入等效失调或输出的影响。可理解为：

```text
PSRR(dB) = 20 lg(ΔVs / ΔVos)
```

PSRR 越高，电源纹波和噪声对电路影响越小。它随频率变化，高频通常明显下降，所以电源去耦电容仍然不可省略。

### 5.6 增益带宽积 GBW 与压摆率 SR

两者不能混为一谈：

| 参数 | 回答的问题 | 典型限制 |
|---|---|---|
| GBW | 小信号能放大多快、多高频 | 闭环带宽约为 GBW / 闭环增益 |
| SR | 大信号输出变化有多快 | 输出大摆幅、高频时出现失真 |

对正弦波，避免压摆率限制的近似条件：

```text
fmax = SR / (2π × Vpeak)
```

例如 UA741 的 SR 约为 0.5 V/µs，输出峰值 10 V 时：

```text
fmax ≈ 0.5×10⁶ / (2π×10) ≈ 8 kHz
```

超过这个范围，正弦波可能逐渐变成三角波，即使小信号带宽看起来还够。

### 5.7 输入共模范围与输出摆幅

- 输入电压不能任意接近或超过电源轨；
- 输出也不能总是达到电源轨；
- 「轨到轨输入」与「轨到轨输出」是两个不同能力；
- 输出摆幅还随负载电流变化，重载时通常更小。

### 5.8 其他常见参数

- 输入电压噪声、输入电流噪声；
- 电源电流 Icc 与静态功耗；
- 最大输出电流、短路保护；
- 容性负载驱动能力与稳定性；
- 相位裕度、建立时间、过载恢复时间。

## 六、UA741：为什么它是经典教具

UA741 是 1968 年 Fairchild 推出的经典通用运放。其历史意义主要在于：**将内部频率补偿普及为通用运放的标准做法**，使用者不必像早期运放那样复杂地进行外部补偿，电路更容易稳定使用。

### 6.1 典型参数的量级

不同厂家、后缀和温度档会有差异，以下只作数量级参考：

| 参数 | 常见典型量级 |
|---|---|
| Vos | mV 级，常见典型值约 1～2 mV |
| AOL | 约 10⁵ 倍，约 100 dB |
| Ib | 几十 nA 级，BJT 输入 |
| GBW | 约 1 MHz |
| SR | 约 0.5 V/µs |
| 供电 | 经典使用方式为 ±15 V 双电源 |

精确限值必须查对应厂家的数据手册，不能跨厂家直接套用。

### 6.2 引脚与调零

经典 DIP-8 排列中：

- 2：反相输入；
- 3：同相输入；
- 6：输出；
- 7：正电源；
- 4：负电源；
- 1、5：offset null，可外接电位器进行失调调零。

调零脚的存在很直观：**失调是器件输入级失配的结果，可以在一定范围内外部校准，但不等于温漂和长期漂移也被永久消除。**

### 6.3 今天的局限

- Vos 和 Ib 较大；
- SR 较慢，不适合高速大摆幅信号；
- 输入、输出不是轨到轨；
- 单电源低压系统使用不方便；
- 高精度场合应选精密或零漂移运放，高阻场合应选 JFET/CMOS 输入运放。

它仍适合教学，因为电路结构经典、参数直观，也容易通过实验观察饱和、失调和压摆率失真。

## 七、LM358：与 UA741 对照理解

LM358 是一片**双运放**，两个独立运放共用电源，DIP-8 引脚为：

```text
1 = OUT1，2 = IN1−，3 = IN1+，4 = V−/GND
5 = IN2+，6 = IN2−，7 = OUT2，8 = V+
```

主要特点：

- 可单电源或双电源工作；
- 内部频率补偿；
- 输入共模范围可包含地，适合许多低压单电源场景；
- 通用、低成本，但不是高精度、高速器件；
- 输出能力并不完全对称，低电平、灌电流和负载条件需要按手册检查。

仓库资料中特别强调了**版本差异**：

| 参数 | 基础版常见限值 | B 版常见限值 |
|---|---:|---:|
| Vos（25 °C） | ±7 mV | ±3 mV |
| 更宽温度档 | 限值会放宽 | 限值也会变化 |
| AOL | 按具体版本与测试条件查表 | 常见要求 ≥70 V/mV |

因此，测试程序不能只写「LM358 的 Vos 限值」，而应写成「**某厂家、某后缀、某温度档、某测试条件下的限值**」。

## 八、运放与 LDO 的关系

LDO 内部可以看成由以下部分组成：

```text
基准电压 Vref → 误差放大器 ← 输出反馈分压
                      ↓
                   调整管
                      ↓
                     Vout
```

负反馈稳定后：

```text
VFB ≈ Vref
Vout = Vref × (R1 + R2) / R2
```

误差放大器的 Vos 也会形成输出误差，近似为：

```text
ΔVout ≈ Vos(EA) × (1 + R1/R2)
```

所以 LDO 输出精度至少受到三类因素影响：

1. 基准电压误差；
2. 误差放大器失调与漂移；
3. 反馈电阻容差与温漂。

### 为什么两个电阻分压不能替代 LDO 供电

空载分压公式：

```text
Vout = Vin × R2 / (R1 + R2)
```

接上负载 RL 后，R2 与 RL 并联，分压比立即改变；负载电流越大，输出下降越严重。其根源是：

- 分压网络输出阻抗大；
- 没有反馈调节；
- 负载调整率差；
- 电阻上还持续消耗功率。

电阻分压适合提供**几乎不取电流的电压信号**，例如 ADC 采样、比较器阈值、反馈取样；不适合直接给动态负载供电。

## 九、ATE 中如何测运放：从「直接测」到「伺服环路」

### 9.1 为什么不能简单直接测

运放参数常常是：

- Vos：mV 甚至 µV 级；
- Ios：nA 级；
- AOL：80 dB 以上；
- CMRR、PSRR：通过微小差值计算。

如果仪器固定误差本身就有数 mV，直接测 mV 级失调无法得到稳定、可复现的结果。

解决思路不是一味要求仪器更准，而是：

> **利用闭环电路把小信号放大，再测放大后的电压；用差值法消除固定偏置。**

### 9.2 LM358 案例的伺服测试架构

仓库案例中的核心硬件包括：

- 被测运放 DUT；
- 辅助运放与积分环路；
- 1000:1 衰减反馈网络；
- 测试点 TP；
- 继电器 K1、K2、K6 等，用于改变拓扑；
- DPS 提供可独立变化的正负电源；
- BPMU/PPMU 测量 TP 或强制特定电平。

直观理解：

```text
DUT 输入端的 1 mV 变化
          ↓ 伺服环路放大
TP 上约 1 V 的变化
          ↓
测试机测量 V 级信号，再除以 1000 折回输入端
```

这样，仪器的 5 mV 固定误差折回输入端后约为 5 µV，测量能力由电路结构得到改善。

### 9.3 Vos 的测量

最简单的原理演示是把 DUT 接成电压跟随器、同相端接地，此时输出近似等于 Vos。但直接读取 mV 级输出会受到仪器分辨率、输入偏置电流和噪声限制，所以实际 ATE 更常用下面的伺服放大方法。

K1、K2 闭合，使输入端外接电阻处于低阻状态，读取 TP 电压：

```text
Vos ≈ VTP1 / 1000
```

这里只写原理关系；实际符号、零点和公式以测试板原理图及工程实现为准。

### 9.4 Ios 的测量

断开 K1、K2，把已知电阻接入两个输入端，再读 TP：

```text
ΔVTP = VTP2 − VTP1
```

输入电流差引起的输入电压差经同一闭环放大，因此原理上：

```text
Ios ≈ |ΔVTP| / (1000 × R)
```

若 `R = 2000 Ω`，结果换算为 nA 时要注意单位。测试程序应按实际两个输入电阻及拓扑分别计算 Ib+、Ib− 或 Ios，不能只背一个系数。

### 9.5 开环增益 AOL

通过伺服环路使 DUT 输出改变一个已知量，同时测 TP 的变化：

```text
ΔVd = ΔVTP / 1000
AOL = ΔVout / ΔVd
AOL(dB) = 20 lg(AOL)
```

关键是先把工作点稳定在线性区，否则读到的只是饱和值。仓库课件提到用二分法寻找工作区，就是这个原因。

### 9.6 CMRR 与 PSRR：同一电路，不同激励

| 项目 | 激励怎么变 | 共模电压 | 总电源电压 |
|---|---|---|---|
| CMRR | 正负电源同向平移，例如 ±2.5 V → +3.5 V/−1.5 V | 改变 1 V | 保持 5 V |
| PSRR | 正负电源反向拉开，例如 ±2.5 V → ±3 V | 保持中点不变 | 5 V → 6 V |

通用差值计算形式：

```text
CMRR(dB) = 20 lg[1000 × ΔVcm / |ΔVTP|]
PSRR(dB) = 20 lg[1000 × ΔVs  / |ΔVTP|]
```

其中 ΔVs 是**总电源电压变化量**，不是只看正电源变化。这里描述的是 LM358 伺服测试板的实现：在保持环路稳定的条件下，通过平移电源改变 DUT 的共模工作条件，再读取 TP 差值；它不是所有运放测试板唯一的电路形式。

口诀：

```text
两端同向动 → 共模变 → CMRR
两端反向拉 → 总电源变 → PSRR
```

### 9.7 电源电流与静态功耗

无输入信号、输出无规定负载时，分别测正负电源电流。一般静态功耗按各电源实际功率求和：

```text
PD = VCC × ICC + |VEE × IEE|
```

注意测试机「流出为正」等极性约定，以及上电时先大量程、稳定后切小量程，避免浪涌造成钳位或错误读数。

### 9.8 精密模拟测试的四条经验

1. **多次平均**：mV、nA 级信号容易贴近噪声地板；
2. **差值法**：激励前后各测一次，消除固定失调、仪器偏置和部分板级误差；
3. **按型号和温度档判限**：不要跨版本复制限值；
4. **预留 guard band**：考虑测试机误差、重复性、板面漏电和温漂。

## 十、常见误区速查

| 误区 | 正确理解 |
|---|---|
| 运放输出等于同相输入乘增益 | 放大的是 `V+−V−`，且只在开环线性区满足 |
| 开环增益 100 dB，所以电路就放大 10 万倍 | 闭环增益由反馈网络决定 |
| 虚短就是两输入物理短接 | 只是线性负反馈下电位近似相等 |
| 任何运放电路都能用虚短虚断 | 饱和、开环比较、正反馈振荡等场景不能机械套用 |
| Vos 只有正数 | 实际可正可负，手册常给绝对值或最大限值 |
| Vos 小就能接任意高阻信号源 | 还要检查 Ib × Rsource |
| GBW 高就不会出现大信号失真 | 还必须检查 SR |
| 轨到轨输出就能在任何负载下到电源轨 | 摆幅与负载电流有关 |
| CMRR 与 PSRR 只是名称不同 | 激励不同：共模同向变化，电源反向拉开 |
| 直接抄 LM358 的 7 mV 限值测所有版本 | 必须按厂家、后缀、温度和测试条件分档 |
| 测一次 Vos 就判定 | 应多次平均并评估重复性 |
| 测开环增益就断开所有反馈直接扫输入 | 输出极易饱和，应使用伺服环路稳定工作点 |

## 十一、公式速查

```text
开环：       Vout = AOL × (V+ − V−)
含失调模型： Vout = AOL × [(V+ − V−) + Vos]   （符号取决于 Vos 定义）
虚短：       V+ ≈ V−
虚断：       I+ ≈ I− ≈ 0
跟随器：     Acl = 1
反相：       Acl = −Rf/R1
同相：       Acl = 1 + Rf/Rg
差分：       Vout = (R2/R1)(V2−V1)  （电阻匹配时）
增益分贝：   Gain(dB) = 20 lg(Av)
共模电压：   Vcm = (V+ + V−)/2
CMRR：       20 lg(Ad/Acm)
PSRR：       20 lg(ΔVs/ΔVos)
正弦 SR 限制：fmax = SR/(2πVpeak)
LDO 输出：   Vout = Vref × (R1+R2)/R2
```

## 十二、自测题

1. 为什么开环增益很大的运放，反而不能简单开环当普通放大器用？
2. 虚短和虚断分别在什么条件下成立？
3. 反相与同相放大器的增益公式、输入阻抗有什么不同？
4. Vos、Ib、Ios 分别是什么，外部电阻为什么会把 Ib 变成电压误差？
5. GBW 和 SR 分别限制什么信号？
6. 为什么差分放大器的实际 CMRR 很依赖外部电阻匹配？
7. 为什么电阻分压能作基准信号，却不能给动态负载供电？
8. ATE 测 Vos 时为什么采用伺服放大，而不是直接测输出？
9. CMRR 与 PSRR 测试中，电源激励分别怎样变化？
10. 为什么 LM358 基础版和 B 版不能直接共用同一套判限？

参考要点：

1. 开环增益极大，µV 级差模输入就会让输出饱和；稳定放大必须依靠负反馈。
2. 负反馈、线性区未饱和，且输入共模电压在允许范围内。
3. 反相：`−Rf/R1`，输入阻抗约等于 R1；同相：`1 + Rf/Rg`，输入阻抗高。
4. Vos 是等效输入电压源；Ib 是输入电流，流经源电阻后产生 `Ib × Rsource` 的附加电压误差。
5. GBW 限制小信号带宽；SR 限制大信号电压变化速率。
6. 电阻失配会把共模分量转成差模分量，直接拉低整体 CMRR。
7. 分压网络输出阻抗高且没有反馈，负载一取电流，输出电压就明显下降。
8. mV、µV 级信号低于测试机的固定误差；先放大到 V 级再折算，才能稳定分辨。
9. CMRR：正负电源同向平移，共模电压变；PSRR：正负电源反向拉开，总电源电压变。
10. 两版的 Vos、AOL、温漂和测试条件不同，必须按型号与温度档分别查表。
