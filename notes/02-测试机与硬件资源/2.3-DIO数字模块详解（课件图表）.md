## P19 DIO功能模块概述

### 文字内容

> ● DIO模块--Digital Input/Output，也可称为数字波形输入输出模块。DIO作为数字测试机的核心功能模块，主要承担在芯片测试应用中，模拟不同的数字通信协议接口，比如常见的 SPI，I2C，UART，I2S等，以此来和芯片进行通信；达到输入数字波形到芯片，控制芯片进入到某种模式，或者对芯片输出的数字波形进行比较或者采集的工作的目的。

要点提炼：

- DIO = Digital Input/Output，即**数字波形输入输出模块**。
- 定位：数字测试机的**核心功能模块**。
- 作用：在芯片测试应用中模拟不同数字通信协议接口，常见协议有 **SPI、I2C、UART、I2S** 等，用于和芯片通信。
- 目的：① 向芯片输入数字波形、控制芯片进入某种模式；② 对芯片输出的数字波形进行**比较**或**采集**。

### 左图：SPI 接口协议波形

竖向自上而下共 5 条信号（左端标号从上到下依次为）：`WP`、`CS`、`CLK`、`MOSI`、`MISO`；波形图下方标注 **SPI 接口协议**。

| 信号 | 波形描述 |
|---|---|
| WP | 常态为低电平，前半段出现一个正向脉冲（先上升后下降回低） |
| CS | 常态为高电平，中间整体拉低形成一段低电平窗口（片选有效区间），前后各一次下降沿/上升沿 |
| CLK | 在 CS 低电平窗口内输出连续时钟脉冲串（图中约 17 个脉冲），窗口结束后停止 |
| MOSI | 在时钟脉冲期间按位变化；图中标注两组数据：`Cmd=0x8`、`Data=0x99` |
| MISO | 与 MOSI 对应位置图示为 `HIGH-Z`（高阻态），即该段期间器件不驱动 MISO |

## P20 DIO功能模块工作原理

本页为系统框图（原理框图），无表格。框图结构转录如下。

### 信号链（自左向右）

1. **上位机**（蓝色椭圆）—— 输入两个文件：
   - `PatternFile`
   - `TimingFile`
2. **DIO模块**（大虚线框）内的处理单元：
   - `Digital WaveForm Generate`（橙色块）—— 产生数字波形，输出标注 `Digital Waveform`，图示为 `0 1 0 1` 方波序列
   - `Digital WaveForm Capture&Compare`（绿色块）—— 采集与比较，双向与上位机交换数据；其输入侧图示为 `0 1 0 1` 波形，另有一路带上升/下降沿的时序波形输入
3. **PinLevel功能**（内部虚线框）—— 包含三级驱动/比较结构：
   - **Driver**（橙色三角形，上方）：输入参考电平 `VIH`、`VIL`；输出侧图示 `0 1 0 1` 波形；Driver 输出端并联 `CLH`、`CLL` 两个二极管符号（钳位）；输出到 `DIO_CHx`
   - **Compare**（绿色三角形，中间）：比较电平标注 `VOH`、`VOL`，比较门限标注 `VT`，电流标注 `IOH`、`IOL`
   - **Tristate out**（橙色三角形，下方）：输入参考电平 `VHH`、`VIH`、`VIL`；右侧标注纵轴刻度 **0V / 5V / 10V**，波形为三态输出脉冲
4. **输出端口**：`DIO_CHx`

| `DIO_CHx` | 最右侧 | DIO 通道输出 |
| `PatternFile` / `TimingFile` | 上位机 | 向量文件 / 时序文件 |

> ➢ Timing文件是一个WaveformTables波表的一个集合，每个WaveformTable定义了不同资源信号的波形格式，主要参数包含：波表名，波形周期，相关要使用的资源信号名，波形符号定义，在指定周期内的沿时刻点位置及状态等。

## P27 DIO功能模块之Pattern文件概述

### 文字内容

> ➢ Pattern文件中描述了不同信号预期输出或者比较的WFC的集合，即表示使用Timing文件中对应的WFT下的不同WFC进行波形拼接，予以达到实现模拟不同要求的数字波形输出或者比较采集的效果。

要点：Pattern 文件 = 不同信号**预期输出或比较的 WFC 的集合**；通过拼接 Timing 文件中对应 WFT 下的不同 WFC，实现所需的数字波形输出或比较采集。

### 左表：Pattern 示例

| Label | WFT | sequence | SDI | CLK |
|---|---|---|---|---|
| 0 | WFT1 | nop | 0 | 0 |
| YY | WFT1 | repeat 10 | 1 | 1 |
| 1 | WFT1 | nop | 0 | 2 |
| 2 | WFT1 | nop | 1 | 3 |
| XX | WFT1 | nop | L | H |
| AA | WFT1 | stop | H | L |

### 右表：Pattern 文件列参数说明

| 列号 | 列字段 | 说明 |
|---|---|---|
| 1 | Label | 标签，仅为标记字段，可写可不写，但特定微指令使用时必须有 |
| 2 | WFT | 当前行pattern使用的WaveformTable的名字 |

## P33 DIO功能模块之PinLevel功能模式配置详解

> ➢ SetMode(string strMode);

### 模式一：DIO模式

> 作为正常模式，就是我们常用到的打Pat及比较所使用到的一个模式。

```csharp
pinlevel.Signal("DIO_Grp").Connect()

```

### 模式二：FIX模式

> 作为直流输出模式，可输出范围为 **0~13.5V**，带载能力最大 **40mA**。

```csharp
pinlevel.Signal("DIO0").Connect(HIGH_VOLTAGE_MODE);
pinlevel.Signal("DIO0")..SetMode("FIX").SetFixLevel(7).Execute();
```

### 模式三：VHH模式

> 作为3态波形输出模式，若有高压态可输出最大 **1Mhz** 波形，三态波形仅有 **0，8，16，24** 等通道可输出。

```csharp
pinlevel.Signal("DIO0").Connect(HIGH_VOLTAGE_MODE).
pinlevel.Signal("DIO0")SetMode("VHH").SetVih(5).SetVil(0).SetVhh(13).Execute();
```

### 1.3 DIO 资源结构要点

- DIO = Digital Input/Output，数字波形输入输出模块，是数字测试机的核心功能模块；可模拟 SPI、I2C、UART、I2S 等协议（P19）。

- 使用流程 7 步：设计 Timing&Pattern → 下发 → 继电器闭合 → 设置 PinLevel → 运行 Pattern（输出&比较采集）→ 获取结果 → 继电器断开（P21）。
- PinLevel 可设置项 7 条：通道继电器闭合、Driver(VIH/VIL)、Compare(VOH/VOL)、Activeload(VT/IOH/IOL)、High Driver(VIH/VIL/VHH)、FIX(直流电平)、输入波形箝位（P31）。

### 4.2 微指令（Seq 指令）完整列表（P28 + P29 共 20 条）

| 编号 | Seq指令 | Seq参数 | 说明 | 备注 |
|---|---|---|---|---|
| 1 | nop | – | 空指令，顺序执行下一条向量 |  |
| 2 | repeat | Count | 循环指令，按照Count设置的次数，重复执行当前向量 | Count范围为2~65536 |
| 3 | jump | Label | 执行当前向量后无条件跳转至Label并继续执行 |  |
| 4 | loop | Cnt, Label | 按照Cnt设置的次数，循环执行下一条向量至Lable的向量集 | 可嵌套LOOP，共支持3层嵌套；循环体内支持NOP、REPEAT、TRIG；Count范围2~65536 |
| 5 | call | subpat | 与RETURN配合，跳转至subpat中执行，直到遇到RETURN后回到主pat的CALL指令的下一条向量 | 不支持CALL嵌套；不支持条件指令；SubPattern支持LOOP、NOP、REPEAT、TRIG |
| 6 | return | – | 与CALL配合，执行完当前向量后跳转到CALL指令的下一条向量 | subpat中特有 |
| 7 | scan |  | 进入SCAN模式，执行该条向量后的SCAN数据，使用方式：scan sh | SCAN数据的WFT周期延用当前Pat语句WFT周期，沿设置为第一组时刻沿状态 |
| 8 | stop | – | 停止执行向量，Pattern执行结束 | Pattern最后一条语句必须为STOP语句 |
| 9 | STV | – | SaveThisVector，保存当前指令 | 与Pattern->SetHRamMode参数配合使用 |
| 10 | LOOP_INF | Label | 无限块循环指令，从该行的下一行到Label行 | 与Pattern->SetHoldExit配合使用 |
| 11 | REPEAT_INF | – | 无限行重复指令，即当前行无限循环 | 与Pattern->SetHoldExit()配合使用 |
| 12 | Trig | Signal Name | 被触发的Signal的名称，多个Signal中间使用空格分开 | 触发AWG/DGT/TMU。示例：Trig AWG_CH0 DGT_CH0 |
| 13 | TRIG_FRC_START | – | 触发FRunClk开始 | – |
| 14 | TRIG_FRC_STOP | – | 触发FRunClk停止 | – |

| 19 | Imatch | Cnt, Label | 与COND_SET配合，执行当前向量后按条件判断是否跳转 | 符合条件退出执行下一行；不成立继续执行本行；执行Count次后仍不符合则跳转至Label；未设Label默认跳转到pattern最后一行 |
| 20 | Wait | 等待时间 | 执行完本条Vector后保持状态等待时间 | 例子：wait 10us |
