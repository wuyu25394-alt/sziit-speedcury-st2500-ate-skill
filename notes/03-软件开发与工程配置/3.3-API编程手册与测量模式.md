# ST2500 API 编程手册与测量模式

> 由 `6.编程手册-ST2500&&ST5000_API_20210721_V2.2.chm` 解包后整理。

## 4. API 编程手册（重点）

> 以下全部来自 CHM（API 手册 V2.2）。所有 API 均为**对象方法链式调用**风格：`对象.Signal("信号名").设置1().设置2().Execute()`。信号名必须是 Sig 或 Grp 文件中已定义的名称。

### 4.1 用户测试库开发流程

#### 4.1.1 测试项函数的标准宏结构

一个测试项即 `Test.cpp` 中的一个函数，**必须由 `USER_CODE` + `TEST_BEGIN` / `TEST_ERROR` / `TEST_END` 三段宏构成**：

```cpp
USER_CODE void VOH_TEST() {

TEST_BEGIN                      // 正常测试代码的起始标记（含异常捕获域开始）

    vector<ST_DIO_RESULT> comm_result;
    SetVdd(3.3);
    SetVdda(3.3);
    SetLevel(3.3);
    ppmu.Signal("PA4").SetMode("FIMV").CurrForce(100.0e-6)
        .VoltClamp(-2, 2).Execute();
    dio.Pattern("VOH_PAT").Run();
    dio.Pattern("VOH_PAT").GetFailResult(comm_result);

    PoweroffDevice();

    binObj.CheckResultAndBin(0, comm_result);

TEST_ERROR                      // 异常分支：只有上面代码抛出异常时才执行
    binObj.HandlerException(0);
TEST_END                        // 函数结束
}
```

| 宏 | 作用 |
|---|---|
| `USER_CODE` | 测试项函数声明前缀，标记这是用户测试代码函数 |
| `TEST_BEGIN` | 正常流程起点；与 `TEST_ERROR`、`TEST_END` 一起构成异常保护结构 |
| `TEST_ERROR` | 异常处理段。**`binObj.HandlerException(uiHandleCode)` 必须放在这里** |
| `TEST_END` | 函数结束 |

#### 4.1.2 异常处理

```cpp
binObj.HandlerException(unsigned int uiHandleCode);
```
| uiHandleCode | 行为 |
|---|---|
| `0` | 工厂模式 → **退出 ATE 系统**；开发模式 → **停止测试** |
| `1` | 跳过当前测试函数，恢复运行环境，运行下一个测试函数 |

> 原文强调："测试脚本中需要添加宏：`TEST_BEGIN`、`TEST_ERROR`、`TEST_END`"。

#### 4.1.3 编译与被调用方式

- **DLL 导出 / 导出函数名约定 / 库加载路径**：**CHM 中未涵盖**。CHM 只说明测试函数写在 `Test.cpp`，由 tmf 生成的函数名与 `Test Function` 列对应。
- 编译：由 UI 的 **Build Tool** 调用工程内 **Makefile** 完成；changelog 提及"更新测试用例"，但未给编译器、编译选项、链接库清单。
- 运行入口：`Prj Run`（UI）；Runner 进程执行 Load 后的 Job。

#### 4.1.4 典型测试项编写范式（摘自手册示例）

```cpp
// 上电辅助函数
void PowerOnVdd(double dbVoltage){
    dps.Signal("VDD").SetMode("FVMI")
        .VoltForce(dbVoltage)
        .CurrRange(0.5)
        .CurrClamp(0.5, -0.5)
        .Execute();
    sys.DelayUs(1000);
}

// 参考电平设置
void SetLevel(double dbVoltage){
    pinlevel.Signal("LVLPINS_GRP").SetMode("DIO")
        .SetVih(dbVoltage)
        .SetVil(0)
        .SetVoh(dbVoltage*0.7)
        .SetVol(dbVoltage*0.3)
        .VoltClamp(6.0, -2.0)
        .Execute();
    sys.DelayUs(1000);
}
```

### 4.2 `sys` 模块（Sys）

用于**非 AFE 模块资源的通用设置**：选择/复位测试 Site、延时、打印 Datalog。

| 方法 | 签名 | 说明 |
|---|---|---|
| `DelayUs` | `sys.DelayUs(unsigned long usCnt)` | 等待延时，单位 **us** |
| `GetActiveSite` | `sys.GetActiveSite(unsigned long long ulSite)` / `(ULARGE_LONGLONG ulSite)` | 取当前有效 Site，**按位**："1"=Active，"0"=Disable，最低位=Site0。`unsigned long long` 最大支持 **64 sites**；`ULARGE_LONGLONG` 为 16 元素数组，最大支持 **1024 sites**（site0~63 放 `ulSite[0]`） |
| `GetSite` | `sys.GetSite(unsigned long long ulSite)` / `(ULARGE_LONGLONG ulSite)` | 取**当前运行中且尚未被 BIN 出去**的 Site。并行测试时与 `GetActiveSite` 相同；**串行测试（`FOR_EACH_SITE_START` 内）时只返回当前 SITE_ID 的位**（即 2^SITE_ID） |
| `SetSelectSite` | `sys.SetSelectSite(ULARGE_LONGLONG ulSite)` / `(unsigned long long ulSite)` / `(ENUM_SITE_BIT_TYPE type=EN_ALL_SITE)` | 选择指定 Site（按位）。枚举：`EN_ODD_SITE`（奇数）、`EN_EVEN_SITE`（偶数）、`EN_ALL_SITE`（全部） |
| `ResetSelectSite` | `sys.ResetSelectSite()` | 复位选择的 Site，**与 `SetSelectSite` 配对使用** |
| `SetSiteState` | `sys.SetSiteState(unsigned long ulSiteID, bool enabled)` | Enable/Disable 指定 Site；`ulSiteID` 对应 Sig 中 Site 编号，支持 0~1023 |
| `FOR_EACH_SITE_START ... NEXT_SITE` | `FOR_EACH_SITE_START(Site, SITE_ID) ... NEXT_SITE` | 所有 Active Site **串行**执行。`Site` 是第几个 ActiveSite（0~1023），`SITE_ID` 是该 Site 的真实 ID（0~1023）。**必须成对使用** |
| `PrintDatalog` | `sys.PrintDatalog(const char* fmt, ...)` | 向 Datalog 打印自定义 Log；格式符 `%d` `%f` `%c` `%s` |

```cpp
// 只对 Site0 做寄存器配置
sys.SetSelectSite(1);                       // 2^0
dio.Pattern(pat_site0_config).Run();
sys.ResetSelectSite();
```

### 4.3 `dps` 模块（Device Power Supply）

单模块 **4 Channel**。DPS 是 DUT 供电主路径。

| 方法 | 签名 | 关键参数与约束 |
|---|---|---|
| `Signal` | `dps.Signal(string strSignal)` | 指定 Sig/Grp 中 DPS 类型信号（信号组名），是所有后续接口的基础 |
| `Connect` | `dps.Signal(str).Connect()` | 闭合机械 Relay。**必须加等待时间（建议 8~10ms）**；不建议频繁 Connect/DisConnect |
| `DisConnect` | `dps.Signal(str).DisConnect()` | 断开 Relay，同样需 8~10ms 等待 |
| `SetMode` | `.SetMode(string strMode)` | `"FVMV"`(输出电压测电压)、`"FVMI"`(输出电压测电流)、`"FNMV"`(不输出测电压) |
| `VoltForce` | `.VoltForce(double dbVoltage)` | 范围 **-3.25 ~ +8.4 V**；默认使能电流箝位，箝位值为当前电流量程 |
| `CurrRange` | `.CurrRange(double dbCurRange)` | 档位：**5uA、25uA、250uA、2.5mA、25mA、500mA**（默认 5uA）。填入值不在档位中时**自动匹配大于设置值的档位**。**Gang 模式电流档位只能设 500mA** |
| `CurrClamp` | `.CurrClamp(double dbClampHi, double dbClampLo)` | 普通模式 ±0.5A；Gang 模式 ±2A。**必须先设 `CurrRange` 再设 `CurrClamp`**；`dbClampHi > dbClampLo`。Gang 模式下为并联通道电流之和 |
| `Alarm` | `.Alarm(unsigned long ulAlarmType, E_ALARM_BEHAVIOR_TYPE alarmBehavior)` | 报警类型：`E_DPS_ALARM_CLAMP`（钳位提醒）、`E_DPS_ALARM_KELVIN`（未使用开尔文连接）、`E_DPS_ALARM_OPEN_SENSE`（SENSE 未连接） |
| `AlarmClear` | `.AlarmClear()` | 清除报警信息 |
| `Execute` | `dps.Execute()` | 下发全部配置 |
| `Measure` | `dps.Measure(vector<ST_MEAS_RESULT> DpsResult, unsigned long ulResultType, unsigned long ulSampleSize, unsigned long ulSampleInterval)` | 见下 |

**Gang 模式**（在 Sig 文件定义 `DPS_GANG2/3/4`）：

| Gang 模式 | 输出电流 | 备注 |
|---|---|---|
| `DPS_GANG2` | 1A | 两通道 Gang |
| （同名，原文如此） | 1.5A | 三通道 Gang |
| `DPS_GANG4` | 2A | 四通道 Gang |

> **Gang 模式是从小通道号到大通道号组合，不能反向**：DPS1 通道设为 `DPS_GANG2` 执行的是 1、2 通道组合，而不是 0、1。对应物理通道 Force 端需短接。

```cpp
// FVMI：输出 3V，电流档 500mA，高箝位 1A 低箝位 -1A
dps.Signal("DPS_CH0").Connect();
sys.DelayUs(8000);
dps.Signal("DPS_CH0").SetMode("FVMI")
    .VoltForce(3.0).CurrRange(500.0e-3).CurrClamp(1, -1).Execute();
sys.DelayUs(2000);
vector<ST_MEAS_RESULT> DpsResult;
dps.Measure(DpsResult, MEAS_AVG, 1, 10);
for(unsigned long i = 0; i < DpsResult.size(); i++)
    cout << DpsResult[i].strSigName << " " << DpsResult[i].ulSite
         << " " << DpsResult[i].dbValue << endl;
dps.Signal("DPS_CH0").SetMode("FVMI").VoltForce(0.0)
    .CurrRange(500.0e-3).CurrClamp(1, -1).Execute();
dps.DisConnect();
sys.DelayUs(8000);
```

### 4.4 `ppmu` 模块（Per-Pin PMU）

与 DIO 通道 1:1 对应（**32 通道/板**）。主要做电压/电流的输出与测量。

| 方法 | 签名 | 关键参数与约束 |
|---|---|---|
| `Signal` | `ppmu.Signal(string strSignal)` | 必须是 **DIO 类型**的信号/信号组名 |
| `Connect` / `DisConnect` | `.Connect()` / `.DisConnect()` | 连接/断开 PPMU 通道至 DUT |
| `SetMode` | `.SetMode(string strMode)` | `"FVMV"`、`"FVMI"`、`"FIMV"`、`"FIMI"`、`"FNMV"` |
| `VoltForce` | `.VoltForce(double dbVoltage)` | 范围 **-2.0 ~ +6.5 V**；需 FV 模式；输出/测量电压 Range 默认 6.5V **不可调**；默认使能箝位（低 **-2.5V**、高 **+7.5V**） |
| `CurrForce` | `.CurrForce(double dbCurrent)` | 范围 **-40mA ~ +40mA**；需 FI 模式 |
| `CurrRange` | `.CurrRange(double dbCurRange)` | 档位：**2uA、10uA、100uA、1mA、40mA**（自动匹配接近档位） |
| `VoltClamp` | `.VoltClamp(double dbClampHi, double dbClampLo)` | 须在 **-2 ~ +6.5V** 内且 `Hi > Lo`；默认使能 |
| `Alarm` / `AlarmClear` | `.Alarm(unsigned long, E_ALARM_BEHAVIOR_TYPE)` / `.AlarmClear()` | 例：`E_PPMU_ALARM_CLAMP` |
| `Execute` | `ppmu.Execute()` | 下发所有配置并启动 |
| `Measure` | `ppmu.Measure(vector<ST_MEAS_RESULT>& PpmuResult, unsigned long ulResultType, unsigned long ulSampleSize, unsigned long ulSampleInterval)` | 见 [6.1](#61-st_meas_result) |

```cpp
// FIMV：加 -100uA 测电压（OS 二极管测试经典用法）
ppmu.Signal("OSPINS_GRP").SetMode("FIMV")
    .CurrForce(100e-6).CurrRange(100e-6).VoltClamp(2, -2).Execute();
sys.DelayUs(1000);
vector<ST_MEAS_RESULT> MEAS_RESULT;
ppmu.Measure(MEAS_RESULT);
binObj.CheckResultAndBin(0, MEAS_RESULT, 17);   // 从第 0 个子项起比较 17 个子项
```

| 方法 | 关键参数 |

### 4.7 `pinlevel` 模块（PLVL 引脚电平）

设置测试时各 DIO 通道的 Level。**必须先 `Signal()` 指定 DIO 类型信号**。

| 方法 | 签名 | 关键参数与约束 |
|---|---|---|
| `Signal` | `pinlevel.Signal(string strSignal)` | DIO 信号名或信号组名 |
| `Connect` | `.Connect(unsigned long ulMode)` | `NORMAL_MODE`（电平 -1.5~6.5V 时，默认）或 `HIGH_VOLTAGE_MODE`（VHH / FIXLevel 模式，输出超 6.5V）。**动作稳定时间 5ms 以内** |
| `DisConnect` | `.DisConnect()` | 断开继电器，测试完成后复位时调用 |
| `SetMode` | `pinlevel.SetMode(string strMode)` | `"DIO"` 普通 DIO；`"FIX"` 输出固定电平；`"VHH"` 高压模式（**仅通道 0、8、16、24**，且需在 Tim 中把该管脚 WFC 设为 `T`） |
| `SetVih` | `.SetVih(double)` | **-1.4 ~ +6.5 V** |
| `SetVil` | `.SetVil(double)` | **-1.5 ~ +6.4 V** |
| `SetVoh` | `.SetVoh(double)` | **-1.4 ~ +6.5 V** |
| `SetVol` | `.SetVol(double)` | **-1.5 ~ +6.4 V** |
| `SetFixLevel` | `.SetFixLevel(double)` | **0 ~ 13.5 V**；仅 DIO 的 **0、8、16、24** 通道可用，其他通道配置会异常报错 |
| `SetVhh` | `.SetVhh(double)` | **0.0 ~ 13.5 V**；仅 0、8、16、24 通道 |
| `SetActiveLoadStatus` | `.SetActiveLoadStatus(STATUS_TYPE)` | `ON` 打开 / `OFF`（默认）关闭 ActiveLoad |
| `SetVt` | `.SetVt(double)` | **-1.5 ~ 6.5 V**（DIO 模式） |
| `SetIoh` | `.SetIoh(double)` | **-25mA ~ 0mA** |
| `SetIol` | `.SetIol(double)` | **0mA ~ 25mA** |
| `VoltClamp` | `pinlevel.VoltClamp(double ClampHi, double ClampLo)` | 钳位须在 **-2 ~ +6.5V** 内且 `Hi > Lo`；**默认钳位使能** |
| `Execute` | `pinlevel.Execute()` | 执行所有配置 |

```cpp
pinlevel.Signal("DIO_Grp").Connect();
sys.DelayUs(2000);
pinlevel.Signal("DIO_Grp")
    .SetMode("DIO").SetVih(5.0).SetVil(0.0).SetVoh(3.5).SetVol(0.7)
    .SetActiveLoadStatus(OFF).SetVt(0).SetIoh(0).SetIol(0)
    .VoltClamp(5.5, -1.0).Execute();
sys.DelayUs(1000);
pinlevel.Signal("DIO_Grp").DisConnect();
```
> 原文示例中 `SetIoh(-10e-3)` 写作 `-10mA`、`SetIol(10e-3)` 写作 `10mA`，但**参数单位实为 A**（范围说明处的 mA 是笔误）。以 `double` 传 A 为准。

### 4.8 `dio` 模块（DIO 数字 I/O）

`dio` 是**容器对象**，本身无直接测量方法，提供 4 个子对象：

| 子对象 | 说明 |
|---|---|
| `dio.Timing()` | Timing 模块对象 |
| `dio.Pattern(strPatName)` | Pattern 模块对象 |
| `dio.FRunClk()` | FRunClk 模块对象 |
| `dio.DIO微指令` | 微指令（见 4.10） |

#### 4.8.1 `dio.Timing()` — Timing 时序

| 方法 | 签名 | 说明 |
|---|---|---|
| `Load` | `dio.Timing().Load(string strFileName)` | **必须用 tim 文件的绝对路径**（例 `D:\\MINI-ATE\\workspace\\Sample_MCU\\Sample_MCU.tim`）。重新加载需先 `UnLoad` |
| `UnLoad` | `dio.Timing().UnLoad()` | 卸载已加载的 tim；**若已加载 Pattern 也需同步 UnLoad Pattern** |
| `UpdateWfc` | 语法1 `UpdateWfc(string strTset, string strSigName, char chWfc, string strEdge)`；语法2 `UpdateWfc(string strTset, string strSigName, EN_EVENT_MARK eventmark, string strTime)` | 动态改 WFC 对应的 Event。多 Event 用 `,` 分割。改 Edge+Time 建议用语法2 |
| `UpdatePeriod` | `dio.Timing().UpdatePeriod(string strTset, string strPeroid, bool bscale=false)` | **最大 250us、最小 8ns**；字符串需带单位（us/ns/ps）；`bscale=true` 时同步按比例缩放 Edge |
| `GetPeriod` | `dio.Timing().GetPeriod(string strTset, string &strPeroid)` | 取周期（回读为大写，如 `1000NS`） |
| `GetWfc` | `dio.Timing().GetWfc(string strTset, string strSig, char chWfc, string &strWfcEvent)` | 例回读 `U,0NS,X,0NS,X,0NS,X,0NS` |

**`EN_EVENT_MARK` 枚举**（Timing 与 Shmoo 共用）：

| 成员 | 说明 |
|---|---|
| `EN_EVENT_MARK_D0` | Driver 第 1 个 Edge（修改指定信号所有 Driver WFC 的第 1 个 Edge） |
| `EN_EVENT_MARK_D1` | Driver 第 2 个 Edge |
| `EN_EVENT_MARK_D2` | Driver 第 3 个 Edge |
| `EN_EVENT_MARK_D3` | Driver 第 4 个 Edge |
| `EN_EVENT_MARK_R0` | Compare 的 Edge |

```cpp
dio.Timing().Load("D:\\MINI-ATE\\workspace\\Sample_MCU\\Sample_MCU.tim");
dio.Timing().UpdateWfc("PASSCODE_TIMING", "PA0", '1', "D,U");
dio.Timing().UpdatePeriod("PASSCODE_TIMING", "1000ns");
string strPeroid, strWfcEvent;
dio.Timing().GetPeriod("PASSCODE_TIMING", strPeroid);
dio.Timing().GetWfc("PASSCODE_TIMING", "PA0", '1', strWfcEvent);
dio.Timing().UnLoad();
```

#### 4.8.2 `dio.Pattern(strPatName)` — Pattern 控制（最常用）

`strPatName` 对应 **pat 文件中的 Pattern Set Name**。

| 方法 | 签名 | 说明 |
|---|---|---|
| `Load` | `.Load(string strFileName)` | 向内存下载 Pattern，如 `...\\Pattern\\vopu_pat.csv` |
| `UnLoad` | `.UnLoad()` | 卸载内存中的 Pattern |
| `SetHRamMode` | `.SetHRamMode(ENUM_CAPTURE_MODE enMode=EN_NORMAL_MODE, bool bReptCompress=false)` | HRam 存储模式 |
| `SetTrigMode` | `.SetTrigMode(ENUM_TRIG_MODE enMode=EN_FIRST_MODE, bool enableEvent=false, unsigned long PreTrigCycleCnt=0, bool StopOnFull=true)` | HRam 触发模式；**HRam 最多存 1024 条 Vector**；`EN_LABEL_MODE` 时 `StopOnFull` 只能为 true |
| `SetLabelEvent` | `.SetLabelEvent(string strlabel, unsigned long ulOffset, bool enable)` | 须先把 `SetTrigMode` 设为 `EN_LABEL_MODE` |
| `SetInitStatus` | `.SetInitStatus(string strPinList, ENUM_INIT_STATUS)` | **"目前暂未支持"**（原文） |
| `SetTimeOut` | `.SetTimeOut(unsigned long ulTimeOutMs=1000)` | 超时，单位 ms |
| `Run` | `.Run(string startLabel = "")` | 运行 Pattern（**不阻塞**），`startLabel` 为空时从第一行开始 |
| `StartStop` | `.StartStop(string StartLabel="", string StopLabel="")` | 运行指定区间段；不传参则运行整个 Pattern |
| `Test` | `.Test()` | 运行**并等待**结束（内部已含 `WaitEnd()`，默认超时 1000ms）。**要打印 Pattern 详细执行信息必须用 `Test()`** |
| `WaitEnd` | `.WaitEnd()` | 阻塞等待 Pattern 结束 |
| `Stop` | `.Stop()` | 停止运行 Pattern |
| `GetHoldStatus` | `.Run().GetHoldStatus(bool &bHold)` | `[0]` 无 Hold，`[1]` 处于 Pattern Hold。需配合微指令 `REPEAT_INF` / `LOOP_INF`，且不能与其他微指令嵌套 |
| `SetHoldExit` | `.SetHoldExit()` | 结束**当前** Hold 状态（非所有） |
| `UpdateVctBlockData` | `.UpdateVctBlockData(string strLabel, unsigned long ulOffset, string PinList, string strWfclist[], unsigned long ulVctCnt)` | 替换多行 Vector（仅内存，不改文件） |
| `UpdateVctData` | `.UpdateVctData(string strLabel, unsigned long ulOffset, string PinList, string strWfc)` | 替换**单行** Vector |

### 4.9 `tmu` 模块（Time Measurement Unit）

TMU 提供频率、占空比、事件采集、上升/下降时间、通道延迟、脉宽等时间参数测量。单板 **4 通道**（默认复用 DIO 0/1/16/17）。

| 方法 | 说明 |
|---|---|

| 子模块 | 特性 |
|---|---|
| `Freq` | `SetSampleSize` **2~512**（默认 2）。周期性信号需 2 个采样点算 1 个频率；设 10 个点则内部算 5 个频率取均值 → **多设 samplesize 可提高精度**。**未获取到频率时返回结果为 0** |

### 4.10 DIO 微指令（Seq 指令）完整表

| 编号 | Seq 指令 | 参数 | 参数说明与使用限制 |
|---|---|---|---|
| 1 | `[C]nop` | — | 空指令，顺序执行下一条 vect |
| 2 | `[C]stop` | — | 停止执行向量，Pattern 结束。**Pattern 最后一条语句必须为 STOP** |
| 3 | `[C]repeat` | `Count` | 重复执行当前 vect，**Count 2~65536** |
| 4 | `[C]REPEAT_INF` | — | 无限重复，须与 `Pattern.SetHoldExit()` 配合 |
| 5 | `[C]jump` | `Label` | 执行当前向量后无条件跳转到 Label |
| 6 | `[C]loop` | `Count Label` | 循环执行"loop 下一行"到"Label 所在行"；**可嵌套 LOOP，共支持 4 层**；循环体内支持 NOP/REPEAT/TRIG；**Count 2~65536** |
| 7 | `[C]LOOP_INF` | `Label` | 无限循环，须指定标签；须与 `Pattern.SetHoldExit()` 配合 |
| 8 | `MJump` | `Label` | 与 `COND_SET` 配合；条件成立跳转，否则顺序执行 |
| 9 | `Set_Mloop` | `Count,Label` | 与 `EXT_MLOOP` 配合；Count 2~65536，**Count=0 时一直循环** |
| 10 | `Ext_Mloop` | `Label` | 与 `COND_SET`、`SET_MLOOP` 配合，放在循环体最后一条向量上 |
| 11 | `[C]call` | `Subpat 的 Name` | 与 `RETURN` 配合；**不支持 CALL 嵌套、不支持条件指令；SubPattern 不支持 LOOP/NOP/REPEAT/TRIG** |
| 12 | `return` | — | 与 `CALL` 配合，跳回 CALL 的下一条向量 |
| 13 | `[C]scan SH` | — | 进入 SCAN 模式；SCAN 信号的 Timing 与主 Pattern 不一致时需定义新 Timing；**需 scan 的信号名后加 `[SI]`/`[SO]`** |
| 14 | `Cond_Set` | `CMP_FAIL` / `CMP_PASS` | 与 `MJump`、`Mloop` 配合设置 Match 条件 Flag；**只能使用其中一种** |
| 15 | `ext_mloop Label` | `Label` | 与 Mloop 配合，符合 Match 条件则跳转（例 `ext_mloop 100`） |
| 16 | `Cond_Clr` | — | 清除设置的条件 Flag |
| 17 | `[C]trig` | `Signal Name` | 被触发的 Signal 名。**一个 Pattern 中只能 Trig 一种类型的 AFE 模块** |
| 18 | `TRIG FRC_START` | — | 触发 FRunClk 开始 |
| 19 | `TRIG FRC_STOP` | — | 触发 FRunClk 停止 |
| 20 | `[C]STV` | — | SaveThisVector，保存当前指令所在行所有 Vector；与 `SetHRamMode()` 的 enMode 参数配合 |

> 注：`[C]` 为可选项，表示该 Seq 记录保存至 Capture Mem 内，与 `SetHRamMode(EN_CAP_MODE)` 配合使用。`Label` 为当前 Vector 的 Label 名。

**微指令限制汇总（CHM 原文）**

- **Jump**：目标地址不能用 `CALL`/`SCAN SH`/`MATCH_JUMP`/`SET_MLOOP`/`COND_SET`；**跳转地址范围 4K**；只能跳转至更大的目标地址。
- **COND_SET**：与 `SET_MLOOP`/`MJUMP` 配合时**中间不能插入任何指令**，需连续使用 MJump。
- **MJump**：后 512 条向量内及跳转至 Label 后 512 条向量内，勿用 `MATCH_JUMP`/`CALL`/`SET_MLOOP`/`EXT_MLOOP`；**MJUMP 不记录 FAILCNT**，HISTDATA 的 FAIL_FLAG 恒为 0；对应 WAVE FORMAT 参数**只能含单个沿**；比较沿含 `X` 时不跳转、顺序执行；MJump 下一条向量作为 match 结果判断向量，**该向量最小周期 80ns**。
- **LOOP**：内部向量时长需 **> 24ns**；内部勿用 `MATCH_JUMP`/`CALL`/`JUMP`/`SET_MLOOP`/`EXT_MLOOP`；**结束地址处不支持 JUMP、COND_SET**；**Loop 指令结束位置只允许放置 NOP**；**Loop 地址范围 4K**。
- **SET_MLOOP**：之前必须用 `COND_SET` 设 Match 条件；需与 `EXT_MLOOP` 配合，`EXT_MLOOP` 放循环体最后一条向量；内容执行向量时长需 **> 24ns**（该向量 Compare 位置与周期结束时刻预留 20ns）；**循环向量集总数不超过 4096 条**；Set_Mloop 对应 HRAM 只记录 Start_Addr 与 End_Addr 两条向量；`EXT_MLOOP` 所在行不参与 Match 条件；MLOOP 内若无 Compare 功能向量，**只执行一次且不跳转**；MLOOP 内每条向量**至少有一个 DIO 通道使用 Compare**，否则 Match 不成功；**SET_MLOOP 内部不支持 Loop/Jump**；该向量 Compare 位置与周期结束时刻预留 **80ns**。
- **EXT_MLOOP**：后 512 条向量内及跳转至 Label 后 512 条内，勿用 `MATCH_JUMP`/`CALL`/`SET_MLOOP`/`EXT_MLOOP`。
- **Loop_Inf**：`pat period = 4ns` 不支持 loop_inf；`5~8ns` 内部执行 pat 条数 ≥ 100；`9~12ns` ≥ 50；`12~23ns` ≥ 25；`>= 24ns` ≥ 2。
- **CALL/Return**：被调子向量集内勿用 `MATCH_JUMP`/`CALL`/`SET_MLOOP`/`EXT_MLOOP`；**subpat 内部不支持除 repeat 外的其它指令**。
- **Scan**：针对 SCAN IN / SCAN OUT 信号，需在信号名后加 `[SI]`/`[SO]`；SCAN 行在 Sequence 列加 `"scan SH"`；下一行填 scan data，Label 列填 scan data 信号名，WFT 列填 scan data。**SCAN 数据内部不支持切换 DIO 数据方向**（单个 SCAN 数据只支持 Driver 或 Compare 模式）；scan data 中 `U` 表示高电平 1、`D` 表示低电平 0；**每行 Vector 最大运行 1024 个输入/输出数据**。
- **Trig**：PAT 文件**只支持一次 TRIG**，Trig 一次当作 START；Trig 的信号 STOP 通过调用 API 实现。
- **STV**：与 `StartStop()` 配合时，**STOP Label 行不要使用 STV 指令**（否则 STOP Label 所在行不往 HRAM 存 Vect）。

## 5. 测量模式缩写表完整解释

### 5.1 命名规则

模式字符串由 **4 个字母**组成，格式为 **`F<X>M<Y>`**：

```
F  = Force （施加 / 驱动）
X  = V (Voltage，电压) 或 I (Current，电流) 或 N (None，不施加)
M  = Measure （测量）
Y  = V (Voltage，电压) 或 I (Current，电流)

即："Force X Measure Y" —— 第 3、4 个字母表示"测什么"。
```

> **注意**：任务描述里的 `FMIM` 在 CHM 中**不存在**。CHM 实际出现的模式只有 **FVMV / FVMI / FIMV / FIMI / FNMV** 五种。`FMIM` 应纠正为 `FIMV`（Force 电流 Measure 电压）或 `FIMI`（Force 电流 Measure 电流）。

### 5.2 四种"Force X Measure Y"象限模式

| 模式 | 全称 | 物理含义 | 测量结果单位 | 典型使用场景 |
|---|---|---|---|---|
| **`FVMV`** | Force Voltage, Measure Voltage | 强制（驱动）指定电压，同时测量（回读）实际电压 | **V（电压）** | 1) 给 DUT 供电并回读实际电压（验证负载调整率、IR Drop）；2) PPMU/BPMU/DPS 输出电压精度验证；3) 电源拉偏测试中确认被拉偏的落点电压 |
| **`FVMI`** | Force Voltage, Measure Current | 强制电压，测量流过该引脚的电流 | **A（电流）** | **最常用的电源模式**。ICC/IDD 静态电流、工作电流、漏电流测量；PPMU 测 IO 驱动能力（加电压测电流）；VOPD 测试中把 IO 拉高然后测灌入电流 |
| **`FIMV`** | Force Current, Measure Voltage | 强制电流，测量引脚上产生的电压 | **V（电压）** | **OS（Open/Short）二极管测试的经典模式**：给 IO 加 ±100uA，测二极管正向压降（上二极管 0.2~1.2V，下二极管 -1.2~-0.2V）。也用于测接触电阻、通路阻抗、Vt/I-V 曲线取点 |
| **`FIMI`** | Force Current, Measure Current | 强制电流并测量电流（本质上是电流源+电流回读） | **A（电流）** | 需要精确设定电流注入并回读实际注入值，或做电流源精度/合规（compliance）验证；PPMU 的 20mA 电流源示例 |
| **`FNMV`** | Force None, Measure Voltage | **不施加任何激励**，仅测量电压（高阻监听） | **V（电压）** | **只测不驱动**：PVD 测试中测量 PA7 管脚电压（须先把 DPS 与参考电平设好）；测量 DUT 自有的输出电压、待机电压；测试项收尾把通道复位成"不驱动"状态（例：OS 测试结束后 `SetMode("FNMV").Execute()` 复位） |

### 5.3 各模块支持的模式对照（CHM 实测）

| 模块 | 支持的模式 | 出处 |
|---|---|---|
| `dps` | `FVMV`、`FVMI`、`FNMV`（**不支持 FIMV / FIMI**） | `3_API_DPS` |
| `ppmu` | `FVMV`、`FVMI`、`FIMV`、`FIMI`、`FNMV`（**五种全支持**） | `7_API_PPMU` |
| `bpmu` | `FVMV`、`FVMI`、`FIMV`、`FIMI`、`FNMV`（**五种全支持**） | `8_API_BPMU` |
| `rvs` | 仅 `FVMV`、`FVMI`（**仅 FV 模式**） | `4_API_RVS` |

### 5.4 与模式的常见搭配约束

| 模式类别 | 必须配套设置的参数 | 说明 |
|---|---|---|
| FV 类（FVMV / FVMI） | `VoltForce()` | 设置强制电压；`FNMV` 不需要 |
| FI 类（FIMV / FIMI） | `CurrForce()` + `CurrRange()` | 设置强制电流与电流档位；**FI 类必须设电流档位才能保证精度** |
| 测量电流（FVMI / FIMI） | `CurrRange()` | 电流测量档位，决定测量精度与箝位默认值 |
| 测量电压（FVMV / FIMV / FNMV） | `VoltClamp()`（PPMU/BPMU）或 `CurrClamp()`（DPS） | 保护测试机与 DUT。**PPMU `FNMV` 只测电压不需要 VoltForce** |
| MV 类输出 | 结果为**电压，单位 V** | 见各 Measure 接口说明 |
| MI 类输出 | 结果为**电流，单位 A** | 见各 Measure 接口说明 |

### 6.11 返回值与错误码约定

- **`binObj.CheckResult(...)` 返回 `bool`**：`true` = 比较结果正常，`false` = 比较失败。这是 CHM 中**唯一明确给出返回值类型**的接口族。
- **`math.GetValue(...)` 返回 `double`**（数值）或 **`bool`**（Pattern Pass/Fail）。
- **其余接口无返回值**（均通过参数引用或 `vector` 出参回传）。
- **统一错误码表 / 错误码枚举（如 `ERR_xxx`）/ 异常类**：**CHM 中未涵盖**。CHM 只提供基于宏的异常处理机制（`TEST_BEGIN` / `TEST_ERROR` / `TEST_END` + `binObj.HandlerException(uiHandleCode)`，`uiHandleCode` 仅 `0`/`1` 两个取值），**没有定义具体错误码编号或错误信息字符串**。

### 7.6 校准板与硬件连接（P.248–P.250）

**校准所需资源（4 项）**
1. **2612 一台**，用于校准测量；
2. **电源一台**，用于校准供电；
3. **校准板一块**；
4. **机箱一套**。

**校准板三个标记位**

| 标记 | 用途 |
|---|---|
| 标记 1 | 通过 **DUT 线缆**连接待校准的 AFE 业务板 |
| 标记 2 | 用于连接**测量仪表**（测量仪表与计算机连接以存储测试结果） |
| 标记 3 | 用于连接**电源**，为校准时供电 |

**连接步骤（原文）**
1. 用 **DUT 线缆**连接待校准的 AFE 板卡；
2. 用**带老虎夹的表笔**连接**标记 2 和 2612 测试源**；
3. 将**电源正负表笔连接标记 3（红正黑负）**；
4. 校准前**先判断环境是否连接正确**，确认**校准板电源指示灯为绿色常亮**；
5. 通过 UI 软件启动校准；
6. **校准完成后，测试机断电，断开校准部件**。

### 7.7 校准周期与环境要求

- ST2500 属于精密测量仪器，**需要定期校准以保证测量精度**（P.243）。
- 环境要求（P.52）：
  - 工作温度 **+20℃ 至 +30℃**；
  - **误差校正温度范围 23℃(±5℃)，且与校准温度的偏差 < 1℃**；
  - 湿度 40%RH ~ 60%RH（无冷凝）；
  - 海拔 0~2000 米；振动 0.21G 最大值，5Hz~500Hz。
- 非工作环境：温度 -10℃~+60℃，湿度 20%RH~90%RH（无冷凝），海拔 0~4572 米，振动 0.5G/5~500Hz。

### 7.8 校准相关的 API

**CHM 中未涵盖校准 API**。CHM 33 个文件均为测试执行类接口（Sys / CBIT / DPS / RVS / PLVL / DIO / PPMU / BPMU / TMU / AWG / DGT / CWaveCalc / Math / BinDef / Prober / Shmoo / Pattern 系列），**没有 Calibration 对象或校准方法**。校准只能在 UI 的校准界面完成。

## 8. 常见问题、报错含义与注意事项

### 8.1 工程与编译类

| 现象 / 报错 | 原因与处理 |
|---|---|
| 直接 Load 弹出错误提示，Job 项目**变红** | 未先 Build。**必须先 Build 成功再 Load** |
| 无法 Load 另一个 Job | **一次只能 Load 一个 Job**；有已 Load 的项目时无法 Load 其它。切换工程**建议重启软件** |
| 改了 Test.cpp 后测试结果不变 | 必须 **Unload Job → 重新 Build → 再测试** |
| Build 失败 | 在 Build Dialog 看 Make 输出，查 Problems 视图 |
| Sig 文件中 Signal 名标红、保存时弹重名提示 | **Signal 名不可重复** |
| 新增 Signal 未填参数，参数位置变红 | 必填项未填，填好后恢复 |
| 未选 Site 就新增 Signal | **必须先 Add Site 才能 New Signal** |
| Test.cpp 中同时用 VDD 和 VDDA 报错 | 资源被设为 Share，两个 Signal 不可同时使用。改资源分配 |
| 打开 JobExplore 要求密码 | 工厂界面打开测试工程需输入 **`dev`** 密码 |

### 8.2 Pattern / Timing 类

| 现象 / 报错 | 原因与处理 |
|---|---|
| 编辑 Pattern 时报错 | 添加的芯片管脚**必须先在 Tim 文件中定义** |
| PatternTool 编辑时报错 | Pattern 源文件中管脚状态值必须与 Tim 定义一致；WFT 必须是 Tim 中已存在的 TimingName |
| Pattern 运行无反应 | 运行前**必须 Load**（Status 显示 `Load Success` 才可 Run） |
| 打印不出 Pattern 中的 vector | 代码中运行 Pattern 时**必须用 `Test()` 接口**，并在 UI 设置 Datalog 打印模式 |
| `GetHistCnt()` / `GetHistData()` / `SetReadOption()` 多 Site 下结果不对 | 这三个接口**只支持单 Site**，多 Site 需配合 `FOR_EACH_SITE_START(SITE, SITE_ID)` |
| `StartStop()` 配合 STV 时数据缺失 | **STOP Label 行不要使用 STV 指令** |
| 动态改 Pattern 后不生效 | 动态修改后**必须再运行 Pattern**；多 Site 测试更新后需**多 Site 运行** |
| 插入了错误的 Seq 指令 | 插入时该行若已有指令，必须先删除原指令；Pattern 最后一行必须是 `stop` |
| Label 报错 | **Label 不可重复** |
| tmf 编辑后不生效 | tmf 在 **Load 状态**下编辑完成后，必须点 **Save**（自动执行 Reload 命令） |

### 8.3 测量与硬件类

| 现象 / 报错 | 原因与处理 |
|---|---|
| DPS/PPMU 测量值异常 | **测量前一定要设置等待延时**（`sys.DelayUs`）。Contact 机械 relay 需 **8~10ms**；pinlevel Connect 稳定时间 5ms 以内 |
| 频繁 Connect/DisConnect 出问题 | 内部会闭合/断开**机械 relay**，**除特殊要求外不建议频繁动作** |
| 通道配置异常报错（PLVL） | `FIX` / `VHH` 模式**只能用 DIO 的 0、8、16、24 通道** |
| VHH 波形看不到 | 需在 Sig 中把该通道定义为 TMU/VHH 用途；**需在 Tim 文件中把指定管脚 WFC 设为 `T`**，再在 Pattern 中使用该 WFC 并运行 Pattern，用示波器抓波形 |
| DPS 电流被箝位（Gang 模式） | Gang 模式 `CurrClamp` 是**并联通道电流之和**。两通道 Gang 最大 1A，若把 CurrClamp 设成 500mA 会箝位。Gang 模式电流档位只能设 500mA |
| CurrClamp 设置无效 | **必须先设 `CurrRange` 再设 `CurrClamp`** |
| Gang 组合不对 | Gang 是**从小通道号到大通道号组合，不能反向**（DPS1 设 `DPS_GANG2` 是 1、2 通道） |
| TMU 绑定失败 | TMU 0、1 限制 DIO_0~15；TMU 2、3 限制 DIO_16~31；**不可跨板卡绑定**，四通道只能在同一块板卡 |
| TMU 测不到频率，返回 0 | 未获取到信号频率时**返回 0**；检查触发电平/触发沿/超时，或增大 `SetSampleSize` |
| FRunClk 频率不对 | DIO0~15 同一时刻只能同频率；DIO16~31 同理。周期 >16384ns 时必须是 **4 的倍数** |
| AWG 连续发送失败 | **必须先把上一次 `Stop()` 再设等待延时** |
| DGT `SetCapture` 报错 | `dbSampleRate`（MHz）"暂时不开放"，不要传该参数；点数 1~65535；量程自动匹配 0~2/0~4/0~8V |
| DGT 读取 csv 后原通道消失 | 读取时会**清空已打开通道** |
| Digitizer 内存超限 | **最大内存 1024 点**，超出会提示并撤回最近更改；采样间隔必须为 **6250ps 整数倍**且 ≤1s |

### 8.5 通用注意事项（原文强调）

1. 编写测试项代码时请在 `Test.cpp` 中的**对应测试项函数体内**编写。
2. `Test.cpp` 有修改，就必须 **Unload Job → 重新 Build → 再测试**。
3. 测试前必须先点工具栏按钮**把测试项所需的 Pattern 下发**。
4. 级联线缆插拔：**须先将线缆向里推进少许，然后按下开关**，切不可蛮力插拔。
5. 开机顺序：先连接好所有测试组件 → 启动工控主机 → 进入系统桌面后 → 再按下各级联机头的电源模块按钮。
