## 2. 上位机软件界面与操作流程

### 2.1 四个界面与登录账户（P.53–P.54）

登录界面输入账户密码后，选择四个入口图标：

| 入口 | 默认账户/密码 | 用途 |
|---|---|---|
| 用户管理界面 | `admin` / `admin` | 新增/删除用户、修改权限与 Role 分组 |
| 开发主界面 | `dev` / `dev` | 新建 Job 工程、编辑工程文件、编译、Load、调试、Prj Run |
| 工厂界面 | `user` / `user` | 批量生产测试、Handler/Prober 连接、Datalog 导出、WaferMap |
| 自检/校准界面 | `dev` / `dev` | 校准（Calibration）与自检（SelfCheck） |

用户管理注意事项（P.55–P.57）：新建 Account 名称**一旦确定不可再修改**；Role 决定显示在哪个分组；Password 与 Password Confirm 必须一致；灰色输入框不可二次编辑。

### 2.2 开发主界面（P.84–P.93）

进入前需选择 **WorkSpace**（保存测试工程的目录，可 Browse 修改）。

**菜单栏功能**

| 菜单 | 关键选项 |
|---|---|
| **File** | New（新建 Job / 新建 .cpp、.h）、Import（从 Workspace 外部导入 Job，不能导入已存在项目，导入时自动拷贝到当前 Workspace）、Close(Ctrl+W)、Close All、Save(Ctrl+S)、Save As、Save All、Refresh Workspace、Exit |
| **Edit** | Undo/Redo/Cut/Copy/Paste/Delete/Select All/Find-Replace（所有可编辑工程文件都支持） |
| **Tester** | Load（加载 Job，**每次只能 Load 一个**，且 Load 前必须先 Build）、Unload、Start Debug、Stop Debug、Run（Prj Run，Ctrl+R）、Stop、Restart、Runner（Runner 异常时手动重启） |
| **Build** | **Build Tool**（编译 Job 工程）、ReLoad（对已 Load 的 Job 重新 Load） |
| **ToolBar(Tools)** | 各 AFE 调试工具：AWG、DGT、CBIT、BPMU、DPS、PPMU、RVS、VCD 转码、Pattern 工具；以及"加载测试工程的 Timing 和 Pattern"、"新建测试批号"、"导出测试数据" |
| **Windows** | Show Views（Job / Datalog / Outline / Runner Console / Progress / Problems / Log）、ToolBars、**Perference**（Runner 启动方式与路径、Language、Runner Log Level=INFO/WARN/DEBUG/ERROR、DIO Log Level）、Reset Perspective、Debug Reset Perspective |
| **Help** | 查看当前 UI 版本 |

**Runner**：测试执行的后台进程。可在 Perference 中配置启动方式与启动路径；异常时用 Tester→Runner 重启。

### 2.3 工程开发标准流程（P.83、P.154–P.155）

```
1. 新建 Job 测试工程（File → New → Job File）
2. 编辑 Sig / Grp 文件：按 LoadBoard 资源连接，定义芯片管脚 → 测试机资源的映射
3. 编辑 tmf 文件：定义测试项、ParamName、Limit、Sbin/Hbin、Results
4. 编辑 Tim 文件（管脚时序）与 Pat 文件（绑定 Pattern 源文件）
5. 在 Test.cpp 中编写测试项函数体（tmf 保存时自动生成函数骨架）
6. 编译（Build → Build Tool → Make）；Load Job 工程
7. 下发 Pattern/Timing（工具栏按钮），勾选 tmf 中要测试的测试项
8. 点击 Prj Run，选择运行的 Site，开始调试/测试
```

**关键约束**
- **必须先 Build 才能 Load**；直接 Load 会弹错误提示且 Job 项目变红（P.99、P.159）。
- **一次只能 Load 一个 Job**；切换工程建议**重启软件**后再选工程并加载（P.99、P.80）。
- 只要 **Test.cpp 有修改，就必须先 Unload Job 工程 → 重新 Build → 再测试**（P.193）。
- 测试前必须点工具栏按钮**下发 Pattern 与 Timing**；无 Pattern 的测试项可不发，运行时会弹"没有加载 Pattern 和 Timing"提示，选"是"即可（P.131）。
- 运行/调试时用 Run 按钮的下拉控件选择 Site，**默认全选**（P.131）。
- Debug 模式的运行方式与 Run 一致（P.131）。

### 2.4 工厂界面（P.58–P.82）

批测流程：**Load Job → 配置 Handler/Prober 并确认分 Bin → Start**。

| 控件 | 说明 |
|---|---|
| **File → New Lot** | 设置当前 Lot ID（须先 Load Job）；测试前设置好便于数据导出 |
| **File → Export Csv** | 导出测试数据 |
| **Load** | 加载 job 文件，同时把工程所需的 Pattern 一并下发，可在 Console 查看；底部状态栏显示加载状态 |
| **Manual Test** | 手动测试仅一次，用于批测前调试或验证 Handler/Prober 通信 |
| **Start / Stop** | Start 后需选择运行 Site，按钮变绿 `Testing` 且不可点击；Stop 暂停（变红），再 Start 继续 |
| **End Lot** | 结束当前批次，自动弹出保存测试数据选项 |
| **Windows → JobExplore** | 显示工程文件（打开需输入 `dev` 密码）。**工厂模式下只有 tmf 文件可简单编辑**，其他文件只能查看；tmf 在工厂界面手动改后必须点 **Save（执行 Reload）** 才生效 |
| **Tools** | 报警监测球：正常绿色、故障红色；双击进机箱监测界面，选板卡→"获取异常"读取异常信息 |
| **TDR** | 手册原文标注"**待补充**" |

**Handler/Prober 配置**（P.68–P.79，通常只需配置一次，软件持久化保存）

| 分选平台 | 可用型号 |
|---|---|
| Handler | `Handler TTL`（TTL 通信）、`Handler 6430`（GPIB 通信）、`Chroma RS-232`（232 通信） |
| Prober | `UF200`、`P12` |

- **TTL 接口 Timing Definition**：`Bin`（Out）、`Eot`（Out）、`Sot`（In），以及 T1–T5 延时（支持一位小数）与 `Synchronous Wait Time`（多工位同步等待时间）。
  - **T1**：一次测试结束到发出 Bin 信号的延时，建议 0。
  - **T2**：应比 T4 长 1ms 以上，使 T2 包含 T4。
  - **T3**：建议 0–1ms，保证 **Eot 前跳变沿慢于 Bin 前跳变沿**（Handler 先收 Eot 再检测 Bin），且 T3 > T1。
  - **T5**：发出 Bin 后跳变沿到读取 Sot 状态间的延时，需**略小于** Handler 动作时间。
  - **Synchronous Wait Time**：收到第一个 Sot 后预留的时间窗；窗内若收到新 Sot，则对这些 Site 一起测试。测试完成后**同时**向各 Site 发 EOT 和 Bin。
- **Signal Definition**：SOT 有 `Negative Logic`（低电平脉冲）与 `Latched`（边沿触发 / 电平触发）；EOT 有 `Negative Logic`；Bin 有 `Negative Logic` 与 **Bin Type**。
  - **Bin Type** 三选一：`BCD`（=1）、`HEX`（=2）、`PARALLEL`（=3，一一对应 Handler 的 BIN 号）。**手册建议一般使用 PARALLEL**。
  - 控制台回显格式：`HL SET_SOT <0|1> <0|1>`、`HL SET_EOT <0|1>`、`HL SET_BIN <0|1>`、`HL SET_BIN_CODETYPE <1|2|3>`。
- **GPIB 配置**：`GPIB Board`（通信链路）、`Time out`、`Address`。
- **Chroma RS-232 配置**：四个串口可配置，每个串口一个地址（**1~255 正整数，不可重复**）和四个 Site 工位；Site 下拉按工程 Site 数动态添加且不可重复。`Baud Rate` 默认 9600，`Bit Length` 默认 8 Bits，`Stop Bit` 默认 1 Bit，`Parity` 默认 None，`Timeout` 必填默认 500（可为 0）。Save 持久化，Close 不保存。
- **Prober Connect Settings**：`GPIB Board`、`Test Site`（Site 个数，点 Config 配置排列）、`Time out`、`Address`。
  - 针卡编辑网格 640×640，左键单击单元格添加 Site、右键清空；Site 数超过 Test Site 会告警；`IncreasingX` / `IncreasingY` 控制坐标轴方向。配置保存到 `D:\MINI-ATE\Prober`。
- **Mapping Settings**：勾选 Mapping 才能打开 WaferMap。
- **WaferMap View 控件**：ZoomIn/ZoomOut、Show Under Test、Site 编辑框、Show Site、Hide Site、Hide/Show All Sites、Jump Test(输入 X,Y 跳转)、`Text To Display`（每格显示：**HardBIN / SoftBIN / SiteNumber / Pass/Fail**）、Clear Wafer Maps、Export（txt）、Import（导入外部 Wafer 数据预览）。

### 2.5 Datalog 数据记录与导出

- **测试数据视图**：表头 `Part ID`（循环测试次数编号）、`SBin`（软分档）、`SiteTime`（当前测试回合耗时）、`Unit`、`Min`、`Max`（与 tmf 各参数对应）；右侧为所有测试项，`Sub Test` 对应子测试项。失败值**标红**；可切换 Site 查看。
- **导出**：Export 按钮弹出 Datalog 导出窗口。
  - 可按 **Lot / Test Result / 测试时间 / Site 工位**筛选。
  - Setting 区可设**单文件最大条数**做分组：**全部最多支持 500W 条导出，单文件最大 50W 条**。
  - 默认导出格式 **CSV**；软件另支持 **txt、csv 及 STDF**，并支持标准 STDF 文件解析与初始统计数据分析（P.19）。
  - ⚠️ **Delete 按钮会删除所有测试数据，谨慎操作**。
- **Log 配置**（P.135）：`Log PASS/FAIL Result Only`、`Log Detail Fail`、`Log Failling Signals`、`Log ALL Signals`、`Log Error Message`。
  - **若要打印 Pattern 中的 vector，代码中运行 Pattern 必须用 `Test()` 接口**，并在 UI 中设置 Datalog 打印模式。

### 2.6 AFE 调试工具（第 3 章，P.194–P.242）

均在 **Debug 模式**下直接操作 AFE 模块。控制台命令统一前缀 `RES AFE`：

| 工具 | 控制台命令格式 |
|---|---|
| CBIT | `RES AFE CBIT SETON <FBID/Slot> <Channel>`（例：`RES AFE CBIT SETON 1 0`） |
| DPS | `RES AFE DPS SET <FBID> <Channel> <Mode> <Irange> <ForceValue>`；`RES AFE DPS MEAS <FBID> <Channel> <VOLT/CURR>` |
| BPMU | `RES AFE BPMU SET <FBID> <Channel> <Mode> <Irange> <ForceValue>`；`RES AFE BPMU MEASURE <FBID> <Channel> <VOLT/CURR>` |
| RVS | `RES AFE RVS SET <FBID> <Channel> <Mode> <Irange> <ForceValue>`；`RES AFE RVS MEAS <FBID> <Channel> <VOLT/CURR>` |

- **通道数按位下发**：通道 0 下发 `1`(2⁰)，通道 1 下发 `2`(2¹)，通道 7 下发 `128`(2⁷)。**后续所有 AFE 工具通道均按位下发**（P.200）。
- `VOLT` / `CURR` 由 Mode 决定：`FVMI` 表示"钳位电压测量电流"，因此返回 `CURR`。
- **DPS 工具**：Mode 下拉 `FNMV / FVMI / FVMV`；`ForceValue` 标注范围 `-4.4V~8.4V`（与接口手册 `-3.25~+8.4V` 不一致，**以接口手册为准**）；Irange 下拉 `5uA、25uA、250uA、5mA、25mA、500mA`。
- **BPMU 工具**：Mode 下拉 `FNMV / FVMV / FVMI / FIMI / FIMV`；Irange `5uA、20uA、200uA、2mA、80mA`。
- **PPMU 工具**：操作的其实是 **DIO 类型 Signal**；Mode 下拉；Irange `2uA、10uA、100uA、1mA、40mA`；ForceValue `-2V~6.5V`。
- **RVS 工具**：ForceValue `0V~10V`；Irange 默认 50mA 不可编辑。
- **CBIT 工具**：Slot1–Slot5 对应 5 块业务板（Sig 中 FBID 1–5），每 Slot 8 个信号（K0–K6 示例）；支持单 Channel On/Off 与信号组操作；`Seton All` / `Seton off` 一次操作 40 个通道。**信号组 On/Off 只控制信号组内的信号**。
- **AWG 工具**：波形预览区 + 波形表格区；字段 `Waveform / Repeat Count / Amplitude / OffSet / Samples Sum / Show Wave`；右键可创建/删除波形、上移/下移；支持六种波形 **Sine、Ramp、Triangle、Sawtooth、Pulse、DC**；支持十字标（Cursor）测量、横向/纵向双光标差值、保存波形（按波形组保存，一组一个文件夹）。关闭 AWG 工具会**自动保存**所有编辑。
- **DGT(Digitizer) 工具**：菜单 `文件 / 垂直(通道) / 时基 / 触发 / 显示 / 游标`。
  - 保存类型支持 **csv 与 png**；csv 中 `T` 前缀数据表示该通道的**触发点**。
  - 读取仅支持 csv，读取时会**清空已打开通道**。
  - 时基 = 采样间隔 × 内存；**采样间隔只能为整数，且必须是 6250ps 的整倍数，不超过 1s**；**最大内存 1024 点**。
  - 栅格：1 / 2 / 4 / 8 / 16 格（含 4×2、4×4）；支持余晖效果、放大显示区域、移动 0s 三角与 0V 三角、波形拖动/缩放（Ctrl+滚轮缩放时间轴，滚轮缩放电压轴，均以触发点为原点）。
  - **DGT CMD**：
    - `AFETestDGT cmpget`：获取所有通道数据，Long=8 字节、Int=4 字节、Float=4 字节，**一个数据包 32784 字节**，共发 64 次。回发结构：`Interval(Long,数据时间间隔)`、`triggerPoint(Int)`、`pointSum(Int,总点数)`、`pointVoltage(Float[8192])`。
    - `AFETestDGT miniset`：下发采样率与采样点；`Interval` 必须为 6250ps 整数倍且不超 1s，默认 6250。
    - `AFETestDGT miniget`：获取下发后返回数据，`MINIPOINT = 1024`；返回 `Interval(Long)`、`pointSum(Int)`、`pointVoltage(Float[MINIPOINT])`。

### 2.8 Pattern Tool 与单步调试（P.138–P.153）

- **调试 Pattern 顺序**：**加载(Load Pattern) → 运行(Run) → 停止(Stop)**。底部状态栏显示 `Site`、`Status`（Load Success / Run Success）、`Fails`（比较失败个数）。
- 菜单：`File`（New/Save/Save As/Close）、`Debug`（Load Pattern/Run/Stop）、`Edit`（Copy/Paste/Undo/Redo/Add Rows/Delete Rows/ReNameSignal/Add Column/Delete Column）、`View`（Vector 模式 / Waveform / **Fail Memory** 显示比较失败的 Vector）、`Find/Goto`（Find fail 在 Fail Memory 模式找下一个错误；Goto Label 定位）。
- Pattern 表头：`Lable`（索引，**不可重复**）、`WFT`（对应 Tim 文件 Timing 组名）、`Sequence`（微指令）、`Loops`（图形化显示，不可编辑）、`Comment`。
- Sequence 可插入：`Nop`、`Repeat`（填重复次数）、`Loop`（Loop Count / Start Vector / Stop Vector，序列格式如 `Loop 20:2:9`）、`Jump`（目标 Label）、`Stop`。**Pattern 最后一条语句必须为 STOP**。
- 插入指令时若该行已有指令，必须先删除原指令才能插入。
- **Waveform Tool**：`View → Programmed → Waveform` 打开；支持横向放大/缩小、Fit、刷新、Move To Start/End、Clear Support Line、Ctrl+滚轮缩放；SignalGroup 右键 `Add To Signals` 添加波形；拖动信号可上下交换位置；Waves 中右键 `Add Line` 添加辅助线（最多两条，显示时间差）；双击显示当前位置时间戳。
- **CLI 参数**：运行 Pattern 前需"设置参考电平"，`Pat Run Num` 设置运行 Pattern 的 Site 编号。
