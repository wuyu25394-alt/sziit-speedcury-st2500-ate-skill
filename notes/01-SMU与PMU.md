# SMU 与 PMU（集成电路测试）

## 一、SMU 是什么

**SMU = Source Measure Unit，源测量单元**（也叫"源表"）。

一句话定义：**把"电源"和"万用表"合成一个仪器，在同一引脚上同时完成"施加"与"测量"。**

### 核心能力：四象限工作

| 象限 | 电压 | 电流    | 功率     | 典型场景  |
| -- | -- | ----- | ------ | ----- |
| 第一 | 正  | 流出(+) | 输出     | 正常供电  |
| 第二 | 负  | 流出(+) | **吸收** | 模拟负载  |
| 第三 | 负  | 流入(−) | **吸收** | 反偏、放电 |
| 第四 | 正  | 流入(−) | 输出     | 灌电流   |

**这是它区别于普通电源的本质。** 普通实验室电源只能工作在**第一象限**；SMU 四个象限都能工作，所以它可以：

- 当电源（source）
- 当负载（sink）
- 双向扫描（−1V → +1V 扫二极管曲线，或 +V → −V 扫晶体管输出特性）

## 二、两种工作模式

| 模式       | 施加（Force） | 测量（Measure） | 等效于       |
| -------- | --------- | ----------- | --------- |
| **FVMI** | 强制电压      | 测量电流        | 电压源 + 电流表 |
| **FIMV** | 强制电流      | 测量电压        | 电流源 + 电压表 |

命名规则：`F` = Force（施加），`M` = Measure（测量）。

### Compliance（钳位 / 限值）

**这是考试常考点。** 当你 FVMI 时，必须设一个电流上限，防止被测件短路烧毁，这个上限叫 **current compliance**。反之 FIMV 时设 **voltage compliance**。

> **关键机制**：SMU 一旦触及 compliance，就自动从"源"模式转入"限制"模式 —— 不再强行维持设定值，而是停在限值上。

## 三、为什么 IC 测试要用 SMU

```
ATE 需要给芯片加电、并测量芯片的电流/电压
        ↓
但 ATE 的数字通道（pin electronics）只能做逻辑高低电平
        ↓
所以每个需要"测参数"的引脚都要配一套 SMU/PMU
        ↓
这就构成了 DC 参数测试的硬件基础
```

### DC 参数测试常见项目

| 测试项           | 含义           | SMU 怎么用            |
| ------------- | ------------ | ------------------ |
| **IIL / IIH** | 输入漏电流（低/高电平） | FVMI：加规定电压，测流入电流   |
| **VOL / VOH** | 输出电平         | FIMV：灌/拉规定电流，测输出电压 |
| **IOL / IOH** | 输出驱动能力       | 同上，看能否达到规定电平       |
| **IDD / ICC** | 电源电流         | FVMI：正常供电，测总电流     |
| **IOS**       | 输出短路电流       | FVMI：输出短接到地，测电流    |
| **VIL / VIH** | 输入阈值         | 扫描电压找翻转点           |

### 符号命名规则

```
I  = 电流     V = 电压
第 2 字母：L = Low，H = High
第 3/4 字母：I = Input，O = Output

例：IOL = 输出低电平时的电流
    IIH = 输入高电平时的漏电流
```

这套命名是 IC 测试的通用语言。

## 四、SMU 与 PMU 的区别（重点）

|     | **SMU**                                | **PMU**（Parametric Measurement Unit） |
| --- | -------------------------------------- | ------------------------------------ |
| 全称  | Source Measure Unit                    | 参数测量单元                               |
| 定位  | **独立仪器**（Keithley 2400、Keysight B2900） | **ATE 系统内的功能模块**                     |
| 形态  | 台式、带面板和界面                              | 板卡/通道，集成在测试头里                        |
| 通道数 | 通常 1~2 路                               | 一块板几十上百路                             |
| 精度  | 高（nA ~ fA 级）                           | 相对低（受通道数和成本限制）                       |
| 速度  | 慢（ms 级）                                | 快（μs 级，要跟上测试节拍）                      |
| 用途  | 器件表征、实验室调试                             | 量产测试、多引脚并行                           |

> **一句话概括**：PMU 是"ATE 里的 SMU"，是 SMU 在量产测试场景下的**集成化、多通道、高速化**版本。

**注意**：有些教材/厂商会把 ATE 里的模块也直接叫 SMU（如 "per-pin SMU"）。看到时按**上下文是台面仪器还是机台模块**来判断。

## 五、开尔文四线连接（Force / Sense）

标准 SMU 有两对线：

| 线                    | 作用  |
| -------------------- | --- |
| **Force 线**（HF / HV） | 走电流 |
| **Sense 线**（HS / LS） | 测电压 |

**为什么要分开？**

Force 线上有导线电阻和接触电阻，电流流过会产生压降。若直接用 Force 端的电压当测量值，就**把线阻算进去了**。

Sense 线在被测件两端单独测电压（此时 Sense 线几乎不走电流，压降可忽略），从而消除这个误差。

**这就是开尔文四线测量 —— 测小电阻、大电流时必用。**

## 六、时序问题（测试工程里最易忽略）

SMU 不是理想器件，有几个时间参数：

| 参数                    | 说明                     |
| --------------------- | ---------------------- |
| **Settling time**     | 施加电压后，到电流读数稳定所需时间      |
| **Range change time** | 量程切换开销（μA 档 → mA 档）    |
| **Cable 电容充放电**       | 长电缆有几十~几百 pF，切换电压时要充放电 |

**这些时间会直接限制测试吞吐量。** 量产测试中参数测试往往是瓶颈项（模拟测量天生比数字慢）。

因此测试程序里讲究：

- **少切量程**（尽量用同一档测完一组）
- **合理设置延时**（不够测不准，太长掉产能）
- **并行测量**（多 PMU 同时测）

## 七、复习提纲

```
SMU
├── 定义：源+测一体，四象限
├── 模式：FVMI / FIMV + compliance
├── 连接：Force/Sense 四线开尔文
├── 与 PMU 的关系：台面仪器 vs ATE 模块
└── 应用
    ├── DC 参数测试（IIL / IOH / VOL / IDD …）
    ├── 器件表征（IV 曲线扫描）
    └── 时序约束 → 影响测试吞吐量
```
