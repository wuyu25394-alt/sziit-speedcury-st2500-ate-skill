## 一、器件认识

### 1.1 是什么

**74HC299 是 8 位通用移位寄存器，带三态输出。** 内含 8 个边沿触发 D 触发器与级间逻辑，可完成**同步右移 / 左移 / 并行置数 / 保持**四种操作，操作类型由模式选择输入 **S0、S1** 决定。

- `I/O0 ~ I/O7` 是触发器的**三态缓冲输出**，并行置数时又当作**数据输入**（分时复用同一批引脚）
- `Q0`、`Q7` 是**串行输出**（普通输出），用于级联扩展更长字长
- `MR` 低电平**异步主复位**，优先于 Sn 和 CP
- `OE1`、`OE2` 任一为高即**关断三态缓冲**，`I/On` 进入高阻，但移位/保持/置数/复位仍可进行

### 1.2 引脚定义（数据手册 Table 2）

| 符号       | 引脚    | 说明               |
| -------- | ----- | ---------------- |
| S0, S1   | 1, 19 | 模式选择输入           |
| OE1, OE2 | 2, 3  | 三态输出使能（**低有效**）  |
| I/O0     | 7     | 并行数据输入 / 三态并行输出  |
| I/O1     | 13    | 同上               |
| I/O2     | 6     | 同上               |
| I/O3     | 14    | 同上               |
| I/O4     | 5     | 同上               |
| I/O5     | 15    | 同上               |
| I/O6     | 4     | 同上               |
| I/O7     | 16    | 同上               |
| Q0       | 8     | 串行输出（普通输出）       |
| Q7       | 17    | 串行输出（普通输出）       |
| MR       | 9     | 异步主复位输入（**低有效**） |
| DSR      | 11    | 串行数据右移输入         |
| DSL      | 18    | 串行数据左移输入         |
| CP       | 12    | 时钟输入（**上升沿触发**）  |
| GND      | 10    | 地                |
| VCC      | 20    | 正电源              |

> ⚠️ **引脚编号不连续、且与位序无关**：`I/O0=7、I/O1=13、I/O2=6、I/O3=14、I/O4=5、I/O5=15、I/O6=4、I/O7=16`。  
> 接线和 `.sig` 里极易串位，**务必逐脚核对**。

### 1.3 功能表（数据手册 Table 3）

H = 高电平；L = 低电平；↑ = CP 由低到高跳变；X = 不关心。

|   MR  |  S1 |  S0 |  CP | 响应                         |
| :---: | :-: | :-: | :-: | -------------------------- |
| **L** |  X  |  X  |  X  | **异步复位**：Q0~Q7 全为 LOW      |
|   H   |  H  |  H  |  ↑  | **并行置数**：I/On → Qn         |
|   H   |  L  |  H  |  ↑  | **右移**：DSR → Q0，Q0 → Q1，…… |
|   H   |  H  |  L  |  ↑  | **左移**：DSL → Q7，Q7 → Q6，…… |
|   H   |  L  |  L  |  X  | **保持**                     |

> **口诀**：**MR 低 → 全清；S1S0 = 11 置数、01 右移、10 左移、00 保持。**  
> ⚠️ 注意与直觉相反：**S1=0,S0=1 是右移，S1=1,S0=0 是左移。**

### 2.4 时序定义（写进 `HC299_v1.tim`）

波形表 **WFT1**，周期 **10 µs**：

| 信号                                        | WFC | 事件（时刻）     | 说明                     |
| ----------------------------------------- | --- | ---------- | ---------------------- |
| INPUT_PINS / CTRL_PINS / IO_PINS / Q_PINS | `0` | `D` @ 0 µs | 驱动低                    |
| 同上                                        | `1` | `U` @ 0 µs | 驱动高                    |
| IO_PINS / Q_PINS                          | `L` | `L` @ 6 µs | 比较低                    |
| IO_PINS / Q_PINS                          | `H` | `H` @ 6 µs | 比较高                    |
| IO_PINS / Q_PINS                          | `X` | `X` @ 0 µs | 不比较                    |
| IO_PINS / Q_PINS                          | `M` | `M` @ 0 µs | 中间态（高阻/不驱动）            |
| CP                                        | `0` | `D` @ 0 µs | 时钟低                    |
| CP                                        | `1` | `U` @ 5 µs | **时钟上升沿**（周期中点，保证建立时间） |
| CP                                        | `Z` | `D` @ 0 µs | 停止时回低                  |

**为什么比较点选 6 µs**：时钟 5 µs 上升沿后，数据手册 `tpd(CP→I/On)` 最大 60 ns、  
`tPZH/tPZL` 最大 47 ns，6 µs 处早已稳定，留足裕量。

> 时序约束核对（手册 @ VCC = 4.5 V，25 ℃）：
>
> - `tW`（CP 脉宽）最小 **16 ns** → 本表 5 µs ✅
> - `tsu`（I/On、DSR、DSL、S0/S1 对 CP）最大 **25 ns** → 本表 5 µs ✅
> - `th`（保持）最小 **0 ns** ✅
> - `fmax` 25 MHz @4.5 V ❗**本表周期 10 µs 仅 100 kHz，位移速度远低于上限，测不到 `fmax`**

### 5.1 三个容易写错的地方（本工程已处理）

1. **`CurrRange` 必须先于 `CurrClamp`**（DPS 侧强制顺序），且传入值不在档位中会自动向上匹配。  
   DPS 档位：5 µA / 25 µA / 250 µA / 2.5 mA / 25 mA / 500 mA。  
   PPMU 档位：2 µA / 10 µA / 100 µA / 1 mA / 40 mA。
2. **小电流测量必须"先大量程、后切小量程"**（`IIL_T`、`IOZ_T` 都这么做），否则上电瞬态会超量程或读数不稳。
3. **`OSN_T` 前必须把 VCC 置 0 V**，否则电源脚保护二极管会给出并联通路，读数偏低。

### 5.2 与 CD4511 案例的关键差异

|            | CD4511             | **74HC299**                      |
| ---------- | ------------------ | -------------------------------- |
| 器件性质       | 组合逻辑 + 锁存          | **时序逻辑（移位寄存器）**                  |
| 输出强制手段     | 用 LT/BI 两个脚强制全高/全低 | **必须跑时钟才能改变状态**（仅 MR 能强制全 0）     |
| 双向引脚       | 无                  | **I/O0~I/O7 分时复用**（置数时是输入、之后是输出） |
| 三态         | 无                  | **有，且要专测 IOZ**                   |
| VOH/VOL 测法 | 用 LT/BI 强制，不用向量    | **必须先跑时钟置数**，再测 —— 步骤明显更多        |
| 时钟         | 无                  | **CP 上升沿，含 tsu/th/tW/fmax 约束**   |


> 这五点差异决定了：**74HC299 不能照抄 CD4511 的 `VOH_T`/`VOL_T` 写法**，  
> 必须像本工程这样"先摆状态、再测量"。
