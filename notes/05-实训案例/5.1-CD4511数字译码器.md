## 一、器件认识

### 1.1 是什么

> **CD4511 是一片 CMOS BCD—锁存/7 段译码/驱动器**，用于驱动**共阴极 LED 数码管**显示器的 **BCD 码 → 七段码译码器**。具有 BCD 转换、消隐和锁存控制、七段译码及驱动功能。**CMOS 电路能提供较大的拉电流，可直接驱动共阴 LED 数码管。**（课件 P.4）

### 1.2 引脚定义（课件 P.7 表）

| Pin | Pinname | Type | Main function |
| --- | ------- | ---- | ------------- |
| 1   | A0      | I    | 二进制数据输入端 A0   |
| 2   | A1      | I    | 二进制数据输入端 A1   |
| 3   | A2      | I    | 二进制数据输入端 A2   |
| 4   | A3      | I    | 二进制数据输入端 A3   |
| 5   | LE      | I    | 数据锁定控制端       |
| 6   | BI      | I    | 输出消隐控制信号      |
| 7   | LT      | I    | 灯测试控制端        |
| 8   | VSS     | S    | 接地            |
| 9   | VDD     | S    | 电源正信号         |
| 10  | a       | O    | 译码输出端 a       |
| 11  | b       | O    | 译码输出端 b       |
| 12  | c       | O    | 译码输出端 c       |
| 13  | d       | O    | 译码输出端 d       |
| 14  | e       | O    | 译码输出端 e       |
| 15  | f       | O    | 译码输出端 f       |
| 16  | g       | O    | 译码输出端 g       |

> ⚠️ **课件内部口径矛盾（务必注意）**：上表（P.7）写的是 **3=A2、4=A3、6=BI、7=LT**；但同一份课件 P.8 的「管脚说明」文字却写「**BI：4 脚**是消隐输入控制端」「**LT：3 脚**是测试输入端」。两处互相矛盾。实测工程（`.sig` 文件）与 CD4511BE 数据手册均以 **P.7 引脚表**为准，即以 **6=BI、7=LT、3=A2、4=A3** 为准。学习时如遇到实训板接线问题，应优先核对实物丝印与数据手册。

### 1.3 三个控制端的逻辑（课件 P.8）

| 控制端           | 逻辑                | 效果                                                        |
| ------------- | ----------------- | --------------------------------------------------------- |
| **BI**（消隐输入）  | **BI = 0**        | 不管其它输入端状态如何，七段数码管**均处于熄灭（消隐）状态**，不显示数字                    |
| **LT**（灯测试输入） | **BI = 1，LT = 0** | 译码输出**全为 1**，不管输入 DCBA 状态如何，七段**均发亮，显示"8"**。主要用来检测数码管是否损坏 |
| **LE**（锁定控制）  | **LE = 0**        | **允许**译码输出                                                |
|               | **LE = 1**        | 译码器**锁定保持**状态，输出保持在 LE=0 时的数值                             |
| **A1~A4**     | —                 | **8421 BCD 码**输入端                                         |
| **a ~ g**     | —                 | 译码输出端，**输出为高电平 1 有效**                                     |

## 二、硬件资源与通道分配

### 2.1 信号映射（工程 `.sig` 文件）

| 信号                        | AFEType | ChType | Site0 通道           |
| ------------------------- | ------- | ------ | ------------------ |
| VDD                       | **DPS** | Supply | `1:1:0`            |
| B ~ A、Ye ~ Yf 等共 14 个 I/O | **DIO** | Inout  | `1:1:0` ~ `1:1:13` |

即：本案例在通用接口板上把**信号管脚全部接到 DIO Inout 通道**，**电源接到 DPS**。

### 2.2 信号分组（工程 `.grp` 文件）

| 组名            | 包含信号                       | 用途              |
| ------------- | -------------------------- | --------------- |
| `INPUT_PINS`  | B, C, LT, BI, LE, D, A     | 输入脚漏电流等         |
| `OUTPUT_PINS` | Ye, Yd, Yc, Yb, Ya, Yg, Yf | VOH/VOL、时序采样    |
| `INOUT_PINS`  | 上述全部 14 个 I/O              | OS、功能电平、Pattern |

> **分组的价值**：`Test.cpp` 里可以写 `ppmu.Signal(INPUT_PINS)`、`pinlevel.Signal(OUTPUT_PINS)`，避免逐脚写重复代码。

### 2.3 时序定义（工程 `.tim` 文件）

本工程定义 **WFT1**：

| 项目                | 值                                             |
| ----------------- | --------------------------------------------- |
| 周期 Period         | **10 µs**                                     |
| 输入脚 `INPUT_PINS`  | WFC `0` → 驱动低（D）；WFC `1` → 驱动高（U）；边沿 **0 µs** |
| 输出脚 `OUTPUT_PINS` | `L`/`H`/`X` 在 **9 µs** 处比较（接近周期末采样）           |

**含义**：前半周期驱动输入，**接近周期结束时**对七段输出做期望电平比较 —— 给电路留出充分的建立时间。

### 2.4 功能向量（`pattern/func.csv`）

列含义：`Label, WFT, Sequence, LE, BI, LT, D, C, B, A, Ya~Yg`

| # | 输入 DCBA | LE | BI | LT | 期望显示  | 期望输出                               |
| - | ------- | -- | -- | -- | ----- | ---------------------------------- |
| 1 | 0000    | 0  | 1  | 1  | **0** | Ya~Yf = H，Yg = L                   |
| 2 | 0001    | 0  | 1  | 1  | **1** | Yb, Yc = H                         |
| 3 | 0010    | 0  | 1  | 1  | **2** | Ya, Yb, Yd, Ye, Yg = H，以 `stop` 结束 |

控制条件恒为 **LE=0, BI=1, LT=1**（非消隐、非灯测、允许译码输出）—— 这正是 CD4511 的**正常译码工作条件**。

> **注意**：课件里的向量是**简化演示**（只有 3 行），实际量产模式会覆盖全部 10 个 BCD 码 + 消隐 + 灯测试 + 锁存功能。

## 四、关键测试项的代码实现要点

| 测试项          | 实现步骤                                                                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **`OSN_T`**  | ① 连接 `VDD`、`INOUT_PINS`；② VDD=0 V，各 I/O 先置 0 V；③ PPMU **FIMV**：对所有 I/O **抽电流 −100 µA**，**电压钳位 ±2 V**；④ 测电压并与 TMF OSN 限值比较；⑤ 复位并断开             |
| **`OSP_T`**  | 与 OSN 对称，改为**灌电流 +100 µA**，期望正向压降 0.2 ~ 1.2 V                                                                                                 |
| **`IIL_T`**  | ① VDD=5 V；② 对 `INPUT_PINS` **FVMI**：**强迫 0 V**，**先大量程再切到 2 µA 量程**；③ 测电流，限值 ±0.1 µA                                                           |
| **`VOH_T`**  | ① VDD=5 V，**LT=0**（灯测试使七段输出拉高）；② 对 `OUTPUT_PINS` **FIMV**：抽 **−10 mA**；③ 测电压，要求 3.9 ~ 5 V                                                     |
| **`VOL_T`**  | ① VDD=5 V，**BI=0、LT=5 V**（消隐条件，输出拉低）；② 对 `OUTPUT_PINS` **FIMV**：灌 **+10 µA**；③ 测电压，要求 0 ~ 0.3 V                                               |
| **`IDD_T`**  | ① VDD 先 **FVMV = 5 V**（建立供电）；② 再 **FVMI**，**电流量程/钳位 5 µA**；③ 测 IDD ≤ 5 µA                                                                     |
| **`FUNC_T`** | ① VDD=5 V，连接 `INOUT_PINS` 的 pinlevel；② 设置数字电平 **VIH=5、VIL=0、VOH=3.5、VOL=1.5**；③ 执行 `dio.Pattern("FUNC")`（超时 20 s）；④ `GetFailResult` 后与 TMF 比较 |

**常用 API 对象**：

| 对象          | 用途                        |
| ----------- | ------------------------- |
| `dps`       | 器件电源 Force/Measure        |
| `ppmu`      | 管脚参数测量（FVMV/FIMV/FVMI 等）  |
| `pinlevel`  | 数字管脚电平设置                  |
| `dio`       | Pattern 执行与失败结果           |
| `sys`       | 延时等系统服务                   |
| `binObj`    | 判限与分 Bin                  |
| `proberObj` | 探针台 / Handler 相关（EOW/EOL） |

## 六、教学重点与易错点

### 6.1 为什么这是最好的入门案例

1. **工程结构最完整**：`.job / .tmf / .sig / .grp / .res / .tim / .pat + Test.cpp + Makefile` 一应俱全，是理解整套体系的模板。
2. **Pattern 最少**（1 个、3 行向量）：把注意力集中在"工程文件怎么协同"而不是"向量怎么编"。
3. **DC 测试项最典型**：OS / IIL / VOH / VOL / IDD 五种最常用的 DC 测试全覆盖。
4. **数字可控性最好**：CD4511 是纯组合逻辑 + 锁存器，用 LT/BI 两个脚就能把输出强制成"全高"或"全低"，不需要复杂向量就能测 VOH/VOL。

### 6.2 易错点

| # | 易错点                            | 说明                                                                                              |
| - | ------------------------------ | ----------------------------------------------------------------------------------------------- |
| 1 | **课件引脚表与文字矛盾**                 | P.7 表：6=BI、7=LT；P.8 文字：4=BI、3=LT。以数据手册和工程 `.sig` 为准                                             |
| 2 | **VOH 靠 LT=0 而不是靠向量**          | CD4511 用 LT（灯测试）就能让七段全亮，比跑向量更省时间 —— 这是"用控制脚替代向量"的典型技巧                                           |
| 3 | **VOL 只灌 10 µA 而 VOH 抽 10 mA** | 量级差 1000 倍，体现 CMOS"拉电流强、灌电流弱"。**不要把两个电流搞反**，否则会损坏器件或测不准                                         |
| 4 | **OS 测试前必须把 VDD 置 0 V**        | 否则电源脚的保护二极管会引入额外通路                                                                              |
| 5 | **小电流测量要先大量程**                 | 直接上 2 µA 量程会因上电/电容瞬态导致超量程或读数不稳                                                                  |
| 6 | **通用器件接口板要手工接线**               | CD4511 是本课程**唯一需要自己用杜邦线搭电路**的案例，接线错误是最常见的"测试失败"原因                                               |
| 7 | **工程路径需重新定位**                  | `.job` 里的 `AteHomePath` / `jobDir` 指向原开发机路径（`D:\MINI-ATE\workspace\CD4511_v1`），换机器后需在 IDE 中重新定位 |

## 七、二次开发建议（来自工程 readme）

1. **改限值**：优先改 `.tmf` 中对应 `ResultAnalysis`，保持与 `CheckResultAndBin` 参数个数一致。
2. **改管脚/通道**：同步修改 `.sig` 与 `.grp`，并确认 `.res` 中 DIO/DPS 资源足够。
3. **加功能向量**：编辑 `pattern/func.csv`，必要时扩展 `.tim` 波形；`FUNC_T` 中电平与 Pattern 名保持一致。
4. **加测试项**：在 `Test.cpp` 增加 `USER_CODE` 函数，并在 `.tmf` 的 `FuncList` 中注册顺序、Bin 与限值。
5. **换机台路径**：更新 `.job` 的 `AteHomePath`/`jobDir`，以及 `Makefile`、`.cproject` 中的 MINI-ATE 路径。
6. **编译**：在已安装 MINI-ATE 且 `RUNNER_HOME`（`d:/MINI-ATE/runner`）路径正确的环境下，于工程目录执行 `make` 生成 `Test.dll`。
