## 一、器件认识

### 1.1 是什么

**74HC595 是 8 位串行输入、并行输出的移位寄存器**，内部由
**8 位移位寄存器 + 8 位输出锁存器 + 三态输出缓冲** 组成。

- **SER**（DS）：串行数据输入；
- **SRCLK**（SHCP）：移位时钟，**上升沿**采样 SER；
- **RCLK**（STCP）：锁存时钟，**上升沿**把移位寄存器送到输出锁存；
- **OE_n**：输出使能，**低有效**；高 = 高阻；
- **SRCLR_n**：移位寄存器清零，**低有效**（异步）；
- **QA~QH**：8 路并行输出；
- **QH'**（本工程写作 `QH_n`）：级联串行输出。

### 1.2 基本操作

| 操作 | 条件 | 结果 |
|---|---|---|
| 移位 | SRCLK 上升沿 | SER 进入 QA，原 QA→QB→…→QH→QH' |
| 锁存 | RCLK 上升沿 | 移位寄存器的 8 位复制到输出锁存 |
| 输出使能 | OE_n = 0 | QA~QH 正常驱动 |
| 高阻 | OE_n = 1 | QA~QH = Hi-Z |
| 清零 | SRCLR_n = 0 | 移位寄存器清 0（输出锁存不变） |

> **关键顺序**：先移位 8 次 → 再给 RCLK 上升沿 → 输出才更新。
> 只给 SRCLK 不给 RCLK，输出保持上一次锁存值。

### 1.3 与 74HC138 的区别

| 器件 | 类型 | 输出 | 控制 |
|---|---|---|---|
| 74HC138 | 组合译码 | 反相，选中低 | 地址 + 使能，无时钟 |
| **74HC595** | 串入并出 + 锁存 | 推挽 + 三态 | SER/SRCLK/RCLK/OE/SRCLR |

74HC595 的测试重点从「真值表」变成了 **时序 + 锁存 + 三态**。

## 二、工程文件体系

### 2.1 信号映射（`.sig`）

| 信号 | 通道 | 说明 |
|---|---|---|
| SRCLK | `1:1:2` | 移位时钟 |
| RCLK | `1:1:3` | 锁存时钟 |
| SER | `1:1:5` | 串行数据 |
| OE_n | `1:1:4` | 输出使能（低有效） |
| SRCLR_n | `1:1:1` | 清零（低有效） |
| QA~QH | `1:1:7`、`1:1:10`~`1:1:16` | 并行输出 |
| QH_n | `1:1:0` | 级联串出 |
| VCC | DPS `1:1:0` | 电源 |
| TMU1/TMU2 | `1:1:0` / `1:1:1` | 时序（预留） |
| RCLK_T / SRCLK_T / QA_T | `1:1:8` / `1:1:9` / `1:1:6` | 测试点，给 Tpd 用 |

> 通道不是连续的：QA=`7`、QB=`10`，中间 `8/9/6` 留给了 `RCLK_T/SRCLK_T/QA_T`。
> 改线时不要按「QA~QH 连续 8 个通道」想当然。

### 2.2 信号分组（`.grp`）

| 组名 | 成员 | 用途 |
|---|---|---|
| `IO_PINS` | 14 个 I/O | OS、功能 |
| `INPUT_PINS` | RCLK,SRCLK,SER,OE_n,SRCLR_n | IIH/IIL |
| `OUTPUT_PINS` | QA~QH | VOH/VOL/IOZ |
| `Q_OUTPUT_PINS` | QA~QH + QH_n | OSP（含串出） |
| `ENBNLE_PINS` | SER,QA~QH,QH_n,OE_n,SRCLR_n | 备用（名字拼写有误） |
| `TMU_PINS` | TMU1,TMU2 | 时序 |
| `I_PINS` | SER,SRCLK,OE_n,SRCLR_n | Tpd 输入 |

### 2.3 时序（`.tim`）

| WFT | 周期 | 内容 |
|---|---|---|
| WFT1 | 16 ns | 通用高速档（`H/L` 在 10 ns） |
| **WFT2** | **60 ns** | **SRCLK、RCLK：0→D、1→D 20 ns 上升；H/L 在 40 ns 比较** |

WFT2 把时钟上升沿放在 20 ns、采样放在 40 ns，给 595 的建立/保持留余量。

### 2.4 Pattern（`.pat`）

| # | Pattern | 用途 |
|---|---|---|
| 1 | `VOH` | 移入全 1，OE=0，输出全高 |
| 2 | `VOL` | 清零/移入全 0，输出全低 |
| 3 | `Shift_R` | 移位 + 锁存，检查 QA~QH |
| 4 | `Reset` | SRCLR_n=0 清零 |
| 5 | `HI_Z` | OE_n=1 高阻 |
| 6 | `ICC_dyn` | 动态 ICC（TMF 关闭） |
| 7 | `DELAY` | Tpd 的 loop_inf 激励（TMF 关闭） |
| 8 | `DELAY2` | 备用延时 Pattern |

## 四、`Test.cpp` 实现要点

### 4.1 OS / ICC：标准配方

- `OSN`：VCC=0，`FIMV` 对 `IO_PINS` 抽 **−100 µA**，测 14 脚电压；
- `OSP`：VCC=0，对 `Q_OUTPUT_PINS` 灌 **+100 µA**，测 9 个 Q 输出；
- `ICC`：VCC=6 V，先 20 mA 量程上电，再切 20 µA 量程测静态电流。

### 4.2 IOZ：三态漏电

```cpp
dio.Pattern("HI_Z").Test();              // OE_n=1，输出高阻
ppmu.Signal("OUTPUT_PINS").SetMode("FVMI").VoltForce(0)
    .CurrRange(20e-6).VoltClamp(6, -2);  // 0 V 漏电
ppmu.Signal("OUTPUT_PINS").Measure(IOZ_L_RESULT, MEAS_AVG, 10, 10);

ppmu.Signal("OUTPUT_PINS").SetMode("FVMI").VoltForce(6); // 6 V 漏电
ppmu.Signal("OUTPUT_PINS").Measure(IOZ_H_RESULT, MEAS_AVG, 10, 10);
```

> `MEAS_AVG, 10, 10`：10 次平均，抑制高阻态下的噪声。

### 4.3 VOH / VOL：移位 + 锁存后带载

```cpp
dio.Pattern("VOH").Test();               // 移入全 1，RCLK 锁存，OE=0
ppmu.Signal("OUTPUT_PINS").SetMode("FIMV")
    .CurrForce(-6e-3).CurrRange(20e-3).VoltClamp(5, -2);
ppmu.Signal("OUTPUT_PINS").Measure(VOH_RESULT);
```

VOL 对称：`VOL` Pattern 移入全 0，`CurrForce(+6e-3)`。
注意 **VOH 抽 −6 mA、VOL 灌 +6 mA**，方向不能反。

### 4.4 FUNC：三个 Pattern 三个参数

| Param | 名称 | Pattern | 验证点 |
|---|---|---|---|
| 0 | `Z` | `HI_Z` | OE_n=1 时 QA~QH 为高阻 |
| 1 | `S` | `Reset` | SRCLR_n=0 后输出为低 |
| 2 | `R` | `Shift_R` | 移位 + 锁存后的 QA~QH |

> 代码里 **S=Reset、R=Shift_R**，与字母直觉（S=Shift、R=Reset）相反，
> 看 TMF 参数名时容易误解，建议改名或加注释。

## 五、Pattern 设计要点

1. **先清零再移位**：`SRCLR_n=0` 一个周期，保证移位寄存器初态为 0。
2. **OE_n 先使能**：在移位前置 `OE_n=0`，否则输出一直是 Z，比较不到。
3. **8 个 SRCLK 上升沿**：WFT2 的 `1` 在 20 ns 上升，40 ns 采样，
   每个周期移 1 位。
4. **最后一个 RCLK 上升沿**：把 8 位送进输出锁存，之后才比较 QA~QH。
5. **高阻 Pattern 用 `Z`**：`HI_Z` 里 OE_n=1，QA~QH 写 `Z`，测试机不驱动。
6. **`X` 只用于不关心**：输入脚不要写 `X`，输出脚不比较才写 `X`。

## 六、已知问题（代码审查清单）

> 这一节是本案例最有价值的部分：工程能编译、能跑，但**参数个数和单位存在不一致**。
> 上机前应逐条确认，否则会出现「越界写参数」「漏测」「误判」。

| # | 位置 | 问题 | 影响 | 建议 |
|---|---|---|---|---|
| 1 | `OSP()` | 只测 9 个 Q 输出，却调用 `CheckResultAndBin(0, R, 14)` | 参数 9~13 越界/取到无效值 | 改成 `9`，与 TMF 一致 |
| 2 | `VOH()` / `VOL()` | 只测 8 个输出，却调用 `... ,14)` | 参数 8~13 越界 | 改成 `8` |
| 3 | `IIH()` / `IIL()` | 只测 5 个输入，却调用 `... ,14)` | 参数 5~13 越界 | 改成 `5` |
| 4 | `IIH()` / `IIL()` | `.tmf` 单位写 **mA**、限值 ±1 mA | 输入漏电实际是 µA 级，判据过松 | 改成 **µA**、±1 µA |
| 5 | `IOZ()` | 两次 `CheckResultAndBin(0, ..., 8)`，第二次覆盖第一次 | 0 V 漏电结果丢失，只剩 6 V | L 用 Param 0，H 用 Param 8；TMF 扩成 16 项，或分开两次测 |
| 6 | `IIH()` | 复位的是 `IO_PINS`，但连接的是 `INPUT_PINS` | 复位对象错，可能残留驱动 | 改成 `INPUT_PINS` |
| 7 | `IIH()` | `VoltForce(6)` 却 `VoltClamp(2, -2)` | 钳位低于强制电压，可能限流/测不准 | 改成 `VoltClamp(6, -2)` |
| 8 | `Tpd()` / `ICC_dyn()` | 空桩 + `LoopCount=0` | 功能缺失，误开即假通过 | 补实现或保持关闭并注释 |
| 9 | `.grp` | `ENBNLE_PINS` 拼写错误 | 可读性差，易引用错 | 改名 `ENABLE_PINS` |
| 10 | `pattern/*.csv` | 表头末尾多逗号 / 列数不一致 | 不同解析器可能报错 | 统一列数与逗号 |
| 11 | `FUNC()` | S=Reset、R=Shift_R，与字母直觉相反 | 参数名易误解 | 改名为 `RST`/`SHIFT` |
| 12 | `Tpd()` 注释代码 | `tmu.Connect()` 后没有 `GetMeasResult` 的完整路径 | 不可直接启用 | 参照 74HC138/1637 的 Hold 流程重写 |

### 6.1 为什么这些 bug 不容易被发现

- `CheckResultAndBin` 的 `paramCount` 只影响「写多少个参数」，
  **多写的参数在 TMF 里没有对应项时不会报错**，只是被忽略或越界；
- `IIH/IIL` 的 mA 限值让 **µA 级漏电永远在范围内**，等于没测；
- `Tpd/ICC_dyn` 的 `LoopCount=0` 让空桩永远不执行，看起来「全绿」。

> 这也是本仓库反复强调「**工程 `.tmf` 与 `Test.cpp` 必须交叉核对**」的原因。
